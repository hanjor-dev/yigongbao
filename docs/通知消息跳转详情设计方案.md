# 通知消息跳转详情设计方案

## 背景

系统消息通知（弹窗/铃铛列表）中的"查看详情"按钮，需要跳转到对应业务页面并自动打开详情弹窗。当前系统详情页均以弹窗形式嵌入各列表页，无法直接通过路由访问。

---

## 技术方案：Route Query 参数

**核心思路**：

1. 后端在通知消息中提供 `jumpUrl`（页面路径）和 `bizId`（业务实体 ID）
2. 前端跳转时将 `bizId` 拼接为 `?detailId=xxx` 附加到 URL
3. 目标列表页在 `onMounted` 检测 `query.detailId`，自动调用现有的详情打开方法

**优点**：URL 可刷新保留、可分享直接打开详情、改动最小。

---

## 前后端约定

### 通知消息字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `jumpUrl` | string | 目标页面路由路径（仅路径，不含参数） |
| `bizId` | number | 业务实体主键 ID |
| `bizType` | string | 业务类型标识 |

### jumpUrl 路径约定

| 业务场景 | jumpUrl | bizId 含义 |
|---|---|---|
| 订单 | `/business/order` | 订单 ID |
| 设计工单 | `/business/design` | 设计工单 ID |
| 生产单 | `/produce/workOrder` | 生产单 ID |
| 质检记录 | `/qc/inspection` | 质检记录 ID |
| 仓储记录 | `/warehouse/storage` | 仓储记录 ID |
| 审核申请 | `/business/modifyApply` | 申请单 ID |

> **规则**：`jumpUrl` 统一为前端路由路径，不含 query 参数；`bizId` 由前端在跳转时自动拼接为 `?detailId=bizId`。

## 前端实现

### 1. 跳转时拼接 detailId（已实现）

```ts
// src/components/NotificationPopup.vue & NotificationList.vue
function handleViewDetail() {
  if (currentPopup.value?.jumpUrl) {
    router.push({
      path: currentPopup.value.jumpUrl,
      query: { detailId: String(currentPopup.value.bizId) }
    })
  }
  store.confirmCurrentPopup()
}
```

### 2. 各列表页接收并打开详情（待实现）

在需要支持跳转打开详情的列表页中添加：

```ts
import { useRoute } from 'vue-router'
import { onMounted } from 'vue'

const route = useRoute()

onMounted(() => {
  const detailId = Number(route.query.detailId)
  if (detailId) {
    handleView({ id: detailId })  // 调用该页面现有的打开详情方法
  }
})
```
