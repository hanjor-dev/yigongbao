# Production Ledger 22-Column Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current 41-column production-product ledger with the approved 22-column export, strip the final file extension, and filter by order creation time.

**Architecture:** Keep the controller/service flow unchanged. Make `ProductionProductMapper` return one flat row per `production_product`, with order values from `order_main` and a correlated flow-card-level post-processing aggregate; make `ProductLedgerExcelBuilder` own presentation-only formatting and fixed columns.

**Tech Stack:** Java 21, Spring/MyBatis annotations, Apache POI, JUnit 5, Maven

- [x] **Step 3: Implement the minimal Mapper SQL**

Change `listProductLedgerData` to select only the approved raw values and computed seconds. Give every projected value an explicit alias matching the 20-key contract above. Use a correlated aggregate:

```sql
SELECT CASE
         WHEN COUNT(*) = 0 THEN 0
         WHEN SUM(CASE WHEN start_time IS NULL OR end_time IS NULL OR end_time < start_time
                       THEN 1 ELSE 0 END) > 0 THEN NULL
         ELSE SUM(TIMESTAMPDIFF(SECOND, start_time, end_time))
       END

  AND p_process.process_type IN ('wash', 'cure', 'clean_dry')
  AND p_process.is_deleted = 0
```
