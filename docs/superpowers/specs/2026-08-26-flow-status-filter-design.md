# 流转状态筛选展示字段设计

## 目标

调整 `/flow/select/statuses` 返回结果：保留完整状态枚举，同时通过 `show` 字段标记是否应展示在前端筛选项中。

## 方案

在现有 `SelectTreeVO` 增加布尔字段 `show`。接口继续按原顺序返回状态，并保留阶段过滤、名称、值和颜色字段。

以下不会停留的自动流转状态返回 `show=false`：草稿、数据审核通过、数据审核不通过、质检合格、质检不合格、返工；其余状态返回 `show=true`。

## 验证

通过 `FlowSelectControllerTest` 验证接口返回指定状态的展示标记，并验证阶段筛选行为不受影响。
