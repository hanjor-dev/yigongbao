# 用户加工中心名称同步修复

## 目标

用户更新接口只接收 `centerId` 时，为生产员和生产管理员从加工中心主数据查询名称，并同步写入用户的 `centerName` 冗余字段。

## 设计

- 在 `UserServiceImpl.updateUser` 中，基于本次生效角色判断是否为生产员或生产管理员。
- 两类角色均要求存在有效加工中心；查询结果既用于校验，也作为 `centerName` 的唯一来源。
- 当请求携带 `centerId` 时，始终以查询到的加工中心名称覆盖用户实体的 `centerName`，不依赖前端传值。

## 错误处理

- 未绑定加工中心时保留现有缺少参数错误。
- 加工中心不存在时保留现有数据不存在错误。

## 验证

- 为生产员和生产管理员分别添加更新测试：请求仅传 `centerId`，断言持久化实体的 `centerName` 为查询到的名称。
