# 图纸下载文件名使用产品类型中文名称设计

## 问题

分类图纸生成时把 `productCategory` 字典编码直接拼入上传文件名。基础文件下载服务随后从持久化的 `originalFilename` 生成 `Content-Disposition`，导致下载名称出现“零五-17.2图纸.xlsx”。已有图纸会被复用，仅修正后续生成名称无法修复存量文件。

## 设计

1. `FileService` 增加向后兼容的下载重载，允许业务调用方指定本次下载显示的文件名；原有下载方法继续使用持久化原始名称。
2. `DesignDocServiceImpl` 复用已注入的 `DesignQueryHelper.getDictName`，把分类编码转换为中文名称。
3. 分类图纸下载时动态传入“患者姓名-分类中文名图纸.xlsx”，让存量文件立即使用正确名称。
4. 新生成图纸上传时复用同一命名方法，保证文件元数据本身也正确。
5. 字典名称不存在时使用“未分类”，不再把编码或 `null` 暴露在文件名中。

## 兼容性

- 接口 URL、请求参数和响应内容不变。
- 其他文件下载调用不变。
- 不修改数据库结构或历史文件记录。

## 测试

- 基础文件服务验证指定名称会覆盖响应头，旧方法仍使用原始名称。
- 设计文档服务验证复用历史图纸时下载名称为中文分类。
- 设计文档服务验证新生成图纸上传名称为中文分类。
