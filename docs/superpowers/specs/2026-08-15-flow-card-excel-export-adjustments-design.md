# 生产流转卡 Excel 导出四项修正设计

## 目标

修正生产流转卡 Excel 中生产批号、结束时间标签、后处理时间格式和空气压缩机编号显示，并让线上已有缓存文件在部署后能够重新生成。

## 现状与根因

1. `FlowCardExcelBuilder` 直接把 `productionBatchNo` 写入 Excel，没有根据打印开始日期转换。
2. 打印结束标签硬编码为“结束:”。
3. 酒精初洗、固化、超声清洗共用秒级时间格式器。
4. 空气压缩机编号的本地保存、查询、传递和写入链路已经完整，但没有回归测试；线上空值还可能来自历史数据、前端未提交辅助设备或旧缓存 Excel。
5. 导出接口按 `content_update_time` 与 `flow_card_generate_time` 复用缓存，代码升级不会自动让旧 Excel 失效。

## 设计

- 当 `printStartTime` 存在时，导出批号使用 `yyyyMMdd`；不存在时回退到原 `productionBatchNo`，保持打印前导出兼容性。
- 打印起止时间继续精确到秒，仅把标签修正为“结束时间:”。
- 新增分钟级格式器，仅供 `wash`、`cure`、`clean_dry` 的起止时间使用。
- 保留现有空气压缩机生产代码，增加 Builder 回归测试，证明 `secondaryDeviceNo` 写入模板空气压缩机行。
- 增加幂等 SQL：将有效流转卡的 `flow_card_generate_time` 置空，使下次导出按新规则重新生成；不删除旧文件，不修改业务数据、业务更新时间和表结构。

## 测试与验收

- 打印开始时间 `2026-08-13 14:15:24` 时，批号单元格为 `20260813`。
- 打印开始时间为空时，仍输出原生产批号。
- 打印开始时间为空且原生产批号为 null/空白时，继续输出 `-`。
- 打印结束单元格为 `结束时间: 2026-08-13 16:15:24`。
- 三个后处理工序的开始、结束时间均为 `yyyy-MM-dd HH:mm`，不包含秒。
- `clean_dry.secondaryDeviceNo` 出现在空气压缩机设备编号单元格。
- 现有 Builder 测试和生产模块测试保持通过。

## 上线核验

- 先停止所有旧版本实例或将其全部摘流，确认新版本实例已生效后，再执行一次性缓存失效 SQL，避免旧实例重新写入旧格式缓存。
- 对仍缺少空气压缩机编号的流转卡查询 `production_process.secondary_device_id/secondary_device_no`；若数据库为空，再核对前端开始超声清洗请求是否提交 `secondaryDeviceId`。
