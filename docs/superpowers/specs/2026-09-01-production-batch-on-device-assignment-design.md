# 设备提交时生成生产批号与产品编号设计

## 目标

生产批号和正式产品编号以生产员提交打印设备的日期为准，不再以流转卡创建日期或前端填写的生产批号为准；释放后重新选择设备时重新生成一套编号。

## 规则

- `production_batch_no` 在 `assignDevice` 成功流程中由后台按业务当前日期生成，格式保持 `YYMMDD`。
- 设备当日上机次数在同一设备提交事务中递增。
- 正式产品编号使用新生产批号、设备编号、当日上机次数和产品序号生成。
- 更换设备必须先执行现有释放流程；释放会清空旧产品编号，重新提交设备后重新生成批号和产品编号。
- 已有历史流转卡及历史产品编号不回溯修改。
- 前端不再提交生产批号；后端不允许该参数覆盖正式批号。原材料批号仍可保存。

## 数据流与事务

设备提交时按“锁设备 → 锁流转卡 → 权限/状态校验 → 保存重量 → 生成并写入批号 → 保存设备与工序 → 递增设备日计数 → 生成正式产品编号”的顺序执行。任一环节失败，设备、批号、计数器和产品编号整体回滚。

## 导出与兼容

流转卡 Excel 直接使用数据库中的正式生产批号，不再用打印开始时间覆盖显示值，避免设备提交日期与实际打印开始日期跨天时出现口径不一致。批号预览接口保留兼容，但不作为正式批号依据；批号提交接口不再允许修改生产批号。

## 验收

- 跨午夜提交设备时，批号和产品编号使用提交当天日期。
- 释放后重新提交设备时，批号和产品编号重新生成，设备上机次数不回退。
- 提交失败时不留下半成品批号、设备配置、计数器或产品编号。
- Excel、生产列表、产品台账、质检和仓储展示的批号口径一致。
