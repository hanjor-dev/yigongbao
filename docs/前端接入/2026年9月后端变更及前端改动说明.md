# 2026 年 9 月后端变更及前端改动说明

本文档整理 2026 年 9 月后端最终落地版本中需要前端关注的变更，已合并后端中间调整过程，仅描述前端应对的最终版本。

## 一、设计师备注

### 接口调整

原接口停止使用：

```http
POST /design/workorder/{orderId}/evaluation-opinion
```

当前接口：

```http
POST /design/workorder/{orderId}/designer-remark
```

请求体：

```json
{
  "designerRemark": "备注内容"
}
```

参数要求：

- `designerRemark` 必填，不能是空白内容
- 最大长度 2000 字符
- 不需要传 `dataEvaluationOpinion`
- 不需要传 `version`

只有当前订单分配的设计师可以保存备注。

### 返回字段

以下接口返回对象中均增加 `designerRemark`：

```http
POST /design/workorder/list
GET  /design/workorder/{orderId}
POST /order/page
GET  /order/{id}
```

前端需要在设计工单和订单的列表、详情页面增加设计师备注展示；设计工单详情需要支持备注回显、编辑和保存。

注意：

- `designerRemark` 表示设计师备注
- `dataEvaluationOpinion` 仍表示影像评估意见，两个字段不能混用

订单和设计工单默认列配置已增加 `designerRemark`，前端使用列配置接口时可直接读取该字段。

## 二、订单导出字段

接口：

```http
GET /order/export/fields
```

当前可导出的新增字段：

| 字段 | 名称 |
|---|---|
| `designStartTime` | 设计开始时间 |
| `designSubmitTime` | 设计结束时间 |
| `productionStartTime` | 生产开始时间 |
| `productionEndTime` | 生产结束时间 |
| `designerRemark` | 设计师备注 |

自定义导出接口：

```http
POST /order/export/custom
```

前端应使用 `/order/export/fields` 返回的字段列表生成导出选项，不需要在页面中手工维护字段。

## 三、订单搜索

接口：

```http
POST /order/page
```

原有 `orderCode` 关键字搜索现在也会匹配医生姓名。

前端无需新增参数，可将搜索提示调整为“订单编号/机构/医院/患者/医生等关键字”。

## 四、生产批号和产品编号

- 生产批号由后端在设备提交时自动生成
- 产品编号在设备分配相关流程中生成
- 前端不再依赖手工填写生产批号
- `productionBatchNo` 不建议继续传递
- `materialBatchNo` 仍按原流程提交
- `/production/record/{id}/generate-batch-no` 为兼容接口，新页面不建议调用

生产流转卡列表和详情仍按后端返回的 `productionBatchNo`、`productNo` 展示。

## 五、强制完成打印

接口：

```http
POST /production/record/{id}/force-complete-print
```

该接口无请求体。

前端需要：

- 在生产流转卡操作区域增加“强制完成打印”按钮
- 仅对拥有 `manufacture:ForceCompletePrint` 权限的用户展示
- 操作前增加确认提示
- 成功后刷新流转卡详情、打印状态和列表
- 不再填写或提交强制完成原因

## 六、订单修改申请

订单修改相关行为调整如下：

- 数据审核驳回后，符合条件的业务员可以直接修改订单
- 存在待审核修改申请时，不能直接修改订单
- 存在待审核取消申请时，不能直接修改订单
- 过期申请会被后端自动回收

前端需要：

- 修改提交失败后刷新订单详情和申请状态
- 对待审核、取消申请、申请过期等情况显示后端返回的提示
- 不要长期缓存 `can-apply` 判断结果

## 七、统计数据

数据概览的周维度统计和数据权限过滤已修正。

接口结构没有变化，前端无需调整接口，只需接受统计结果与旧版本可能存在差异。

## 八、前端改动清单

1. 替换设计师备注保存接口及 API 方法名。
2. 设计工单和订单列表、详情增加 `designerRemark` 展示。
3. 设计工单详情增加设计师备注编辑和保存功能。
4. 导出字段选择器改为读取 `/order/export/fields`。
5. 增加生产流转卡“强制完成打印”操作及权限判断。
6. 调整生产批号录入逻辑，不再依赖前端生成或填写。
7. 完善订单修改申请的异常提示和状态刷新。
8. 调整订单关键字搜索提示，说明支持医生姓名搜索。
