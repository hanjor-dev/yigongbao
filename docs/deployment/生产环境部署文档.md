# 医工宝生产环境部署文档

## 一、概述

本文档描述医工宝系统生产环境的部署流程，包括Docker容器化部署、Nginx反向代理配置以及WebSocket服务配置。

### 1.1 版本信息

- **应用版本**: 1.0.0
- **Java版本**: 21
- **Spring Boot版本**: 3.2.x
- **数据库**: MySQL 8.0
- **缓存**: Redis 7
- **容器化**: Docker + Docker Compose

### 1.2 架构说明

生产环境采用以下架构：

```
                    ┌─────────────────┐
                    │   Nginx (宿主机)  │
                    │   监听端口:       │
                    │   - 80 (HTTP)    │
                    │   - 8081 (WS)    │
                    └────────┬─────────┘
                             │
                ┌────────────┴────────────┐
                │                         │
        ┌───────▼────────┐       ┌───────▼────────┐
        │  HTTP API 代理  │       │  WebSocket 代理 │
        │  /api/* → 8082  │       │  / → 8082      │
        └───────┬────────┘       └───────┬────────┘
                │                         │
                └────────────┬────────────┘
                             │
                    ┌────────▼─────────┐
                    │  Docker 容器      │
                    │  yigongbao-app   │
                    │  端口: 8082       │
                    │  - HTTP API: /api│
                    │  - WebSocket: /  │
                    └──────────────────┘
```

**端口说明**：
- **8082**: 应用容器端口（HTTP API + WebSocket）
- **8081**: Nginx监听端口（WebSocket专用，对外暴露）
- **80**: Nginx监听端口（HTTP API，可选）

**路径说明**：
- HTTP API: `http://ip/api/*` → 容器 `http://localhost:8082/api/*`
- WebSocket: `ws://ip:8081/` → 容器 `ws://localhost:8082/`

## 二、环境准备

### 2.1 服务器要求

- **操作系统**: Linux (推荐 Ubuntu 20.04+ 或 CentOS 7+)
- **CPU**: 2核及以上
- **内存**: 4GB及以上
- **磁盘**: 50GB及以上

### 2.2 软件依赖

需要在服务器上安装以下软件：

1. **Docker** (版本 20.10+)
   ```bash
   curl -fsSL https://get.docker.com | sh
   sudo systemctl enable docker
   sudo systemctl start docker
   ```

2. **Docker Compose** (版本 2.0+)
   ```bash
   sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
   sudo chmod +x /usr/local/bin/docker-compose
   ```

3. **Nginx** (版本 1.18+)
   ```bash
   sudo apt update
   sudo apt install nginx -y
   sudo systemctl enable nginx
   sudo systemctl start nginx
   ```

### 2.3 防火墙配置

开放必要的端口：

```bash
# 开放 HTTP 端口
sudo ufw allow 80/tcp

# 开放 WebSocket 端口
sudo ufw allow 8081/tcp

# 开放 SSH 端口（如果使用）
sudo ufw allow 22/tcp

# 启用防火墙
sudo ufw enable
```

## 五、Nginx配置（重点）

### 5.1 配置文件位置

Nginx配置文件通常位于：
- Ubuntu/Debian: `/etc/nginx/sites-available/yigongbao`
- CentOS/RHEL: `/etc/nginx/conf.d/yigongbao.conf`

### 5.2 完整配置示例

创建配置文件 `/etc/nginx/sites-available/yigongbao`：

```nginx
# HTTP API 服务器配置
server {
    listen 80;
    server_name your_domain.com;  # 替换为实际域名或IP

    # 客户端请求体大小限制（支持大文件上传）
    client_max_body_size 2G;

    # HTTP API 代理
    location /api/ {
        proxy_pass http://localhost:8082/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # 超时设置
        proxy_connect_timeout 60s;
        proxy_send_timeout 60s;
        proxy_read_timeout 60s;
    }

    # 静态文件代理（如果需要）
    location /files/ {
        proxy_pass http://localhost:8082/api/files/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

# WebSocket 服务器配置（重点）
server {
    listen 8081;
    server_name your_domain.com;  # 替换为实际域名或IP

    # WebSocket 代理配置
    # 外部系统连接 ws://ip:8081/ 会被代理到后端的 /ws/device
    location / {
        # 代理到应用的 8082 端口 WebSocket 路径
        proxy_pass http://localhost:8082/ws/device;
        
        # WebSocket 必需的头部
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        
        # 标准代理头部
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 超时设置（保持长连接）
        proxy_connect_timeout 7d;
        proxy_send_timeout 7d;
        proxy_read_timeout 7d;
    }
}
```

### 5.3 配置说明

**WebSocket配置关键点**：

1. **监听端口**: 8081（对外暴露的WebSocket端口）
2. **代理目标**: `http://localhost:8082/ws/device`（应用容器的WebSocket路径）
3. **必需头部**:
   - `Upgrade: $http_upgrade` - 升级协议到WebSocket
   - `Connection: "upgrade"` - 保持连接升级
   - `proxy_http_version 1.1` - 使用HTTP/1.1协议
4. **超时设置**: 7天（保持WebSocket长连接）

**路径映射关系**：
- 外部访问: `ws://your_domain.com:8081/`（无需路径后缀）
- Nginx代理: `http://localhost:8082/ws/device`
- 应用处理: WebSocket路径为 `/ws/device`（已在 `DeviceWebSocketConfig.java` 中配置）

### 5.4 启用配置

```bash

# 测试配置文件语法
```

## 七、常见问题

### 7.1 WebSocket连接失败

**问题**: 无法连接到 `ws://your_domain.com:8081/`

**排查步骤**:

1. 检查Nginx是否监听8081端口：
   ```bash
   sudo netstat -tlnp | grep 8081
   ```

2. 检查防火墙是否开放8081端口：
   ```bash
   sudo ufw status | grep 8081
   ```

3. 检查应用容器是否正常运行：
   ```bash
   docker ps | grep yigongbao-app
   curl http://localhost:8082/api/v3/api-docs
   ```

4. 检查Nginx配置是否正确：
   ```bash
   sudo nginx -t
   cat /etc/nginx/sites-available/yigongbao
   ```

5. 查看Nginx错误日志：
   ```bash
   sudo tail -50 /var/log/nginx/error.log
   ```

### 7.2 WebSocket连接后立即断开

**问题**: WebSocket连接成功但立即断开

**可能原因**:
- Nginx超时设置过短
- 应用未正确处理WebSocket握手

**解决方案**:
1. 确认Nginx配置中的超时设置：
   ```nginx
   proxy_connect_timeout 7d;
   proxy_send_timeout 7d;
   proxy_read_timeout 7d;
   ```

2. 检查应用日志是否有异常：
   ```bash
   docker-compose -f docker-compose.prod.yml logs app | grep -i websocket
   ```

### 7.3 容器启动失败

**问题**: Docker容器无法启动

**排查步骤**:

1. 查看容器日志：
   ```bash
   docker-compose -f docker-compose.prod.yml logs app
   ```

2. 检查环境变量配置：
   ```bash
   cat .env
   ```

3. 检查数据库连接：
   ```bash
   docker exec -it yigongbao-mysql mysql -uroot -p${DB_PASSWORD} -e "SHOW DATABASES;"
   ```

4. 检查Redis连接：
   ```bash
   docker exec -it yigongbao-redis redis-cli -a ${REDIS_PASSWORD} ping
   ```

### 7.4 端口冲突

**问题**: 端口已被占用

**解决方案**:

1. 查看端口占用情况：
   ```bash
   sudo netstat -tlnp | grep -E '8080|8081'
   ```

2. 停止占用端口的进程或修改配置使用其他端口

## 九、总结

### 9.1 部署架构总结

生产环境采用以下架构：
- **应用端口**: 8082（容器内，HTTP API + WebSocket）
- **Nginx端口**: 80（HTTP API）、8081（WebSocket）
- **WebSocket路径**: 外部访问 `ws://ip:8081/`，内部代理到 `http://localhost:8082/`

### 9.2 关键配置点

1. **应用配置** (`application-prod.yml`):
   - 端口: 8082
   - WebSocket路径: `/`

2. **Docker配置** (`docker-compose.prod.yml`):
   - 端口映射: `8082:8082`
   - 环境变量: `SPRING_PROFILES_ACTIVE=prod`

3. **Nginx配置**:
   - HTTP API: 监听80端口，代理到 `http://localhost:8082/api/`
   - WebSocket: 监听8081端口，代理到 `http://localhost:8082/`
   - 必需头部: `Upgrade`, `Connection`, `proxy_http_version 1.1`
