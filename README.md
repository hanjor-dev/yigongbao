# 医工宝

医工宝是一款面向医疗行业的数字化生产管理平台，主要服务于个性化医疗器械的定制生产场景。

## 项目背景

随着3D打印技术在医疗领域的广泛应用，个性化医疗器械的定制需求日益增长。医工宝旨在连接医生、设计师与生产商，提供从订单创建到产品交付的全流程数字化管理。

## 核心功能

### 订单管理
- 支持创建医疗器械、非医疗器械、服务三种类型的订单
- 订单状态全流程跟踪（订单、设计、生产等）

### 设计管理
- 设计师在线接收和处理设计任务
- 上传3D设计文件（STL/3MF/OBJ格式）
- 自动生成指令单和图纸，支持电子签名

### 生产管理
- 3D打印生产任务管理
- 生产作业记录（产品流转卡）
- UDI码追溯管理
- 扫码流转机制

### 权限管理
- 多角色体系：业务员、设计师、生产员、管理员等
- 数据权限精细控制
- 医院范围配置
