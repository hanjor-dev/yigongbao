# 医工宝系统功能设计

---

# 功能架构详细设计

```
医工宝系统
│
├─ 一、业务运营
│  │
│  ├─ 1.1 订单管理
│  │  ├─ 订单列表（查询筛选、查看详情、创建订单、编辑订单、提交订单、删除草稿、导出、审核）
│  │  ├─ 草稿订单（草稿列表、保存草稿、恢复草稿、删除草稿）
│  │  ├─ 订单审核（待审核列表、审核通过、审核拒绝、审核记录查看）
│  │  ├─ 订单修改申请
│  │  │  ├─ 申请列表（发起申请、查询）
│  │  │  └─ 审核列表（待审核、审核通过、审核拒绝、执行修改）
│  │  └─ 订单查询（订单统计、订单导出）
│  │
│  ├─ 1.2 设计管理
│  │  ├─ 我的工单（待设计列表、查看详情、开始设计、上传设计文件、填写打印信息、生成指令单、生成图纸、提交设计）
│  │  ├─ 设计审核（待审核列表、查看设计详情、审核通过、审核拒绝）
│  │
│  ├─ 1.3 生产管理（？）
│  │  ├─ 生产任务（待生产列表、查看详情、下载打印文件、开始生产、指定生产设备）
│  │  ├─ 生产作业记录（填写作业记录表、保存记录、打印记录）
│  │  ├─ 扫码流转（生产扫码、质检扫码、入库扫码、UDI扫码）
│  │  ├─ 生产设备管理（设备列表、新增设备、编辑设备、删除设备、设备状态管理）
│  │  └─ 生产统计（生产统计报表、生产记录导出）
│  │
│  ├─ 1.4 质检管理
│  │  ├─ 质检任务（待质检列表、查看详情、开始质检、填写质检记录、申请返工/报废）
│  │
│  └─ 1.5 仓储管理
│     ├─ 入库管理（待入库列表、扫码入库、确认入库）
│     ├─ 库存管理（库存列表、库存详情查询、库存调整）
│     ├─ 出库管理（待出库列表、扫码出库、确认出库）
│     └─ UDI管理（UDI码列表、UDI码查询追溯）
│
├─ 二、客户管理
│  │
│  ├─ 2.1 医院管理
│  │  ├─ 医院列表（查询筛选、新增、编辑、删除、详情查看、启用停用）
│  │  └─ 医院查询（医院数据导出）
│  │
│  ├─ 2.2 科室管理
│  │  ├─ 科室列表（查询、新增、编辑、删除）
│  │  └─ 科室查询
│  │
│  └─ 2.3 医生管理
│  │  ├─ 医生列表（查询、新增、编辑、删除、历史订单查看）
│  │  └─ 医生查询
│  │
│  └─ 2.4 医院范围模板管理
│     ├─ 模板列表（查询、新增、编辑、删除、详情查看）
│     └─ 模板医院配置（配置模板包含的医院）
│
├─ 三、基础数据
│  │
│  ├─ 3.1 机构管理
│  │  ├─ 机构列表（查询筛选：按类型（生产企业/经销商/医疗机构/其他）、地区、状态，新增、编辑、删除、详情查看、启用停用）
│  │  └─ 机构查询（数据导出）
│  │
│  ├─ 3.2 部门管理
│  │  ├─ 部门列表（查询：按机构筛选，新增、编辑、删除、启用停用）
│  │  └─ 部门查询
│  │
│  ├─ 3.3 项目管理
│  │  ├─ 部位管理（部位列表、查询、新增、编辑、删除、编号规则配置）
│  │  ├─ 重建项目（项目列表、查询、新增、编辑、删除、详情查看、配置关联部位）
│  │  ├─ 项目分类（分类列表、新增、编辑、删除）
│  │  └─ 项目-部位关联（部位-项目关联配置、子项目配置）
│  │
│  ├─ 3.4 产品管理
│  │  ├─ 产品目录（查询、新增、编辑、删除、详情查看）
│  │  ├─ 产品型号（查询、新增、编辑、删除）
│  │  └─ 注册证管理（列表、新增、编辑、删除）
│  │
│  ├─ 3.5 物料管理
│  │  ├─ 物料列表（查询、新增、编辑、删除）
│  │  ├─ 物料库存【废弃】（查询、库存调整）
│  │  └─ 原材料批次【废弃】（查询、新增、批次追溯）
│  │
│
├─ 四、用户和权限管理
│  │
│  ├─ 4.1 账户管理
│  │  ├─ 账户列表（查询筛选：按机构类型/角色/所属机构/状态，新增、编辑、删除、详情查看、启用停用、重置密码、分配医院业务范围）
│  │  ├─ 机构用户管理（外部机构管理员管理本机构用户：用户列表、创建、编辑、启用停用）
│  │  └─ 账户查询（数据导出）
│  │
│  ├─ 4.2 角色权限管理
│  │  ├─ 角色列表（查询、新增、编辑、删除、详情查看）
│  │  ├─ 权限配置（功能点权限配置、数据范围配置：self/hospitals/org/all）
│  │  └─ 角色查询
│  │
│  ├─ 4.3 资源管理
│  │  ├─ 菜单配置（树形列表、新增、编辑、删除、排序）
│  │  └─ 功能点配置（菜单功能点配置）
│  │
│  └─ 4.4 注册审核管理
│     ├─ 注册申请列表（查询筛选：按状态/日期，查看详情、审核通过、审核拒绝、审核历史）
│     └─ 注册统计（数据统计）
│
├─ 五、系统配置
│  │
│  ├─ 5.1 字典管理（查询、新增、编辑、删除）
│  │
│  ├─ 5.2 流程配置管理
│  │  ├─ 流程定义（模板列表、新增、编辑、删除、发布版本、版本管理）
│  │  ├─ 节点配置（属性配置、新增、编辑、删除）
│  │  ├─ 转移规则配置（节点间转移规则配置）
│  │  └─ 流程监控（流程执行监控）
│  │
│  ├─ 5.3 系统参数配置
│  │  ├─ 参数配置（查询、新增、编辑、删除、启用停用）
│  │  ├─ 编码规则（规则列表、新增、编辑、删除、编码预览）
│  │  └─ 消息模板（模板列表、新增、编辑、删除）
│  │
│  └─ 5.4 操作日志
│     ├─ 登录日志（列表、导出）
│     └─ 操作日志（列表、导出）
│
└─ 六、个人中心
   │
   ├─ 6.1 个人资料（查看资料、编辑资料）
   │
   ├─ 6.2 密码管理（修改密码、忘记密码）
   │
   └─ 6.3 签名管理
      ├─ 签名设置（上传签名、手写绘制、选择字体、签名预览、申请审核、查看状态）
      └─ 签名记录
```
