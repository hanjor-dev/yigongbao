# 打印信息填写方案（指令单录入）

**版本**：v2.1  
**日期**：2026-04-17  
**状态**：待审查

---

## 一、核心定位

**打印信息填写页面 = 指令单数据录入表单**。

- 入口：每个数据包独立一个填写页，一个数据包对应一张指令单
- 填写完成后，设计师点击"生成指令单"即可直接输出 Excel
- 页面数据保存在 `design_product`（产品行）+ `design_product_file`（文件关联）两张表

---

## 二、页面结构

页面分为三个区块，从上到下依次：

```
┌────────────────────────────────────────────────────────────────────────┐
│  【一】基本信息（只读，自动带出）                                       │
├────────────────────────────────────────────────────────────────────────┤
│  【二】其他打印信息（部分只读，产品标识必填）                           │
├────────────────────────────────────────────────────────────────────────┤
│  【三】生产产品信息（动态行，可增删）                                   │
│                                              [保存] [生成指令单]        │
└────────────────────────────────────────────────────────────────────────┘
```

## 三、各区块详细设计

### 3.1 基本信息（只读）

自动从订单和数据包带出，设计师不可编辑：

```
┌─────────────────────────────────────────────────────────────────────┐
│  基本信息                                                            │
│                                                                     │
│  订单编号   ORD-20260417000001      客户（医院） 北京协和医院        │
│  数据包编号 ORD-20260417000001-1    联系人       张医生              │
│  预交货时间 2026-05-01                                               │
└─────────────────────────────────────────────────────────────────────┘
```

字段来源：

| 字段 | 来源 |
|---|---|
| 订单编号 | `order_main.order_code` |
| 数据包编号 | `design_package.package_code` |
| 客户（医院） | `order_main.hospital_name` |
| 联系人 | `order_main.doctor_name` |
| 预交货时间 | `order_main.expected_delivery_date` |

### 3.2 其他打印信息

```
┌─────────────────────────────────────────────────────────────────────┐
│  其他打印信息                                                        │
│                                                                     │
│  * 产品标识  [________________]   患者姓名    张三（只读）           │
│                                                                     │
│  包装数量    [    ]               是否邮寄    是（只读）             │
│                                                                     │
│  邮寄地址   北京市xxx（只读）                                        │
│                                                                     │
│  备注       [________________________________]                      │
└─────────────────────────────────────────────────────────────────────┘
```

字段说明：

| 字段 | 来源 | 是否可编辑 |
|---|---|---|
| * 产品标识 | 无默认值 | **必填，手动输入** |
| 包装数量 | 无默认值 | 选填，手动输入，数据包级别的统计值 |
| 患者姓名 | `order_main.patient_name` | 只读 |
| 是否邮寄 | `order_main.is_postal` | 只读 |
| 邮寄地址 | `order_main.postal_address` | 只读 |
| 备注 | 无默认值 | 选填，手动输入 |

> 产品标识对应指令单中的"产品标识"列，是该数据包所有产品共用的一个标识值（如 LGC），必须手动填写。

### 3.3 生产产品信息（动态行）

默认展示 1 行，点击"添加"新增行，每行独立可删除：

```
┌─────────────────────────────────────────────────────────────────────┐
│  生产产品信息                                                        │
│                                                                     │
│  ┌── 产品行 1 ──────────────────────────────────────────────────┐   │
│  │                                                              │   │
│  │  * 产品名称  [分类▼] [该分类下产品▼]   * 型号规格  [规格▼]   │   │
│  │                                                              │   │
│  │  * 材质      [树脂▼]                   * 颜色      [白色▼]   │   │
│  │                                                              │   │
│  │  * 时效      [普通▼ / 加急▼]           * 注册证号  自动带出  │   │
│  │                                                              │   │
│  │  * 数量      [1    ]                   * 数据文件  [选择▼]   │   │
│  │                                                              │   │
│  │  [添加]  [保存]  [删除]                                      │   │
│  └──────────────────────────────────────────────────────────────┘   │
│                                                                     │
│  ┌── 产品行 2 ──────────────────────────────────────────────────┐   │
│  │  ...（同上）                                        [删除]    │   │
│  └──────────────────────────────────────────────────────────────┘   │
│                                                                     │
│                                           [保存全部]  [生成指令单]  │
└─────────────────────────────────────────────────────────────────────┘
```

#### 每行字段说明

| 字段 | 类型 | 规则 |
|---|---|---|
| * 产品分类 | 下拉（一级） | 来自产品大类字典（dict_code=17）：17.1 模型类 / 17.2 导板类 / 17.3 假体类，由字典动态维护，选后过滤产品列表和颜色范围 |
| * 产品名称 | 下拉（二级） | 根据分类过滤（product.category 与字典码对应），从产品库选择 |
| * 型号规格 | 下拉 | 根据产品联动，仅显示该产品下有效规格 |
| * 注册证号 | 只读文本 | 选规格后自动带出，不可编辑 |
| * 时效 | 下拉 | 固定选项：普通 / 加急；**默认值从订单 `is_urgent` 字段带出**（加急订单默认选"加急"），允许修改；最终提交值用于指令单时效列，加急时该列加粗 |
| * 材质 | 下拉 | 来自材质字典（dict_code=15），默认树脂（15.1），可修改，不按分类过滤 |
| * 颜色 | 下拉 | 根据产品分类过滤：模型类（17.1）→ 白色（16.1）；导板类（17.2）→ 透明（16.2）；假体类（17.3）→ 不限 |
| * 数量 | 数字输入 | 该产品生产件数，最小值 1 |
| * 数据文件 | 多选弹窗 | 列出该数据包内所有文件，至少选 1 个 |

#### 联动规则

```
选择产品分类（dict_code=17）
  └─→ 产品列表：只显示 product.category 匹配该分类的产品
  └─→ 颜色范围：17.1 模型类 → 16.1 白色；17.2 导板类 → 16.2 透明；17.3 假体类 → 不限

选择产品
  └─→ 规格列表：只显示该产品下有效规格

选择规格
  └─→ 注册证号：自动填入，只读

页面加载时
  └─→ 时效默认值：订单 is_urgent=1 → 默认"加急"；is_urgent=0 → 默认"普通"
```

#### 数据文件选择弹窗

点击"选择"按钮弹出：

```
┌─────────────────────────────────────────────────┐
│  选择数据文件                               [×]  │
│  ─────────────────────────────────────────────  │
│  ☑ 左髋骨.stl              2.3 MB               │
│  ☑ 右髋骨.stl              1.8 MB               │
│  ☐ 导板A.stl               0.5 MB               │
│  ☐ 导板B.stl               0.6 MB               │
│  ─────────────────────────────────────────────  │
│                      [取消]    [确认]            │
└─────────────────────────────────────────────────┘
```

- 列出当前数据包解压后的所有文件
- 支持多选，至少选 1 个
- 文件可跨行复用（同一文件可出现在多个产品行）

## 四、操作按钮说明

| 按钮 | 位置 | 行为 |
|---|---|---|
| 添加 | 每行底部 | 在当前行下方新增一个空白产品行 |

## 五、数据模型

### 5.1 `design_product` 表（改造）

移除 `package_file_id`、`package_file_name`，产品标识和备注从单行字段提升至数据包级别：

> 注意：`product_mark`（产品标识）和 `remark`（备注）是整个数据包共用的，不属于某一产品行，应存储在 `design_package` 表中（新增两个字段），而不是 `design_product`。

**`design_package` 新增字段：**

```sql
product_mark   VARCHAR(100)  COMMENT '产品标识（必填，数据包级别）',
pack_quantity  INT           COMMENT '包装数量（统计值，数据包级别）',
remark         VARCHAR(500)  COMMENT '备注',
```

**`design_product` 字段（改造后）：**

```sql
id              BIGINT        NOT NULL AUTO_INCREMENT,
order_id        BIGINT        NOT NULL  COMMENT '订单ID',
package_id      BIGINT        NOT NULL  COMMENT '数据包ID',
product_id      BIGINT        NOT NULL  COMMENT '产品ID',
product_name    VARCHAR(100)            COMMENT '产品名称（冗余）',
spec_id         BIGINT        NOT NULL  COMMENT '规格ID',
spec_name       VARCHAR(100)            COMMENT '规格名称（冗余）',
cert_no         VARCHAR(100)            COMMENT '注册证号（自动填充）',
material_id     VARCHAR(50)             COMMENT '材质字典码',
material_name   VARCHAR(50)             COMMENT '材质名称（冗余）',
color_id        VARCHAR(50)             COMMENT '颜色字典码',
color_name      VARCHAR(50)             COMMENT '颜色名称（冗余）',
is_urgent       TINYINT       DEFAULT 0 COMMENT '是否加急（0=普通，1=加急），默认从订单带出，可修改',
quantity        INT           NOT NULL  COMMENT '该产品生产数量',
sort_order      INT           DEFAULT 0 COMMENT '排序',
```

> **说明**：
> - `timeliness` 字段废弃，改用 `is_urgent` 整型存储，与订单 `order_main.is_urgent` 语义一致，避免自由文本带来的不确定性
> - `pack_quantity`（包装数量）提升至数据包级别，存入 `design_package`，由设计师在"其他打印信息"区块单独填写
> - 指令单生成时，时效列文字："0→普通，1→加急"；加急时该列加粗

### 5.2 `design_product_file` 表（新增）

```sql
CREATE TABLE design_product_file (
    id                  BIGINT        NOT NULL AUTO_INCREMENT,
    design_product_id   BIGINT        NOT NULL  COMMENT '关联 design_product.id',
    package_file_id     BIGINT        NOT NULL  COMMENT '关联 design_package_file.id',
    package_file_name   VARCHAR(200)            COMMENT '文件名（冗余）',
    sort_order          INT           DEFAULT 0,
    is_deleted          TINYINT       DEFAULT 0,
    create_time         DATETIME,
    PRIMARY KEY (id),
    KEY idx_dpf_product (design_product_id)
) COMMENT='打印产品关联文件';
```

### 5.3 表关系

```
design_package（数据包，存产品标识/备注）
    │ package_id
    ▼
design_product（产品行，每行=一个产品+规格）
    │ design_product_id
    ▼
design_product_file（文件关联，每行=一个模型文件）
    │ package_file_id
    ▼
design_package_file（数据包内的实际文件）
```

## 六、指令单生成逻辑

生成时从 `design_product` JOIN `design_product_file` 展开：

- **每个关联文件 = 指令单的一行**
- 同一产品行的所有字段（产品名、规格、材质、颜色、数量等）在所有文件行中重复填写
- `product_mark`、`remark` 从 `design_package` 读取

示例（1个产品行，关联2个文件）：

| 序号 | 注册证号 | 产品名称 | 数据文件名 | 规格 | 材质 | 数量 | 时效 | 颜色 |
|---|---|---|---|---|---|---|---|---|
| 1 | xxx | 骨模型 | 左髋骨 | 规格A | 树脂 | 1 | 加急 | 白色 |
| 2 | xxx | 骨模型 | 右髋骨 | 规格A | 树脂 | 1 | 加急 | 白色 |

## 八、已确认说明

| 问题 | 结论 |
|---|---|
| 产品大类字典值 | `dict_code=17`：17.1 模型类 / 17.2 导板类 / 17.3 假体类，字典动态维护，颜色过滤按此分类执行 |
| 时效字段 | 改为 `is_urgent` 整型（0=普通，1=加急），默认从订单带出，允许修改；指令单生成时以提交值为准，加急加粗 |
| 包装数量 | 数据包级别字段（非产品行），存入 `design_package`，在"其他打印信息"区块填写；产品行的"数量"= 该产品生产件数 |
