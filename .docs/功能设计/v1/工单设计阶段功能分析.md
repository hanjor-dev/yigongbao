# 工单设计阶段功能分析

> **文档说明**：基于《业务流程_工单设计v2.md》需求文档，进行功能设计分析。
> **版本**：v1.0 | **创建日期**：2026-04-14

---

## 一、功能模块概览

```
工单设计模块
├── 1. 工单列表（设计师视角）
├── 2. 工单详情/设计工作台
│     ├── 2.1 订单信息展示
│     ├── 2.2 设计文件管理
│     │     ├── 打印文件数据包上传/解析
│     │     ├── 可视化模型文件上传
│     │     └── 设计报告上传
│     ├── 2.3 打印信息填写
│     ├── 2.4 指令单/图纸生成与管理
│     └── 2.5 设计提交
├── 3. 设计审核
│     ├── 3.1 审核列表
│     └── 3.2 审核操作
└── 4. 客户确认（不需要实体交付订单）
```

---

## 二、页面规划

### 2.1 页面清单

| 页面 | 路由（建议） | 使用角色 | 说明 |
|------|-------------|----------|------|
| 我的工单列表 | `/design/workorder/list` | 设计师 | 查看待处理、处理中的工单 |
| 工单设计工作台 | `/design/workorder/detail/:orderId` | 设计师 | 订单详情 + 设计操作主页面 |
| 设计审核列表 | `/design/review/list` | 设计管理员、业务管理员 | 待审核工单列表 |
| 设计审核详情 | `/design/review/detail/:orderId` | 设计管理员、业务管理员 | 审核操作页面 |
| 客户确认列表 | `/order/confirm/list` | 业务员 | 待确认订单列表（复用订单模块） |

### 3.1 工单列表接口

#### 3.1.1 查询我的工单列表

**接口**：`POST /api/design/workorder/list`

**权限**：设计师

```json
  "status": 2010,           // 可选，状态筛选：2010待设计/2020设计中/2060审核不通过

  "pageSize": 20
```

### 3.3 状态流转接口

#### 3.3.1 开始设计

**接口**：`POST /api/design/workorder/{orderId}/start`

**权限**：设计师（仅限自己的待设计工单）

**前置条件**：订单状态为 `2010 待设计`

**请求参数**：无

**响应**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "orderId": 1001,
    "status": 2020,
    "statusName": "设计中",
    "designStartTime": "2026-04-14 10:30:00"
  }
}
```

**系统行为**：
- 状态变更：2010 → 2020
- 记录 `design_start_time`

---

#### 3.3.2 继续修改（驳回后）

**接口**：`POST /api/design/workorder/{orderId}/continue`

**权限**：设计师（仅限自己的审核不通过工单）

**前置条件**：订单状态为 `2060 设计审核不通过`

**请求参数**：无

**响应**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "orderId": 1001,
    "status": 2020,
    "statusName": "设计中"
  }
}
```

**系统行为**：
- 状态变更：2060 → 2020

---

#### 3.3.3 提交设计

**接口**：`POST /api/design/workorder/{orderId}/submit`

**权限**：设计师（仅限自己的设计中工单）

**前置条件**：
- 订单状态为 `2020 设计中`
- 通过所有提交校验

**请求参数**：无

**响应**：
```json
{
  "code": 200,
  "message": "提交成功",
  "data": {
    "orderId": 1001,
    "status": 2040,
    "statusName": "设计审核中",
    "designSubmitTime": "2026-04-14 16:00:00"
  }
}
```

**错误响应**（校验不通过）：
```json
{
  "code": 400,
  "message": "提交失败，请完成以下项目",
  "data": {
    "failedItems": [
      "修订版指令单已上传",
      "修订版图纸已上传"
    ]
  }
}
```

**系统行为**：
- 状态变更：2020 → 2040
- 记录 `design_submit_time`
- 创建审核任务，通知审核人员

#### 3.7.2 获取审核详情

**接口**：`GET /api/design/review/{orderId}`

**权限**：设计管理员、业务管理员、系统管理员

**响应**：与工单详情接口结构相同，增加审核历史记录：
```json
{
  "code": 200,
  "data": {
    "orderInfo": { ... },
    "rebuildItems": [ ... ],
    "designPackages": [ ... ],
    "visualModels": [ ... ],
    "designReport": { ... },
    "reviewHistory": [

        "reviewerId": 100,

        "comment": null,               // 审批意见（通过时）
        "rejectReason": "图纸标注不清晰",  // 驳回原因（驳回时）
        "reviewTime": "2026-04-14 17:00:00"
      }
    ]
  }
```

#### 3.7.3 审核通过

**接口**：`POST /api/design/review/{orderId}/pass`

**权限**：设计管理员、业务管理员、系统管理员

**前置条件**：订单状态为 `2040 设计审核中`

**请求参数**：
```json
{
  "comment": "设计方案符合要求"    // 审批意见，选填
}
```

**响应**：
```json
{
  "code": 200,
  "message": "审核通过",
  "data": {
    "orderId": 1001,
    "status": 3010,                // 或 7010
    "statusName": "待打印",        // 或 "待客户确认"
    "nextStep": "production"       // production 或 confirm
  }
}
```

**系统行为**：
- 状态变更：2040 → 2050（内部）→ 3010 或 7010
- 根据 `needsPhysicalDelivery` 决定下一状态
- 记录审核信息

---

#### 3.7.4 审核驳回

**接口**：`POST /api/design/review/{orderId}/reject`

**权限**：设计管理员、业务管理员、系统管理员

**前置条件**：订单状态为 `2040 设计审核中`

**请求参数**：
```json
{
  "rejectReason": "图纸标注不清晰，请补充完善"    // 必填
}
```

**响应**：
```json
{
  "code": 200,
  "message": "已驳回",
  "data": {
    "orderId": 1001,
    "status": 2060,
    "statusName": "设计审核不通过"
  }
}
```

**系统行为**：
- 状态变更：2040 → 2060
- 记录驳回原因
- 通知设计师

### 7.2 关键交互说明

1. **打印信息-打印模型多选**

   - 显示当前数据包内的所有文件
   - 已被其他行选择的文件标记为「已选择」（可重复选择同一文件）

2. **指令单/图纸生成**

   - 所有校验项通过后「提交设计」按钮可用
   - 点击未通过项可快速跳转到对应功能区域
