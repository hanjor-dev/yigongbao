```java
// UTF-8 失败 fallback GBK（L93-106）
try {
    return parseZipWithCharset(zipBytes, UTF_8, ...);
} catch (IllegalArgumentException e) {
    log.warn("ZIP 文件名 UTF-8 解码失败，尝试 GBK 编码重新解析");
    return parseZipWithCharset(zipBytes, GBK, ...);
}
```
- ✅ 影响：ZIP 压缩包文件名解析
- ✅ 兼容性：支持 Windows 和标准 ZIP

**修改 3：DesignFileServiceImpl.java**
```java
// 临时文件流式处理（L102-189）
File tempFile = Files.createTempFile("design_pkg_", fileExt).toFile();
try {
    file.getInputStream().transferTo(new FileOutputStream(tempFile));
    ArchiveParserUtil.parse(new FileInputStream(tempFile), ...);
    fileService.uploadStream(new FileInputStream(tempFile), ...);
} finally {
    FileUtil.del(tempFile);
}
```
- ✅ 影响：设计数据包上传
- ✅ 内存优化：500MB 压缩包从占堆 500MB → <10MB
- ✅ 清理机制：finally 块保证临时文件删除

**修改 4-6：FileService 流式上传支持**

- ✅ 影响：新增功能，不影响现有接口

**修改 7：docker-compose.prod.yml**
