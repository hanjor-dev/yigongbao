# 医院科室功能实现方案

## 5.1 设计目标

独立科室表，与医院无关，作为通用字典供订单等业务模块使用。

## 5.2 表结构

```sql
CREATE TABLE hospital_dept (
    id                   BIGINT          NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    hospital_dept_code   VARCHAR(32)     NOT NULL COMMENT '科室编码（系统唯一）',
    hospital_dept_name   VARCHAR(100)   NOT NULL COMMENT '科室名称',
    sort                 INT             DEFAULT 0 COMMENT '排序',
    status               TINYINT         DEFAULT 1 COMMENT '状态（0=禁用，1=正常）',
    remark               VARCHAR(512)    COMMENT '备注',
    create_time          DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time          DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    is_deleted           TINYINT         DEFAULT 0 COMMENT '是否删除',
    PRIMARY KEY (id),
    UNIQUE KEY uk_hospital_dept_code (hospital_dept_code),
    KEY idx_hospital_dept_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='医院科室表';
```

## 5.3 代码结构

遵循标准分层结构，位于 `basic/hospitalDept` 子模块：

```
basic/hospitalDept/
├── controller/HospitalDeptController.java
├── service/HospitalDeptService.java
├── service/impl/HospitalDeptServiceImpl.java
├── mapper/HospitalDeptMapper.java
├── entity/HospitalDeptEntity.java
├── dto/CreateHospitalDeptDTO.java, UpdateHospitalDeptDTO.java
├── vo/HospitalDeptVO.java
└── convert/HospitalDeptConvert.java
```

## 5.4 编码生成

科室编码由系统自动生成，规则：`HDEPT-XXX`（序号每日递增）。

## 5.5 错误码扩展

```java
DEPT_NOT_FOUND(690, "科室不存在"),
DEPT_EXISTS(691, "科室名称已存在"),
DEPT_HAS_DOCTORS(692, "该科室下存在医生，无法删除");
```
