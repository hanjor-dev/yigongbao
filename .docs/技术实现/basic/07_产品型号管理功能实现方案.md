# 产品型号管理功能实现方案

## 7.1 设计目标

产品型号管理，关联注册证、材质、颜色等信息，支持级联下拉查询。

## 7.2 表结构

```sql
CREATE TABLE product (
    id              BIGINT          NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    product_code    VARCHAR(64)     NOT NULL COMMENT '产品型号编码',
    product_name    VARCHAR(128)    NOT NULL COMMENT '产品名称',
    category        VARCHAR(64)     COMMENT '产品分类（如：髋关节、膝关节、脊柱）',
    spec            VARCHAR(128)    COMMENT '规格',
    cert_id         BIGINT          COMMENT '关联注册证ID（关联registration_cert）',
    material        VARCHAR(128)    COMMENT '材质',
    color_options   VARCHAR(512)    COMMENT '可选颜色（JSON数组）',
    price           DECIMAL(10,2)   COMMENT '标准价格',
    image_url       VARCHAR(512)    COMMENT '产品图片URL',
    status          TINYINT        DEFAULT 1 COMMENT '状态（0=禁用，1=正常）',
    remark          VARCHAR(512)    COMMENT '备注',
    create_time     DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time     DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    is_deleted      TINYINT        DEFAULT 0 COMMENT '是否删除',
    PRIMARY KEY (id),
    UNIQUE KEY uk_product_code (product_code),
    KEY idx_product_category (category),
    KEY idx_product_cert (cert_id),
    KEY idx_product_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='产品型号表';
```

```
├── dto/CreateProductDTO.java, UpdateProductDTO.java
├── vo/ProductVO.java, ProductDetailVO.java
└── convert/ProductConvert.java
```

## 7.4 级联查询接口

```java
/**
 * 获取产品详情（含注册证信息）
 */
ProductDetailVO getDetailById(Long productId);

/**
 * 按注册证查询可选产品
 */
List<ProductVO> listByCertId(Long certId);

/**
 * 按分类查询产品
 */
List<ProductVO> listByCategory(String category);
```
