# 医生管理功能实现方案

## 6.1 设计目标

独立医生表，关联业务员（创建人）和医院，支持：
- 业务员在创建订单时快速添加新医生（同时保存到医生表）
- 业务员选择医院后，自动带出历史在该医院输入的医生列表

## 6.2 表结构

```sql
CREATE TABLE doctor (
    id                BIGINT          NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    doctor_name       VARCHAR(64)     NOT NULL COMMENT '医生姓名',
    doctor_phone      VARCHAR(32)     COMMENT '医生电话',
    hospital_id       BIGINT          COMMENT '所属医院ID',
    hospital_dept_id  BIGINT          COMMENT '所属医院科室ID（关联hospital_dept）',
    creator_id        BIGINT          COMMENT '创建该医生记录的业务员ID',
    order_count       INT             DEFAULT 0 COMMENT '关联订单数量',
    status            TINYINT         DEFAULT 1 COMMENT '状态（0=禁用，1=正常）',
    remark            VARCHAR(512)    COMMENT '备注',
    create_time       DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time       DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    is_deleted        TINYINT         DEFAULT 0 COMMENT '是否删除',
    PRIMARY KEY (id),
    KEY idx_doctor_hospital (hospital_id),
    KEY idx_doctor_hospital_dept (hospital_dept_id),
    KEY idx_doctor_creator (creator_id),
    KEY idx_doctor_name (doctor_name)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='医生表';
```

## 6.4 核心功能

### 6.4.1 医生联想（核心功能）

```java
/**
 * 获取业务员在医院下的历史医生列表
 * 用于订单创建时，医生下拉联想
 *
 * @param userId 业务员ID
 * @param hospitalId 医院ID
 * @param keyword 搜索关键词（可选）
 * @return 按使用频率排序的医生列表
 */
List<DoctorVO> listByCreatorAndHospital(Long userId, Long hospitalId, String keyword);
```

**SQL 查询逻辑**：

```sql
-- 查询该业务员在该医院下使用过的医生（历史订单中出现的医生）
SELECT d.*, COUNT(o.id) as order_count
FROM doctor d
LEFT JOIN erp_order o ON o.doctor_name = d.doctor_name AND o.hospital_id = d.hospital_id
WHERE d.creator_id = #{userId}
  AND d.hospital_id = #{hospitalId}
  AND (#{keyword} IS NULL OR d.doctor_name LIKE CONCAT('%', #{keyword}, '%'))
GROUP BY d.id
ORDER BY order_count DESC, d.create_time DESC
LIMIT 20
```

### 6.4.2 快速添加医生

```java
/**
 * 快速添加医生（订单创建时调用）

 * @param dto 快速添加参数
 * @param creatorId 创建业务员ID
 * @return 医生信息
```
