## 一、文档概述

### 1.1 文档目的

本文档描述医工宝订单模块「订单信息修改申请审核」功能的技术实现方案，详细涵盖数据库设计、接口设计、业务流程、代码结构、错误码设计等内容。

### 1.2 功能概述

| 项目 | 说明 |
|------|------|
| 功能名称 | 订单信息修改申请审核 |
| 功能分类 | 订单管理 > 修改申请 |
| 需求来源 | `.docs/需求分析/v1/业务流程1_订单创建.md` 第4.6章节 |
| 核心流程 | 业务员发起申请 → 管理员审核 → 审核通过后允许修改 → 系统留痕 |
| 实现状态 | 待实施 |

### 1.3 业务规则总结

以下业务规则经需求澄清确认，作为设计方案的前提约束：

| 规则项 | 业务决策 |
|------|------|
| 功能开关 | 默认强制开启，无需配置开关 |
| 允许发起的阶段 | **仅订单阶段（phase=1）和设计阶段（phase=2）**可发起修改申请 |
| 阶段与类型限制 | 订单阶段：可申请基础信息、影像文件、重建项目；设计阶段：**仅可申请重建项目** |
| 类型允许字段 | 通过 `sys_config` 动态配置，管理员可调整 |
| 申请类型选择 | 支持多选，如同时申请修改「基础信息」和「重建项目」 |
| 审批粒度 | 必须全部审批，一次性通过/拒绝整个申请，不支持部分审批 |
| 并发控制 | 每个订单同时只能有1个有效申请（有待审核申请时不允许再发起） |
| 修改留痕 | 每次字段变更必须记录（修改字段/修改前值/修改后值/修改人/修改时间），永久留存 |
| 查询权限 | 由权限配置控制，业务层不关心具体权限判断 |
| 申请编号 | 直接使用主键ID，无需单独编码规则 |

## 二、数据库设计

### 2.1 数据库表总览

| 序号 | 表名 | 说明 | 优先级 |
|------|------|------|--------|
| 1 | `order_modify_apply` | 订单修改申请表 | P0 |

| 4 | `sys_config` 配置记录 | 字段配置 | P0 |

### 2.2 订单修改申请表（order_modify_apply）

```sql
CREATE TABLE `order_modify_apply` (
    `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `order_id` BIGINT NOT NULL COMMENT '订单ID',
    `order_code` VARCHAR(50) NOT NULL COMMENT '订单编号（冗余，便于查询）',

    -- 申请类型：多选时逗号分隔字典编码，如 "14.1,14.3"
    `apply_type_codes` VARCHAR(50) NOT NULL COMMENT '申请类型字典编码（逗号分隔，如 14.1,14.3）',
    `apply_type_names` VARCHAR(200) COMMENT '申请类型中文名称冗余（如 基础信息、重建项目）',
    `apply_reason` TEXT COMMENT '申请原因',

    -- 审核信息
    `status` VARCHAR(20) NOT NULL DEFAULT 'PENDING' COMMENT '状态：PENDING-待审核，APPROVED-已同意，REJECTED-已拒绝',
    `reject_reason` TEXT COMMENT '驳回原因（审核不通过时必填）',

    -- 操作人
    `applicant_id` BIGINT NOT NULL COMMENT '申请人ID',
    `applicant_name` VARCHAR(100) COMMENT '申请人姓名',
    `auditor_id` BIGINT COMMENT '审核人ID',
    `auditor_name` VARCHAR(100) COMMENT '审核人姓名',
    `audit_time` DATETIME COMMENT '审核时间',

    -- 公共字段
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
    `update_time` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    `create_by` BIGINT,
    `update_by` BIGINT,
    `is_deleted` TINYINT DEFAULT 0,

    PRIMARY KEY (`id`),
    KEY `idx_order_modify_apply_order_id` (`order_id`),
    KEY `idx_order_modify_apply_applicant_id` (`applicant_id`),
    KEY `idx_order_modify_apply_status` (`status`),
    KEY `idx_order_modify_apply_create_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单信息修改申请表';

-- 并发控制：同一订单只能有1个 PENDING 申请
-- MySQL 8.0+ 函数索引，is_deleted=1 时返回 NULL，不触发唯一约束
CREATE UNIQUE INDEX uk_order_modify_apply_pending
    ON order_modify_apply ((CASE WHEN is_deleted = 0 AND status = 'PENDING' THEN order_id ELSE NULL END));
```

**设计要点**：

1. **移除 apply_code 字段**：申请编号直接使用主键ID，无需单独编码规则，简化设计
2. **apply_type 字段拆分**：`apply_type_codes VARCHAR(50)` 存储逗号分隔的字典编码（如 `"14.1,14.3"`），`apply_type_names VARCHAR(200)` 存储冗余中文名（如 `"基础信息、重建项目"`）便于查询展示；VARCHAR(50) 最长存储 `"14.1,14.2,14.3"` = 11字符，充裕
3. **并发控制函数索引**：`uk_order_modify_apply_pending` 使用 MySQL 8 表达式索引（CREATE TABLE 后追加），保证同一订单同一时间只有一条 PENDING 状态的记录，从数据库层面彻底解决并发问题
4. `is_deleted` 逻辑删除，撤回申请时标记删除
5. 公共字段（`create_time`、`update_time`、`create_by`、`update_by`、`is_deleted`）由 MyBatis-Plus 自动填充

### 2.3 订单修改留痕表（order_modification_log）

```sql
CREATE TABLE `order_modification_log` (
    `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    `order_id` BIGINT NOT NULL COMMENT '订单ID',
    `order_code` VARCHAR(50) NOT NULL COMMENT '订单编号（冗余）',
    `apply_id` BIGINT COMMENT '关联的修改申请ID',

    -- 修改字段信息
    `field_name` VARCHAR(50) NOT NULL COMMENT '修改字段名称（如 patient_name）',
    `field_label` VARCHAR(100) COMMENT '修改字段中文名（如"患者姓名"）',
    `old_value` TEXT COMMENT '修改前的值',
    `new_value` TEXT COMMENT '修改后的值',

    -- 操作人
    `modifier_id` BIGINT NOT NULL COMMENT '修改人ID',
    `modifier_name` VARCHAR(100) COMMENT '修改人姓名',

    -- 公共字段（仅 create_time）
    `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,

    PRIMARY KEY (`id`),
    KEY `idx_order_modification_log_order_id` (`order_id`),
    KEY `idx_order_modification_log_apply_id` (`apply_id`),
    KEY `idx_order_modification_log_create_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='订单信息修改留痕表';
```

**设计要点**：

1. 每条留痕记录对应一个字段的一次变更（1对1关系）
2. `old_value` 和 `new_value` 使用 TEXT 类型，支持长文本
3. `apply_id` 可为空（未来扩展用）
4. **不继承 BaseEntity**：留痕表为永久不可变审计记录，无软删除、无 `update_time`，仅自动填充 `create_time`
5. 永久留存，不设过期策略

### 2.4 索引命名规范

> **重要**：所有索引使用表名前缀，避免多表索引名冲突；唯一性约束使用 MySQL 8 动态表达式索引解决软删除下的唯一性问题

| 表名 | 索引前缀 | 示例 |
|------|---------|------|
| `order_modify_apply` | `idx_order_modify_apply_` | `idx_order_modify_apply_order_id` |
| `order_modification_log` | `idx_order_modification_log_` | `idx_order_modification_log_order_id` |

## 四、枚举定义

### 4.1 申请类型枚举（ModifyApplyTypeEnum）

```java
/**
 * 订单修改申请类型枚举
 * 对应 order_modify_apply.apply_type_codes 字段，存储字典编码
 * 字典编码：14.1（基础信息）/ 14.2（影像文件）/ 14.3（重建项目），对应 sys_dict group=14
 *
 * @author hanjor
 * @date 2026-04-08
 */
@Getter
@AllArgsConstructor
public enum ModifyApplyTypeEnum {

    INFO("14.1", "基础信息"),
    IMAGE("14.2", "影像文件"),
    ITEM("14.3", "重建项目");

    /**
     * 字典编码（存储到数据库和前端显示的值，对应 sys_dict.dict_code）
     */
    private final String dictCode;

    /**
     * 类型名称（中文描述）
     */
    private final String name;

    /**
     * 根据字典编码获取枚举
     */
    public static ModifyApplyTypeEnum getByDictCode(String dictCode) {
        if (dictCode == null) {
            return null;
        }
        for (ModifyApplyTypeEnum type : values()) {
            if (type.getDictCode().equals(dictCode)) {
                return type;
            }
        }
        return null;
    }

    /**
     * 将逗号分隔的字典编码转换为中文描述（顿号连接）
     * 例如："14.1,14.3" → "基础信息、重建项目"
     */
    public static String toNamesText(String dictCodes) {
        if (dictCodes == null || dictCodes.isBlank()) {
            return "";
        }
        return Arrays.stream(dictCodes.split(","))
                .map(String::trim)
                .map(ModifyApplyTypeEnum::getByDictCode)
                .filter(Objects::nonNull)
                .map(ModifyApplyTypeEnum::getName)
                .collect(Collectors.joining("、"));
    }
}
```

| 设计阶段类型限制 | ORDER_MODIFY_TYPE_NOT_ALLOWED_IN_PHASE(722) | phase=2 时只能申请 item 类型 |
| 同一订单无待审核申请 | ORDER_MODIFY_APPLY_EXISTS(715) | 已有待审核申请 |
| 申请类型在字典中有效 | PARAM_ERROR(400) | 存在无效的申请类型 |

```java
/**
 * 校验申请类型是否在当前阶段允许
 */
private void validateTypeInPhase(OrderMainEntity order, String applyTypes) {
    Integer phase = order.getPhase();

    if (FlowPhaseEnum.ORDER.getValue().equals(phase)) {
        // 订单阶段：允许所有类型（14.1 / 14.2 / 14.3）
        return;
    }

    if (FlowPhaseEnum.DESIGN.getValue().equals(phase)) {
        // 设计阶段：仅允许 14.3（重建项目）
        for (String type : applyTypes.split(",")) {
            ModifyApplyTypeEnum typeEnum = ModifyApplyTypeEnum.getByDictCode(type.trim());
            if (typeEnum != null && typeEnum != ModifyApplyTypeEnum.ITEM) {
                log.warn("设计阶段不允许申请类型：{}", type);
                throw new BusinessException(ErrorCodeEnum.ORDER_MODIFY_TYPE_NOT_ALLOWED_IN_PHASE);
            }
        }
        return;
    }

    // 其他阶段不允许发起申请
    throw new BusinessException(ErrorCodeEnum.ORDER_NOT_APPLICABLE_STATUS);
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | String | ✅ | APPROVE（同意）/ REJECT（拒绝） |
| rejectReason | String | 拒绝时必填 | 驳回原因 |

**审核权限判断**：由 `@RequirePermission` 注解或 Service 层调用权限服务校验。业务层不硬编码角色判断。

**响应**：

### 10.10 执行订单修改

#### PUT /api/order/{id}/modification

> **重要**：此接口专门用于审核通过后的修改，与原有的 `PUT /api/order/{id}`（草稿阶段直接更新）完全独立。
> 设计模块也通过此接口执行修改申请通过后的订单变更。

**路径参数**：订单ID

**请求体**：

```json
{
  "applyId": 1,
  "patientName": "李四（更新）",
  "patientAge": 45,
  "isUrgent": 1,
  "expectedDeliveryDate": "2026-04-20T00:00:00",
  "items": [
    {
      "bodyPartId": 1,
      "projectId": 10,
      "projectDesc": "左腿膝关节",
      "formingRequirement": "高精度打印",
      "otherRequirement": ""
    }
  ]
}
```

**前置校验**：

| 校验项 | 错误码 | 说明 |
|--------|--------|------|
| 订单存在 | ORDER_NOT_FOUND(675) | 订单不存在 |
| 申请存在且状态为 APPROVED | ORDER_MODIFY_APPLY_STATUS_ERROR(704) | 申请状态不合法 |
| 订单与申请关联正确 | PARAM_ERROR(400) | 订单与申请不匹配 |
| 字段在申请允许范围内 | ORDER_MODIFY_FIELD_NOT_ALLOWED(716) | 字段不在申请范围内 |

**执行流程**：

```
1. 查 apply，校验 APPROVED，校验 apply.orderId == orderId
2. 解析 apply.applyTypes → allowedTypes Set
3. 从 sys_config 加载字段配置
4. IF info in allowedTypes AND dto 有标量字段：
   - 校验每个非空字段在 info 允许列表中
   - 保存 before 快照（oldValues Map）
   - fillAreaFromHospital() if hospitalId changed
   - orderMainMapper.updateById()
   - 逐字段记录留痕（显式对比）
5. IF item in allowedTypes AND dto.items != null：
   - 保存旧 items JSON（旧值逐项对比）
   - 逻辑删除旧 order_item 记录
   - validateAndFillItems()（复用校验逻辑）
   - 插入新 items
   - 逐项记录留痕（新增/修改/删除各有记录）
6. IF image in allowedTypes：
   - 逻辑删除旧的 imageData / imageReport 关联
   - 插入新的 order_file 记录
   - 各记录 1 条留痕（JSON 数组格式）
7. 事务提交
```

```java
     *
     * @param orderId 订单ID
     * @return 判断结果（包含 canApply、allowedTypes、reason）

    @Override
    public CanApplyModifyResult canApplyModify(Long orderId) {
        OrderMainEntity order = orderMainMapper.selectById(orderId);
        if (order == null) {
            return CanApplyModifyResult.no("ORDER_NOT_FOUND");
        }

        Integer phase = order.getPhase();
        if (!FlowPhaseEnum.ORDER.getValue().equals(phase)
                && !FlowPhaseEnum.DESIGN.getValue().equals(phase)) {
            return CanApplyModifyResult.no("PHASE_NOT_ALLOWED");
        }

        // 校验是否有待审核申请
        Long pendingCount = orderModifyApplyMapper.selectCount(
            new LambdaQueryWrapper<OrderModifyApplyEntity>()
                .eq(OrderModifyApplyEntity::getOrderId, orderId)
                .eq(OrderModifyApplyEntity::getStatus, ModifyApplyStatusEnum.PENDING.getCode())
                .eq(OrderModifyApplyEntity::getIsDeleted, 0)
        );
        if (pendingCount > 0) {
            return CanApplyModifyResult.no("PENDING_EXISTS");
        }

        // 获取允许的申请类型
        List<String> allowedTypes;
        if (FlowPhaseEnum.ORDER.getValue().equals(phase)) {
            allowedTypes = List.of(
                ModifyApplyTypeEnum.INFO.getDictCode(),
                ModifyApplyTypeEnum.IMAGE.getDictCode(),
                ModifyApplyTypeEnum.ITEM.getDictCode()
            );
        } else {
            // 设计阶段：仅允许 item（14.3）
            allowedTypes = List.of(ModifyApplyTypeEnum.ITEM.getDictCode());
        }

        return CanApplyModifyResult.yes(allowedTypes);
    }

    /**

    @Override
    @Transactional(rollbackFor = Exception.class)
    public ModifyApplyVO createApply(Long orderId, CreateModifyApplyDTO dto) {
        log.info("发起修改申请，orderId={}, applyTypes={}", orderId, dto.getApplyTypes());
        try {
            // 1. 校验订单
            OrderMainEntity order = orderMainMapper.selectById(orderId);
            if (order == null) {
                throw new BusinessException(ErrorCodeEnum.ORDER_NOT_FOUND);
            }

            // 2. 校验订单阶段适用修改申请
            Integer phase = order.getPhase();
            if (!FlowPhaseEnum.ORDER.getValue().equals(phase)
                    && !FlowPhaseEnum.DESIGN.getValue().equals(phase)) {
                throw new BusinessException(ErrorCodeEnum.ORDER_NOT_APPLICABLE_STATUS);
            }

            // 3. 校验阶段+类型联合限制
            validateTypeInPhase(phase, dto.getApplyTypes());

            // 4. 校验申请类型有效性（枚举校验，无需 DB 查询）
            validateApplyTypes(dto.getApplyTypes());

            // 5. 校验无待审核申请（应用层校验，函数索引作为数据库层兜底）
            validateNoPendingApply(orderId);

            // 6. 构建申请实体
            OrderModifyApplyEntity apply = new OrderModifyApplyEntity();
            apply.setOrderId(orderId);
            apply.setOrderCode(order.getOrderCode());
            apply.setApplyTypeCodes(dto.getApplyTypes());
            apply.setApplyTypeNames(ModifyApplyTypeEnum.toNamesText(dto.getApplyTypes()));
            apply.setApplyReason(dto.getApplyReason());
            apply.setStatus(ModifyApplyStatusEnum.PENDING.getCode());
            apply.setApplicantId(StpUtil.getLoginIdAsLong());
            apply.setApplicantName(getCurrentUserName());
            orderModifyApplyMapper.insert(apply);

            log.info("发起修改申请成功，applyId={}", apply.getId());
            return toApplyVO(apply);
        } catch (BusinessException e) {
            throw e;
        } catch (Exception e) {
            log.error("发起修改申请异常，orderId={}", orderId, e);
            throw e;
        }
    }

    /**
     * 校验申请类型是否在当前阶段允许
     */
    private void validateTypeInPhase(Integer phase, String applyTypes) {
        if (FlowPhaseEnum.DESIGN.getValue().equals(phase)) {
            // 设计阶段：只允许 14.3（重建项目）
            for (String type : applyTypes.split(",")) {
                ModifyApplyTypeEnum typeEnum = ModifyApplyTypeEnum.getByDictCode(type.trim());
                if (typeEnum != null && typeEnum != ModifyApplyTypeEnum.ITEM) {
                    log.warn("设计阶段不允许申请类型：{}", type);
                    throw new BusinessException(ErrorCodeEnum.ORDER_MODIFY_TYPE_NOT_ALLOWED_IN_PHASE);
                }
            }
        }
    }

    /**
     * 校验无待审核申请（应用层兜底）
     */
    private void validateNoPendingApply(Long orderId) {
        Long count = orderModifyApplyMapper.selectCount(
            new LambdaQueryWrapper<OrderModifyApplyEntity>()
                .eq(OrderModifyApplyEntity::getOrderId, orderId)
                .eq(OrderModifyApplyEntity::getStatus, ModifyApplyStatusEnum.PENDING.getCode())
                .eq(OrderModifyApplyEntity::getIsDeleted, 0)
        );
        if (count > 0) {
            log.warn("订单已有待审核申请，orderId={}", orderId);
            throw new BusinessException(ErrorCodeEnum.ORDER_MODIFY_APPLY_EXISTS);
        }
    }

    /**

    private void validateApplyTypes(String applyTypes) {

            throw new BusinessException(400, "申请类型不能为空");

            if (typeEnum == null) {
                throw new BusinessException(400, "存在无效的申请类型：" + type);
            }
        }
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public void auditApply(Long applyId, AuditModifyApplyDTO dto) {
        log.info("审核修改申请，applyId={}, action={}", applyId, dto.getAction());
        try {
            OrderModifyApplyEntity apply = orderModifyApplyMapper.selectById(applyId);
            if (apply == null) {
                throw new BusinessException(ErrorCodeEnum.ORDER_MODIFY_APPLY_NOT_FOUND);
            }
            if (!ModifyApplyStatusEnum.PENDING.getCode().equals(apply.getStatus())) {
                throw new BusinessException(ErrorCodeEnum.ORDER_MODIFY_APPLY_ALREADY_PROCESSED);
            }
            String action = dto.getAction().toUpperCase();
            if (!"APPROVE".equals(action) && !"REJECT".equals(action)) {
                throw new BusinessException(400, "审核操作无效：" + dto.getAction());
            }
            if ("REJECT".equals(action) && StrUtil.isBlank(dto.getRejectReason())) {
                throw new BusinessException(ErrorCodeEnum.ORDER_MODIFY_REJECT_REASON_REQUIRED);
            }

            Long auditorId = StpUtil.getLoginIdAsLong();
            String auditorName = getCurrentUserName();
            apply.setAuditorId(auditorId);
            apply.setAuditorName(auditorName);
            apply.setAuditTime(LocalDateTime.now());
            if ("APPROVE".equals(action)) {
                apply.setStatus(ModifyApplyStatusEnum.APPROVED.getCode());
            } else {
                apply.setStatus(ModifyApplyStatusEnum.REJECTED.getCode());
                apply.setRejectReason(dto.getRejectReason());
            }
            orderModifyApplyMapper.updateById(apply);
            log.info("审核修改申请成功，applyId={}, status={}", applyId, apply.getStatus());
        } catch (BusinessException e) {
            throw e;
        } catch (Exception e) {
            log.error("审核修改申请异常，applyId={}", applyId, e);
            throw e;
        }
    }

     *
     * @param orderId 订单ID
     * @param applyId 修改申请ID
     * @param dto     执行修改参数
     */
    @Override
    @Transactional(rollbackFor = Exception.class)
    public void executeModification(Long orderId, Long applyId, ExecuteModificationDTO dto) {
        log.info("执行订单修改，orderId={}, applyId={}", orderId, applyId);
        try {
            // 1. 校验申请
            OrderModifyApplyEntity apply = orderModifyApplyMapper.selectById(applyId);
            if (apply == null) {
                throw new BusinessException(ErrorCodeEnum.ORDER_MODIFY_APPLY_NOT_FOUND);
            }
            if (!ModifyApplyStatusEnum.APPROVED.getCode().equals(apply.getStatus())) {
                throw new BusinessException(ErrorCodeEnum.ORDER_MODIFY_APPLY_STATUS_ERROR);
            }
            if (!apply.getOrderId().equals(orderId)) {
                throw new BusinessException(400, "订单与申请不匹配");
            }

            // 2. 解析允许的申请类型
            Set<String> allowedTypes = new HashSet<>(Arrays.asList(apply.getApplyTypeCodes().split(",")));

            // 3. 加载字段配置
            ModifyApplyFieldConfigDTO config = loadFieldConfig();

            // 4. 获取订单实体
            OrderMainEntity order = orderMainMapper.selectById(orderId);
            if (order == null) {
                throw new BusinessException(ErrorCodeEnum.ORDER_NOT_FOUND);
            }

            // 5. 获取当前操作人
            Long modifierId = StpUtil.getLoginIdAsLong();
            String modifierName = getCurrentUserName();

            // 6. 处理 info 类型修改（14.1）
            if (allowedTypes.contains(ModifyApplyTypeEnum.INFO.getDictCode())) {
                processInfoModification(order, dto, applyId, modifierId, modifierName);
            }

            // 7. 处理 item 类型修改（14.3）
            if (allowedTypes.contains(ModifyApplyTypeEnum.ITEM.getDictCode()) && dto.getItems() != null) {
                processItemModification(order, dto, applyId, modifierId, modifierName);
            }

            // 8. 处理 image 类型修改（14.2）
            if (allowedTypes.contains(ModifyApplyTypeEnum.IMAGE.getDictCode())) {
                processImageModification(order, dto, applyId, modifierId, modifierName);
            }

            log.info("执行订单修改成功，orderId={}, applyId={}", orderId, applyId);
        } catch (BusinessException e) {
            throw e;
        } catch (Exception e) {
            log.error("执行订单修改异常，orderId={}, applyId={}", orderId, applyId, e);
            throw e;
        }
    }

    // ==================== 辅助方法：重建项目修改 ====================

    /**
     * 处理重建项目修改（增量差异：以 orderItemId 匹配，新增/修改/删除各留痕）
     */
    private void processItemModification(OrderMainEntity order, ExecuteModificationDTO dto,
            Long applyId, Long modifierId, String modifierName) {
        // 1. 查询旧 items
        List<OrderItemEntity> oldItems = orderItemMapper.selectList(
            new LambdaQueryWrapper<OrderItemEntity>()
                .eq(OrderItemEntity::getOrderId, order.getId())
                .eq(OrderItemEntity::getIsDeleted, 0)
                .orderByAsc(OrderItemEntity::getSortOrder)
        );

        // 2. 校验所有提供的 orderItemId 确实属于当前订单
        Set<Long> validItemIds = oldItems.stream()
                .map(OrderItemEntity::getId)
                .collect(Collectors.toSet());
        for (ExecuteModificationItemDTO item : dto.getItems()) {
            if (item.getOrderItemId() != null && !validItemIds.contains(item.getOrderItemId())) {
                throw new BusinessException(400, "重建项目ID不属于当前订单：" + item.getOrderItemId());
            }
        }

        // 3. 逐项对比：新增 / 修改 / 删除
        Map<Long, OrderItemEntity> oldItemMap = oldItems.stream()
                .collect(Collectors.toMap(OrderItemEntity::getId, item -> item));

        int sortOrder = 1;
        for (ExecuteModificationItemDTO newItem : dto.getItems()) {
            if (newItem.getOrderItemId() != null && oldItemMap.containsKey(newItem.getOrderItemId())) {
                // 修改：逐字段对比并记录留痕
                OrderItemEntity oldItem = oldItemMap.remove(newItem.getOrderItemId());
                compareAndLogItemFields(order, oldItem, newItem, applyId, modifierId, modifierName);
                BeanUtils.copyProperties(newItem, oldItem, "orderItemId");
                oldItem.setSortOrder(sortOrder++);
                // 重新校验并填充冗余字段（bodyPartName、projectName 等）
                orderDataValidator.validateAndFillItemsForOrder(List.of(oldItem), ValidateMode.DIRECT);
                orderItemMapper.updateById(oldItem);
            } else {
                // 新增：校验并插入
                OrderItemEntity newEntity = new OrderItemEntity();
                BeanUtils.copyProperties(newItem, newEntity);
                newEntity.setOrderId(order.getId());
                newEntity.setOrderCode(order.getOrderCode());
                newEntity.setSortOrder(sortOrder++);
                orderDataValidator.validateAndFillItemsForOrder(List.of(newEntity), ValidateMode.DIRECT);
                orderItemMapper.insert(newEntity);
                // 记录新增留痕
                recordModificationLog(order.getId(), order.getOrderCode(), applyId,
                        "item_" + newEntity.getId(), "新增重建项目",
                        null, newEntity.getProjectName(), modifierId, modifierName);
            }
        }
        // 删除：oldItemMap 中剩余的为删除项
        for (OrderItemEntity deletedItem : oldItemMap.values()) {
            orderItemMapper.deleteById(deletedItem.getId());
            recordModificationLog(order.getId(), order.getOrderCode(), applyId,
                    "item_" + deletedItem.getId(), "删除重建项目",
                    deletedItem.getProjectName(), null, modifierId, modifierName);
        }
    }

    // ==================== 辅助方法：影像文件修改 ====================

    /**
     * 处理影像文件修改（先校验文件存在，再按类别替换）
     */
    private void processImageModification(OrderMainEntity order, ExecuteModificationDTO dto,
            Long applyId, Long modifierId, String modifierName) {
        if (dto.getImageDataFileIds() != null) {
            // 校验文件存在性
            validateFileIds(dto.getImageDataFileIds(), "影像数据");
            replaceOrderFiles(order, dto.getImageDataFileIds(),
                    FileBizTypeEnum.IMAGE_DATA.getDictCode(), applyId, modifierId, modifierName);
        }
        if (dto.getImageReportFileIds() != null) {
            validateFileIds(dto.getImageReportFileIds(), "影像报告");
            replaceOrderFiles(order, dto.getImageReportFileIds(),
                    FileBizTypeEnum.IMAGE_REPORT.getDictCode(), applyId, modifierId, modifierName);
        }
    }

    /**
     * 校验文件ID列表中的文件均存在于 file_detail 表
     */
    private void validateFileIds(List<String> fileIds, String fileTypeName) {
        if (CollUtil.isEmpty(fileIds)) return;
        List<FileVO> found = fileService.listByIds(fileIds);
        if (found.size() != fileIds.size()) {
            throw new BusinessException(ErrorCodeEnum.ORDER_FILE_NOT_FOUND, fileTypeName + "文件");
        }
    }

    /**
     * 替换订单文件关联（按 fileCategory 逻辑删除旧关联，插入新关联，记录留痕）
     */
    private void replaceOrderFiles(OrderMainEntity order, List<String> newFileIds,
            String fileCategory, Long applyId, Long modifierId, String modifierName) {
        // 1. 查询旧文件关联
        List<OrderFileEntity> oldFiles = orderFileMapper.selectList(
            new LambdaQueryWrapper<OrderFileEntity>()
                .eq(OrderFileEntity::getOrderId, order.getId())
                .eq(OrderFileEntity::getFileCategory, fileCategory)
                .eq(OrderFileEntity::getIsDeleted, 0)
        );

        // 2. 逻辑删除旧文件关联
        if (!oldFiles.isEmpty()) {
            List<Long> oldFileEntityIds = oldFiles.stream().map(OrderFileEntity::getId).toList();
            orderFileMapper.update(null,
                new LambdaUpdateWrapper<OrderFileEntity>()
                    .in(OrderFileEntity::getId, oldFileEntityIds)
                    .set(OrderFileEntity::getIsDeleted, 1)
            );
        }

        // 3. 插入新文件关联
        for (String fileId : newFileIds) {
            OrderFileEntity newFile = new OrderFileEntity();
            newFile.setOrderId(order.getId());
            newFile.setOrderCode(order.getOrderCode());
            newFile.setFileId(fileId);
            newFile.setFileCategory(fileCategory);
            orderFileMapper.insert(newFile);
        }

        // 4. 记录留痕（JSON 数组格式记录前后文件 ID 列表）
        recordModificationLog(order.getId(), order.getOrderCode(), applyId,
                fileCategory, fileCategory,
                JSONUtil.toJsonStr(oldFiles.stream().map(OrderFileEntity::getFileId).toList()),
                JSONUtil.toJsonStr(newFileIds),
                modifierId, modifierName);
    }

    // ==================== 辅助方法：留痕 ====================

    /**
     * 加载字段配置（带兜底默认配置）
     */
    private ModifyApplyFieldConfigDTO loadFieldConfig() {
        String configJson = configService.getConfigValue(SystemConfigKeyEnum.ORDER_MODIFY_FIELD_CONFIG.getKey());
        if (StrUtil.isBlank(configJson)) {
            log.warn("字段配置为空，使用默认配置");
            return new ModifyApplyFieldConfigDTO();
        }
        try {
            return JSONUtil.toBean(configJson, ModifyApplyFieldConfigDTO.class);
        } catch (Exception e) {
            log.error("解析字段配置异常，使用默认配置", e);
            return new ModifyApplyFieldConfigDTO();
        }
    }

    /**
     * 记录修改留痕（旧值 == 新值时不记录）
     */
    private void recordModificationLog(Long orderId, String orderCode, Long applyId,
            String fieldName, String fieldLabel, Object oldValue, Object newValue,
            Long modifierId, String modifierName) {
        if (Objects.equals(oldValue, newValue)) {
            return;
        }
        OrderModificationLogEntity logEntity = new OrderModificationLogEntity();
        logEntity.setOrderId(orderId);
        logEntity.setOrderCode(orderCode);
        logEntity.setApplyId(applyId);
        logEntity.setFieldName(fieldName);
        logEntity.setFieldLabel(fieldLabel);
        logEntity.setOldValue(oldValue != null ? oldValue.toString() : null);
        logEntity.setNewValue(newValue != null ? newValue.toString() : null);
        logEntity.setModifierId(modifierId);
        logEntity.setModifierName(modifierName);
        orderModificationLogMapper.insert(logEntity);
    }
}
```

## 十二、与现有模块的交互

### 12.1 与设计模块（phase=2）的解耦方案

> **重要设计目标**：设计模块未来可能需要调用订单修改申请功能，因此本服务设计为**统一调用入口**，设计模块通过 Service 接口使用，不直接操作 Mapper。

**设计模块调用示例**：

```java
/**
 * 设计模块 Service
 */
@Service
@RequiredArgsConstructor
public class DesignProjectServiceImpl implements DesignProjectService {

    private final OrderModifyApplyService orderModifyApplyService;  // 统一入口

    /**
     * 设计阶段修改重建项目（通过修改申请流程）
     */
    @Override
    public void modifyRebuildProjectInDesignPhase(Long orderId, Long applyId, ExecuteModificationDTO dto) {
        // 仅允许 item 类型字段
        List<String> allowedFields = List.of("items");
        // 校验字段范围
        orderModifyApplyService.validateFieldsInScope(applyId, allowedFields);
        // 执行修改
        orderModifyApplyService.executeModification(orderId, applyId, dto);
    }
}
```

### 12.2 与 OrderMainServiceImpl 的关系

`OrderMainServiceImpl.updateOrder()` **保持不变**，继续处理：
- 草稿阶段（phase=1, status=10）的订单更新
- 其他不经过修改申请流程的订单更新

**不将申请逻辑混入 `updateOrder()`**，保持职责单一。

### 12.3 与 Flow 模块的关系

**无依赖**。审核通过后订单状态不变，不调用 `FlowFacade`。
