## 三、第一阶段：字典管理

### 3.1 阶段目标

完成通用字典数据的管理能力建设，作为所有业务模块的基础数据支撑。

### 3.2 设计方案

#### 3.2.1 设计思路

采用**单表树形结构**设计，通过父级/子级关系实现层级结构，相比传统两表分离方案更灵活：

- **字典类型** = 根节点（parent_id = 0）
- **字典数据** = 根节点的子节点
- **支持多级** = 可扩展任意层级

#### 3.2.2 表结构设计

```sql
-- 字典表（单表树形结构）
CREATE TABLE sys_dict (
    id              BIGINT          NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    parent_id       BIGINT          DEFAULT 0 COMMENT '父级ID（0表示根节点/字典类型）',
    dict_code       VARCHAR(64)     NOT NULL COMMENT '字典编码（唯一标识）',
    dict_name       VARCHAR(128)    NOT NULL COMMENT '字典名称',
    dict_value      VARCHAR(256)    DEFAULT NULL COMMENT '字典值（叶子节点使用）',
    level           INT             DEFAULT 1 COMMENT '层级（1=字典类型，2=字典数据，3+=扩展层级）',
    sort            INT             DEFAULT 0 COMMENT '排序（同级内排序）',
    status          TINYINT         DEFAULT 1 COMMENT '状态（0=禁用，1=正常）',
    remark          VARCHAR(512)    DEFAULT NULL COMMENT '备注说明',

    -- 通用字段（继承 BaseEntity）
    create_time     DATETIME        DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time     DATETIME        DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    create_by       BIGINT          DEFAULT NULL COMMENT '创建人ID',
    update_by       BIGINT          DEFAULT NULL COMMENT '更新人ID',
    is_deleted      TINYINT         DEFAULT 0 COMMENT '是否删除（0=否，1=是）',

    PRIMARY KEY (id),
    UNIQUE KEY uk_dict_code (dict_code),
    KEY idx_parent_id (parent_id),
    KEY idx_level (level),
    KEY idx_is_deleted (is_deleted)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='字典表';
```

#### 3.2.3 Entity 类设计

```java
/**
 * 字典 Entity
 * 采用单表树形结构设计，通过 parent_id 实现层级关系
 *
 * @author hanjor
 * @date 2026-03-16
 */
@Data
@TableName("sys_dict")
@EqualsAndHashCode(callSuper = false)
public class DictEntity extends BaseEntity {

    /**
     * 父级ID（0表示根节点/字典类型）
     */
    private Long parentId;

    /**
     * 字典编码（唯一标识）
     */
    private String dictCode;

    /**
     * 字典名称
     */
    private String dictName;

    /**
     * 字典值（叶子节点使用）
     */
    private String dictValue;

    /**
     * 层级（1=字典类型，2=字典数据，3+=扩展层级）
     */
    private Integer level;

    /**
     * 排序（同级内排序）
     */
    private Integer sort;

    /**
     * 状态（0=禁用，1=正常）
     */
    private Integer status;

    /**
     * 备注说明
     */
    private String remark;
}
```

```java
// 字典类型接口（获取根节点 = 字典类型列表）
GET /api/system/dict/type/list

// 字典数据接口（获取子节点 = 字典数据列表）
GET /api/system/dict/data/{typeCode}      // 根据类型编码获取

GET /api/system/dict/tree

// 叶子节点值（用于表单下拉框）
```
