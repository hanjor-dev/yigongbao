## 一、任务概述

根据功能分析文档，设计并创建设计阶段所需的数据库表结构。

---

## 二、数据模型关系

```
订单主表（order_main）
  │
  ├── 重建项目（order_item × N）
  │     └──（仅记录部位+项目信息，不挂打印产品信息）
  │
  ├── 打印文件数据包（design_package × 1~M）
  │     │
  │     ├── 包内文件列表（design_package_file × K）
  │     │     └── 打印产品信息（design_product × 1，一个文件对应一行产品信息）
  │     │
  │     ├── 指令单（design_instruction × 1）
  │     │
  │     └── 图纸（design_drawing × 1）
  │
  ├── 可视化模型文件（design_model × N）
  │
  ├── 设计报告（file_detail，通过 object_type='10.5' 关联）
  │
  └── 设计审核记录（design_review × M）
```

## 三、新增表清单

| 序号 | 表名 | 说明 |
|:----:|------|------|
| 1 | `design_package` | 打印文件数据包 |
| 2 | `design_package_file` | 数据包内解析的文件列表 |
| 3 | `design_product` | 打印产品信息（一行=一个文件） |
| 4 | `design_instruction` | 指令单 |
| 5 | `design_drawing` | 图纸 |
| 6 | `design_model` | 可视化模型文件 |
| 7 | `design_review` | 设计审核记录 |

> **说明**：设计报告直接使用 `file_detail` 表存储，通过 `object_type='10.5'` + `object_id=orderId` 关联，无需单独建表。

## 四、详细表结构设计

### 4.1 打印文件数据包表（design_package）

存储设计师上传的打印文件压缩包。

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| id | bigint | ✓ | 主键 |
| order_id | bigint | ✓ | 订单ID |
| order_code | varchar(50) | ✓ | 订单编号（冗余） |
| package_code | varchar(50) | ✓ | 数据包编号（规则：订单编号-序号） |
| package_seq | int | ✓ | 序号（订单内递增） |
| file_id | varchar(32) | ✓ | 文件ID（关联 file_detail） |
| file_name | varchar(256) | | 原始文件名 |
| file_url | varchar(512) | | 文件访问地址 |
| file_size | bigint | | 文件大小（字节） |
| file_count | int | | 包内文件数量 |
| upload_time | datetime | | 上传时间 |
| create_time | datetime | | 创建时间 |
| update_time | datetime | | 更新时间 |
| create_by | bigint | | 创建人ID |
| update_by | bigint | | 更新人ID |
| is_deleted | tinyint | | 是否删除 |

**索引**：
- `idx_design_package_order_id (order_id)`
- `uk_design_package_code (package_code)` - 函数唯一索引

## 六、设计报告存储方式

设计报告不单独建表，直接使用 `file_detail` 表存储：

| 字段 | 值 | 说明 |
|------|-----|------|
| object_type | `10.5` | 字典编码：设计报告 |
| object_id | `{orderId}` | 订单ID |

查询示例：
```sql
SELECT * FROM file_detail 
WHERE object_type = '10.5' AND object_id = '订单ID' AND is_deleted = 0;
```
