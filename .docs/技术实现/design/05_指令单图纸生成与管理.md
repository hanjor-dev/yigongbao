# 指令单/图纸生成与管理

> **任务序号**：5
> **状态**：待开始
> **前置依赖**：04_打印信息管理

---

## 一、任务概述

实现指令单和图纸的生成、下载模板、上传修订版功能。

---

## 二、涉及接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/design/workorder/{orderId}/package/{packageId}/generate-docs` | POST | 生成指令单和图纸 |
| `/api/design/workorder/{orderId}/package/{packageId}/instruction/download` | GET | 下载指令单模板 |
| `/api/design/workorder/{orderId}/package/{packageId}/instruction/upload-revised` | POST | 上传修订版指令单 |
| `/api/design/workorder/{orderId}/package/{packageId}/drawing/download` | GET | 下载图纸模板 |
| `/api/design/workorder/{orderId}/package/{packageId}/drawing/upload-revised` | POST | 上传修订版图纸 |

---

## 三、业务逻辑

### 3.1 生成逻辑
- 一个按钮同时生成指令单 + 图纸
- 前置校验：打印信息已填写完整
- 版本号管理：首次 A/1，重新生成递增 A/2、A/3...

### 3.2 指令单内容
- 系统自动填充：订单信息、数据包编号、生产产品信息表格
- 表格行数 = 数据包内文件数（按文件展开）

### 3.3 图纸内容
- 系统自动填充：文字信息、二维码（TODO）
- 图片位置留空，设计师线下粘贴
- 布局：4×3=12格位，右上角放二维码，最多11个内容格位
- 自动分页：文件数 > 11 时分页

### 3.4 模板技术
- 使用 Word 模板 + Apache POI 填充
- 模板文件存放位置待定
