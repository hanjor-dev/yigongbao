# 提交设计

> **任务序号**：7
> **状态**：待开始
> **前置依赖**：06_工单查询

---

## 一、任务概述

实现设计提交功能，包括提交前校验和状态流转。

---

## 二、涉及接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/design/workorder/{orderId}/start` | POST | 开始设计 |
| `/api/design/workorder/{orderId}/continue` | POST | 继续修改（驳回后） |
| `/api/design/workorder/{orderId}/submit` | POST | 提交设计 |

---

## 三、业务逻辑

### 3.1 开始设计
- 前置状态：2010 待设计
- 目标状态：2020 设计中
- 记录 design_start_time

### 3.2 继续修改
- 前置状态：2060 设计审核不通过
- 目标状态：2020 设计中

### 3.3 提交设计
- 前置状态：2020 设计中
- 目标状态：2040 设计审核中
- 记录 design_submit_time

### 3.4 提交校验项
| 校验项 | 必填 |
|--------|:----:|
| 已上传打印文件数据包 | ✓ |
| 已上传可视化模型文件 | ✓ |
| 已上传设计报告 | ✓ |
| 打印信息完整填写 | ✓ |
| 指令单已生成 | ✓ |
| 图纸已生成 | ✓ |
| 修订版指令单已上传 | 模式A必填 |
| 修订版图纸已上传 | 模式A必填 |
