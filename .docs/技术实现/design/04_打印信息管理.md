# 打印信息管理

> **任务序号**：4
> **状态**：待开始
> **前置依赖**：03_设计文件上传处理

---

## 一、任务概述

实现打印信息的选项数据查询、保存、删除功能。

---

## 二、涉及接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/design/print-info/options` | GET | 获取打印信息选项数据 |
| `/api/design/workorder/{orderId}/package/{packageId}/print-info` | POST | 保存打印信息 |
| `/api/design/workorder/{orderId}/package/{packageId}/print-info/{printInfoId}` | DELETE | 删除单条打印信息 |

---

## 三、业务逻辑

### 3.1 选项数据
- 产品列表（含型号规格、注册证号）
- 材质列表（标记默认值）
- 颜色列表（按产品大类过滤）
- 当前设计模式

### 3.2 级联关系
```
选择产品 → 过滤型号规格
选择型号规格 → 自动带出注册证号
选择产品 → 按大类过滤颜色
```

### 3.3 打印模型
- 多选，从数据包内文件列表选择
- 一个产品可关联多个文件
