# 打印信息管理

> **任务序号**：4
> **状态**：已完成
> **前置依赖**：03_设计文件上传处理

---

## 一、任务概述

实现打印信息的选项数据查询、列表查询、整包保存、单条删除功能。

---

## 二、涉及接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/design/workorder/{orderId}/package/{packageId}/print-info/options` | GET | 获取打印信息选项数据（产品树、材质、颜色，含数据包回显字段） |
| `/design/workorder/{orderId}/package/{packageId}/print-info` | GET | 查询数据包打印信息列表 |
| `/design/workorder/{orderId}/package/{packageId}/print-info` | POST | 保存打印信息（整包替换，空列表=清空） |
| `/design/workorder/{orderId}/package/{packageId}/print-info/{printInfoId}` | DELETE | 删除单条打印信息 |

## 三、业务逻辑

### 3.1 选项数据（getOptions）

返回打印信息填写所需的下拉选项：

| 字段 | 数据来源 | 说明 |
|------|----------|------|
| designMode | 订单表（暂返回 null） | 当前设计模式（预留字段） |
| products | `productService.listAllWithSpecs()` | 启用产品及其启用规格树，含 certNo |
| materials | `dictService.listByTypeCode("15")` | 材质选项，标记「15.1 树脂」为默认 |
| colorGroups | `dictService.listTreeByTypeCode("16")` | 颜色按产品大类分组 |

**产品树结构**：
```json
{
  "products": [
    {
      "id": 1,
      "productName": "PEEK骨模型",
      "category": "17.1",
      "categoryName": "模型类",
      "specs": [
        { "id": 10, "specName": "47mm", "certId": 100, "certNo": "GZZJ-2026-0001" },
        { "id": 11, "specName": "52mm", "certId": 100, "certNo": "GZZJ-2026-0001" }
      ]
    }
  ]
}
```

**颜色分组结构**：
```json
{
  "colorGroups": [
    {
      "categoryCode": "17.1",
      "categoryName": "模型类",
      "colors": [
        { "code": "16.1.1", "name": "白色", "isDefault": true },
        { "code": "16.1.2", "name": "肤色", "isDefault": false }
      ]
    },
    {
      "categoryCode": "17.2",
      "categoryName": "导板类",
      "colors": [
        { "code": "16.2.1", "name": "透明", "isDefault": true }
      ]
    }
  ]
}
```

> **颜色字典说明**：`init.sql` 中颜色字典（16.x）的 `dict_value` 存储的是对应产品大类编码（`17.1`/`17.2`/`null`），用于按产品大类过滤颜色，而非颜色描述文本。

### 3.2 级联关系

```
选择产品 → 过滤规格（只显示该产品下 status=1 的规格）
选择规格 → 自动带出注册证号（spec.certNo）
选择产品 → 按大类过滤颜色（根据 product.category 匹配 colorGroup.categoryCode）
材质 → 全量可选，默认「树脂」（dict_code=15.1）
打印模型 → 从当前数据包内文件列表多选
```

### 3.3 保存逻辑（savePrintInfo）

采用**整包替换**策略：

1. 校验订单状态（必须为「设计中」或「设计审核不通过」）
2. 校验当前用户为订单指定设计师
3. 校验 packageId 属于 orderId
4. 校验每条 item 的 packageFileIds 中每个文件ID均属于该数据包
5. 校验 productId 存在且 status=1
6. 校验 specId 存在、status=1、且 spec.productId == productId
7. 删除该数据包下所有旧产品-文件关联记录（`design_product_file`）及旧产品记录（`design_product`）
8. 批量插入新产品记录，再批量插入对应的产品-文件关联记录
9. 空列表 = 清空该包所有打印信息

**关键**：
- 后端从 `product_spec` 表读取 `certNo` 覆盖前端传入值，确保注册证号准确。
- 包级字段（`productMark`、`packQuantity`、`remark`）保存至 `design_package` 表。

### 3.4 权限校验

所有写操作（save/delete）执行前校验：
- 订单状态必须为 `DESIGN_IN_PROGRESS(2020)` 或 `DESIGN_REVIEW_REJECTED(2060)`
- 当前登录用户必须是订单的 `designerId`
- 校验失败抛出 `DESIGN_OPERATOR_NOT_ALLOWED(740)`

## 四、数据结构

### 4.1 请求 DTO

**SavePrintInfoDTO**
```java
@Data
public class SavePrintInfoDTO {
    @NotBlank
    private String productMark;              // 产品标识（包级，必填）
    private Integer packQuantity;            // 包装数量（包级）
    private String remark;                   // 备注（包级）
    @NotNull
    private List<@Valid SavePrintInfoItemDTO> items;
}
```

**SavePrintInfoItemDTO**
```java
@Data
public class SavePrintInfoItemDTO {
    @NotEmpty private List<Long> packageFileIds; // 关联的数据包文件ID列表（多选）
    @NotNull private Long productId;             // 产品ID
    @NotNull private Long specId;                // 规格ID
    @NotNull @Min(1) private Integer quantity;   // 数量
    private Integer isUrgent;                    // 是否加急：0=普通，1=加急
    
    // 冗余字段（前端传入，后端可覆盖）
    private String productName;
    private String specName;
    private String certNo;                       // 后端从 spec 表读取覆盖
    private String materialId;                   // dict_code
    private String materialName;
    private String colorId;                      // dict_code
    private String colorName;
    private Integer sortOrder;
}
```

## 五、实体设计

**DesignProductEntity**（design_product 表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键 |
| orderId | Long | 订单ID |
| packageId | Long | 数据包ID |
| productId | Long | 产品ID |
| productName | String | 产品名称 |
| specId | Long | 规格ID |
| specName | String | 规格名称 |
| certNo | String | 注册证号 |
| materialId | String | 材质 dict_code（如 15.1） |
| materialName | String | 材质名称 |
| colorId | String | 颜色 dict_code（如 16.1.1） |
| colorName | String | 颜色名称 |
| quantity | Integer | 数量 |
| isUrgent | Integer | 是否加急：0=普通，1=加急 |
| sortOrder | Integer | 排序 |

> **注意**：`materialId` 和 `colorId` 为 **String** 类型，存储字典 dict_code（如 "15.1"、"16.1.1"）。`pack_quantity`、`timeliness`、`product_mark`、`package_file_id`、`package_file_name` 已从本表移除。

**DesignProductFileEntity**（design_product_file 表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 主键 |
| designProductId | Long | 打印产品记录ID |
| packageFileId | Long | 数据包文件ID（design_package_file.id） |
| packageFileName | String | 文件名（冗余） |
| sortOrder | Integer | 排序序号 |
