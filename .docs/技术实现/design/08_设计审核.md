# 设计审核

> **任务序号**：8
> **状态**：待开始
> **前置依赖**：07_提交设计

---

## 一、任务概述

实现设计审核功能，包括审核列表、审核详情、审核通过/驳回操作。

---

## 二、涉及接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/design/review/list` | POST | 查询待审核列表 |
| `/api/design/review/{orderId}` | GET | 获取审核详情 |
| `/api/design/review/{orderId}/pass` | POST | 审核通过 |
| `/api/design/review/{orderId}/reject` | POST | 审核驳回 |

---

## 三、业务逻辑

### 3.1 审核列表
- 角色限制：设计管理员、业务管理员、系统管理员
- 筛选条件：订单编号、患者姓名、设计师姓名
- 状态固定为 2040 审核中

### 3.2 审核详情
- 与工单详情结构相同
- 增加审核历史记录

### 3.3 审核通过
- 前置状态：2040 设计审核中
- 目标状态：
  - needsPhysicalDelivery=1 → 3010 待打印
  - needsPhysicalDelivery=0 → 7010 待客户确认
- 审批意见选填

### 3.4 审核驳回
- 前置状态：2040 设计审核中
- 目标状态：2060 设计审核不通过
- 驳回原因必填
- 通知设计师
