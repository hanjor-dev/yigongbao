# 设计文件上传处理

> **任务序号**：3
> **状态**：待开始
> **前置依赖**：02_design模块初始化

---

## 一、任务概述

实现设计阶段三类文件的上传、删除功能：
1. 打印文件数据包（含压缩包解析）
2. 可视化模型文件
3. 设计报告

---

## 二、涉及接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/design/workorder/{orderId}/package/upload` | POST | 上传打印文件数据包 |
| `/api/design/workorder/{orderId}/package/{packageId}` | DELETE | 删除数据包 |
| `/api/design/workorder/{orderId}/visual-model/upload` | POST | 上传可视化模型 |
| `/api/design/workorder/{orderId}/visual-model/{fileId}` | DELETE | 删除可视化模型 |
| `/api/design/workorder/{orderId}/report/upload` | POST | 上传设计报告 |
| `/api/design/workorder/{orderId}/report/{fileId}` | DELETE | 删除设计报告 |

---

## 三、技术要点

- **文件存储**：使用 x-file-storage 组件
- **压缩包解析**：支持 ZIP/RAR/7Z 格式，解析包内文件列表
- **数据包编号**：`{订单编号}-{序号}`
- **权限校验**：仅设计中状态可操作，仅本人可操作
