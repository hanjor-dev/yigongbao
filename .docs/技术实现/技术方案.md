# 医工宝系统技术方案

---

## 一、技术栈

### 核心技术栈

| 类别 | 技术选型 | 版本 |
|------|---------|------|
| 语言 | Java | 21 (LTS) |
| 构建工具 | Maven | 3.9+ |
| Web框架 | Spring Boot | 3.2.5 |
| 数据库 | MySQL | 8.0+ |
| ORM | MyBatis-Plus | 3.5.7 |
| 缓存 | Redis | 7.0+ |

### 鉴权与安全

| 技术选型 | 说明 |
|---------|------|
| Sa-Token | 认证与授权 |
| Hutool | 工具库（日期、JSON、加密、HTTP等） |

## 二、模块结构

```
yigongbao-parent/                                    # 父POM，统一版本管理
│
├─ yigongbao-core/                                   # 核心公共层（纯技术，无业务）
│   ├─ yigongbao-core-common/                        # 通用常量和工具类
│   │   └─ com/yigongbao/core/common/
│   │       ├─ result/                               # 统一响应 Result、PageResult
│   │       ├─ exception/                            # 异常定义 BusinessException
│   │       ├─ enums/                                # 枚举 ErrorEnum、StatusEnum
│   │       ├─ constant/                             # 常量 Constants
│   │       └─ util/                                 # 工具类
│   │
│   ├─ yigongbao-core-redis/                         # Redis 操作封装
│   │   └─ com/yigongbao/core/redis/
│   │       ├─ config/                               # RedisConfig
│   │       ├─ template/                             # RedisTemplate 封装
│   │       └─ cache/                                # 缓存工具 CacheUtil
│   │
│   │
│   └─ yigongbao-core-web/                           # Web 通用
│       └─ com/yigongbao/core/web/
│           ├─ config/                               # WebConfig、CorsConfig
│           ├─ handler/                             # GlobalExceptionHandler
│           └─ aspect/                              # LogAspect 日志切面
│
├─ yigongbao-business/                               # 业务模块层
│   ├─ yigongbao-biz-system/                        # 系统模块
│   │   └─ com/yigongbao/biz/system/
│   │       ├─ example/                                # 示例子模块
│   │       │   ├─ controller/ExampleController.java
│   │       │   ├─ service/ExampleService.java
│   │       │       ├─ impl/ExampleServiceImpl.java
│   │       │   ├─ mapper/ExampleMapper.java
│   │       │   └─ domain/
│   │       │       ├─ entity/Example.java
│   │       │       ├─ dto/
│   │       │       └─ vo/
│   │       ├─ role/                                # 角色管理
│   │       ├─ menu/                                # 菜单管理
│   │       ├─ dept/                                # 机构部门
│   │       ├─ dict/                                # 字典管理
│   │       ├─ config/                              # 系统配置
│   │       └─ auth/                                # 登录认证
│   │
│   ├─ yigongbao-biz-base/                          # 基础数据模块
│   ├─ yigongbao-biz-order/                         # 订单模块
│   ├─ yigongbao-biz-design/                        # 设计模块
│   ├─ yigongbao-biz-production/                    # 生产模块
│   ├─ yigongbao-biz-qc/                            # 质检模块
│   ├─ yigongbao-biz-warehouse/                     # 仓储模块
│   └─ yigongbao-biz-file/                          # 文件模块（公共）
│
└─ yigongbao-boot/                                  # 启动入口
    └─ yigongbao-server/
        └─ com/yigongbao/server/
            ├─ YigongbaoServerApplication.java      # 启动类
```
