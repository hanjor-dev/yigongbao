# 医工宝系统技术方案

---

## 一、技术栈

### 核心技术栈

| 类别 | 技术选型 | 版本 |
|------|---------|------|
| 语言 | Java | 21 (LTS) |
| 构建工具 | Maven | 3.9+ |
| Web框架 | Spring Boot | 3.2.5 |
| 数据库 | MySQL | 8.0+ |
| ORM | MyBatis-Plus | 3.5.7 |
| 缓存 | Redis | 7.0+ |

### 鉴权与安全

| 技术选型 | 说明 |
|---------|------|
| Sa-Token | 认证与授权 |
| Hutool | 工具库（日期、JSON、加密、HTTP等） |

## 二、模块结构

```
yigongbao-parent/                                    # 父POM，统一版本管理
│
├─ yigongbao-boot/                                  # 启动入口
│   └─ src/
│       ├─ main/
│       │   ├─ java/com/yigongbao/boot/
│       │   │   └─ YigongbaoApplication.java        # 启动类
│       │   └─ resources/
│       └─ test/
│
├─ yigongbao-common/                                # 通用层
│   └─ src/
│       ├─ main/
│       │   ├─ java/com/yigongbao/common/
│       │   │   ├─ constant/
│       │   │   ├─ enums/
│       │   │   ├─ exception/
│       │   │   ├─ result/
│       │   │   └─ util/
│       │   └─ resources/
│       └─ test/
│
├─ yigongbao-framework/                             # 基础框架能力层
│   └─ src/
│       ├─ main/
│       │   ├─ java/com/yigongbao/framework/
│       │   │   ├─ config/
│       │   │   ├─ log/
│       │   │   ├─ mybatis/
│       │   │   └─ web/
│       │   └─ resources/
│       └─ test/
│
└─ yigongbao-module-system/                         # 系统业务层
    └─ src/
        ├─ main/
        │   ├─ java/com/yigongbao/module/system/
        │   │   ├─ testFun/
            │   │   ├─ controller/
            │   │   ├─ convert/
            │   │   ├─ dto/
            │   │   ├─ entity/
            │   │   ├─ mapper/
            │   │   ├─ service/
            │   │   │   └─ impl/
            │   │   └─ vo/
        │   └─ resources/
        └─ test/
```
