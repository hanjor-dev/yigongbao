# 医工宝设计阶段全流程 Apifox 手动测试文档

> **适用工具**：Apifox
> **服务地址**：`http://localhost:8080`
> **API 前缀**：所有路径前加 `/api`，如 `POST /api/system/auth/login`
> **文档目的**：覆盖设计阶段从开始设计到提交审核的完整业务功能，包含上传修订版（自动确认）和手动确认两条确认路径，以及异常场景。
> **前置条件**：订单 id=1 已处于**待设计（status=2010）**状态，设计师已分配（designerId=1，即 admin）；MySQL 8（localhost:3307）、Redis（localhost:6379）已运行；应用以 dev profile 启动。

---

## 一、测试流程概览

```
【已完成】登录 → 创建订单 → 提交 → 审核通过 → 分配设计师
                              ↓（当前入口）
                       开始设计（2010→2020）
                              │
              ┌───────────────┼───────────────┐
              │               │               │
         上传数据包      上传可视化模型    上传设计报告
              │
       ┌──────┴──────┐
  填写打印信息   （可选）上传截图
       │
  ┌────┴────┐
生成指令单  生成图纸
  │         │
  └────┬────┘
       │
  ┌────┴──────────────────────────────────┐
  │  路径 A：上传修订版                      │  路径 B：手动确认接口
  │  上传修订版指令单（自动 isConfirmed=1）   │  手动调用 confirm 指令单
  │  上传修订版图纸（自动 isConfirmed=1）     │  手动调用 confirm 图纸
  └────┬──────────────────────────────────┘
       │
  提交设计审核（2020→2040）
       │
  ┌────┴────┐
审核通过   审核驳回（2040→2060→继续修改→2020）
  │
3010 待打印 / 7010 待客户确认
```

**Token 设置**：登录后将 `data.token` 设为 Apifox 全局变量 `token`，后续所有请求 Header 添加：
```
satoken: {{token}}
```
