# 医工宝设计阶段 — 指令单/图纸生成全流程 Apifox 手动测试文档

> **适用工具**：Apifox
> **服务地址**：`http://localhost:8080`
> **API 前缀**：所有路径前加 `/api`，如 `POST /api/system/auth/login`
> **文档目的**：从订单创建到设计阶段指令单/图纸生成，验证完整业务流程的接口行为和逻辑正确性。
> **前置条件**：MySQL 8（localhost:3307）、Redis（localhost:6379）已运行；应用以 dev profile 启动；数据库已执行 `ddl.sql` 和 `init.sql`。

---

## 一、测试流程概览

```
登录（admin）
  └─ 创建订单草稿
       └─ 提交草稿为正式订单（status: 1010→1020）
            └─ 数据审核通过（status: 1020→1030→2010）
                 └─ 分配设计师（designerId = 当前 admin）
                      └─ 设计师开始设计（status: 2010→2020）
                           ├─ 上传数据包（ZIP压缩包）
                           ├─ 填写打印信息
                           ├─ 【核心】生成指令单 ✓
                           ├─ 【核心】生成图纸 ✓
                           ├─ 查询版本列表（含 fileId 字段）✓
                           └─ 上传修订版文件（修订场景）✓
```

**Token 设置**：登录后将 `data.token` 设为 Apifox 全局变量 `token`，后续所有请求 Header 添加：
```
satoken: {{token}}
```

## 步骤 9：上传数据包

| 项目 | 内容 |
|------|------|
| 方法 | POST |
| 路径 | `/api/design/package/upload?orderId={orderId}` |
| Content-Type | `multipart/form-data` |
| Header | `satoken: {{token}}` |

**请求参数**：
- Query 参数：`orderId = {orderId}`
- Form-data 字段 `file`：选择一个 **ZIP 压缩包**，包内至少含一个扩展名为 `.stl`、`.obj`、`.ply`、`.3mf`、`.gcode`、`.ctb` 或 `.cbddlp` 的文件

> **测试文件准备**：可新建一个任意 `.stl` 文件（哪怕是空文件），用 ZIP 打包，命名如 `test_package.zip`。

**预期响应：**
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 10,
    "orderId": 2,
    "packageCode": "PKG-xxxxxx",
    "packageSeq": 1,
    "fileCount": 1,
    "files": [
      {
        "id": 101,
        "fileName": "model.stl",
        "fileExt": "stl",
        "hasPrintInfo": false
      }
    ]
  }
}
```
> 记录：`{packageId}` = `data.id`，`{packageFileId}` = `data.files[0].id`。

**验证点**：
- [ ] `code == 200`
- [ ] `data.packageCode` 非空
- [ ] `data.files` 数组长度 ≥ 1
- [ ] `data.files[0].hasPrintInfo == false`（尚未填写打印信息）
