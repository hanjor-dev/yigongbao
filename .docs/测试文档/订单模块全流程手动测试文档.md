# 医工宝订单模块 — Apifox 全流程手动测试文档

> **适用工具**：Apifox（或 Postman）
> **服务地址**：`http://localhost:8080`
> **文档目的**：按测试流程逐步调用接口，验证订单模块全部功能逻辑是否正确完整。
> **前置条件**：MySQL 8 运行于 localhost:3307，Redis 运行于 localhost:6379，应用以 dev profile 启动。

---

## 一、前置准备：登录鉴权

所有接口均需要携带 SaToken 认证信息。先执行登录，获取 Token。

### 步骤 1：用户登录

| 项目 | 内容 |
|---|---|
| 方法 | POST |
| 路径 | `/api/system/user/login` |
| Content-Type | `application/json` |

**请求体：**
```json
{
  "username": "admin",
  "password": "123456"
}
```

**预期响应：**
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "token": "xxxxxxxxxxxxxxxxxxxxxxxx",
    "userId": 1,
    "username": "admin",
    "realName": "系统管理员"
  }
}
```

**操作：** 复制 `data.token` 字段的值，在 Apifox 中设置为全局变量 `token`，后续所有请求的 Header 中添加：
```
satoken: {{token}}
```
