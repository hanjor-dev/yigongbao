## 接口列表

### 16.1 上传文件（不关联业务）

**接口地址**：`POST /basic/file/upload`

**是否需要认证**：是

**接口说明**：上传文件但不关联具体业务记录。文件上传后可通过文件ID进行管理，bizType 用于文件分类管理。

**Content-Type**：`multipart/form-data`

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| file | MultipartFile | 是 | 上传的文件 |
| bizType | String | 是 | 业务类型（字典编码，如 10.1、10.4） |

**请求示例**：
```http
POST /basic/file/upload
Content-Type: multipart/form-data
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | FileVO | 文件信息 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "id": "1876543210123456789",
        "bizType": "10.1",
        "bizId": null,
        "fileName": "product-image.jpg",
        "filePath": "/files/2026/03/30/",
        "fileUrl": "/api/files/public/1876543210123456789.jpg",
        "fileSize": 245760,
        "fileSizeText": "240 KB",
        "fileType": "image/jpeg",
        "fileExt": "jpg",
        "platform": "local",
        "thUrl": null,
        "thSize": null,
        "fileHash": "d41d8cd98f00b204e9800998ecf8427e",
        "createTime": "2026-03-30 10:00:00"
    }
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 未选择上传文件 |
| 400 | 文件大小超出限制 |
| 400 | 不支持的文件类型 |
| 400 | 业务类型不能为空 |

### 16.6 下载文件

**接口地址**：`GET /basic/file/download/{id}`

**是否需要认证**：是

**接口说明**：下载指定文件，直接输出文件流到 HTTP 响应头。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 文件ID（雪花算法生成的字符串ID） |

**请求示例**：
```http
GET /basic/file/download/1876543210123456790
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应说明**：
- Content-Type：根据文件 MIME 类型设置
- Content-Disposition：attachment; filename="文件名"
- 响应体：文件二进制流

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 404 | 文件不存在 |

## 相关数据结构

### FileVO（文件视图对象）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 文件ID（雪花算法生成的字符串） |
| bizType | String | 业务类型（字典 dict_code，如 10.1、10.4） |
| bizId | Long | 业务ID（关联的业务主键） |
| fileName | String | 原始文件名 |
| filePath | String | 存储路径（不含文件名） |
| fileUrl | String | 公开访问URL（路径前缀 /api/files/public/） |
| fileSize | Long | 文件大小（字节） |
| fileSizeText | String | 格式化文件大小（如 2.35 MB） |
| fileType | String | 文件 MIME 类型 |
| fileExt | String | 文件扩展名 |
| platform | String | 存储平台标识（如 local、aliyun-oss-1） |
| thUrl | String | 缩略图访问URL |
| thSize | Long | 缩略图大小（字节） |
| fileHash | String | 文件哈希（MD5） |
| createTime | LocalDateTime | 创建时间 |

## 业务说明

### 业务类型（bizType）

bizType 业务类型通过字典管理，可通过以下接口获取可选值：

```
GET /system/select/biz-type-list
```

常用 bizType 示例：

| bizType | 说明 |
|---------|------|
| 10.1 | 产品图片 |
| 10.2 | 合同文件 |
| 10.3 | 资质证书 |
| 10.4 | 订单附件 |

### 文件访问

- `fileUrl` 为公开访问 URL，前缀为 `/api/files/public/`，无需登录即可访问
- 适用于前端直接嵌入图片、展示附件等场景

### 文件哈希

文件上传后系统自动计算 MD5 哈希值（`fileHash`），可用于：
- 文件去重判断
- 文件完整性校验
- 秒传功能（前端先计算本地文件哈希，服务端比对）

### 缩略图

图片类文件上传后，系统会生成缩略图：
- 缩略图访问地址：`thUrl` 字段
- 缩略图大小：`thSize` 字段

### 存储平台

`platform` 字段标识文件存储位置：
- `local`：本地存储
- `aliyun-oss-1`：阿里云 OSS（配置标识1）
