### 5.2 获取资源列表（分页）

**接口地址**：`POST /system/resource/list`

**是否需要认证**：是

**接口说明**：分页查询资源列表，支持多种筛选条件。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| resourceName | String | 否 | 资源名称（模糊查询） | - |
| resourceCode | String | 否 | 资源编码（模糊查询） | - |
| resourceType | Integer | 否 | 资源类型 | - |
| parentId | Long | 否 | 父级ID（精确筛选） | - |
| queryScope | Integer | 否 | 查询范围：1=全部，2=只查菜单，3=只查按钮 | - |
| status | Integer | 否 | 状态 | - |

**请求示例**：
```json
POST /system/resource/list
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Content-Type: application/json

{
    "pageNum": 1,
    "pageSize": 10,
    "queryScope": 2,
    "status": 1
}
```
| resourceName | String | 否 | 资源名称（模糊查询） | - |
| resourceCode | String | 否 | 资源编码（模糊查询） | - |

## 业务说明

### 资源类型说明

| 类型值 | 类型名称 | 说明 |
|--------|----------|------|
| 1 | 一级菜单 | 左侧菜单栏的一级菜单项 |
| 2 | 二级菜单 | 一级菜单下的子菜单或页面路由 |
| 3 | 按钮 | 页面内的操作按钮（用于权限控制） |

### 资源编码规范

资源编码应唯一，建议格式：`模块:功能`，如：
- `system:user` - 系统管理-用户管理
- `system:role` - 系统管理-角色管理
- `system:user:add` - 系统管理-用户管理-新增按钮

### 组件路径说明

- 一级菜单通常使用 `Layout` 作为布局组件
- 二级菜单使用具体的页面组件路径，如 `/system/user/index`
- Vue 文件存放在 `src/views` 目录下

### 权限控制原理

1. 菜单资源控制左侧菜单的显示
2. 按钮资源控制页面内操作按钮的显示/隐藏
3. 用户登录后，前端根据返回的 `permissions` 数组进行按钮级权限控制
