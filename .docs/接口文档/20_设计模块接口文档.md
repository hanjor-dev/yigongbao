## 工单查询接口

### 20.1 分页查询设计工单列表

**接口地址**：`POST /design/workorder/list`

**是否需要认证**：是

**接口说明**：根据当前登录用户的数据权限范围（SELF/DEPT/ORG/ALL），分页查询设计阶段（phase=20）的工单列表。数据权限按 `designer_id` 过滤，HOSPITALS 类型自动降级为 SELF。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数，最大 100 | 10 |
| orderCode | String | 否 | 订单编号（模糊匹配） | - |
| patientName | String | 否 | 患者姓名（模糊匹配） | - |
| status | Integer | 否 | 工单状态值 | - |
| isUrgent | Integer | 否 | 是否加急：0-否，1-是 | - |
| hospitalId | Long | 否 | 医院ID（精确匹配） | - |
| businessType | String | 否 | 业务类型字典码（如 "11.1"） | - |
| createTimeStart | String | 否 | 创建时间起始（yyyy-MM-dd HH:mm:ss） | - |
| createTimeEnd | String | 否 | 创建时间结束（yyyy-MM-dd HH:mm:ss） | - |
| sortField | String | 否 | 排序字段（白名单见下方说明） | createTime |
| sortOrder | String | 否 | 排序方向：ASC / DESC | DESC |

**sortField 可选值**：`createTime`、`updateTime`、`orderCode`、`patientName`、`hospitalName`、`status`、`isUrgent`、`expectedDeliveryDate`、`designStartTime`。传入不在白名单内的值时自动降级为 `createTime`，不报错。

**请求示例**：
```json
POST /design/workorder/list
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "pageNum": 1,
    "pageSize": 20,
    "isUrgent": 1,
    "sortField": "expectedDeliveryDate",
    "sortOrder": "ASC"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200 表示成功 |
| data | Object | 分页数据 |
| data.current | Long | 当前页码 |
| data.size | Long | 每页条数 |
| data.total | Long | 总记录数 |
| data.records | Array | 工单列表 |
| data.records[].id | Long | 订单ID |
| data.records[].isUrgent | Integer | 是否加急：0-否，1-是 |
| data.records[].orderCode | String | 订单编号 |
| data.records[].status | Integer | 当前状态值 |
| data.records[].statusName | String | 当前状态名称 |
| data.records[].businessType | String | 业务类型字典码 |
| data.records[].businessTypeName | String | 业务类型名称 |
| data.records[].orderType | Integer | 订单类型：1-医疗器械，2-非医疗器械 |
| data.records[].orderTypeName | String | 订单类型名称 |
| data.records[].needsPhysicalDelivery | Integer | 是否需要实体交付：0-否，1-是 |
| data.records[].needsPhysicalDeliveryName | String | 是否需要实体交付名称 |
| data.records[].patientName | String | 患者姓名 |
| data.records[].hospitalId | Long | 医院ID |
| data.records[].hospitalName | String | 医院名称 |
| data.records[].hospitalDeptName | String | 科室名称 |
| data.records[].doctorName | String | 医生姓名 |

**接口说明**：查询指定订单的完整详情，包含订单基本信息、重建项目列表、提交校验状态。任何有权登录的用户均可查询（不校验设计师归属）。

## 列配置接口

### 20.3 获取当前用户列配置

**接口地址**：`GET /design/column-config`

**是否需要认证**：是

**接口说明**：获取当前登录用户的设计工单列表列配置。优先返回用户个人配置（存储于 `sys_user.design_column_settings`），无个人配置时返回系统默认配置（存储于 `sys_config` key=`design.column.config`）。

**请求示例**：
```
GET /design/column-config
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| data.module | String | 固定为 "design" |
| data.columns | Array | 列配置项列表 |
| data.columns[].field | String | 字段名（对应工单列表 VO 的字段） |
| data.columns[].label | String | 列标题 |
| data.columns[].visible | Boolean | 是否可见 |
| data.columns[].sort | Integer | 排序序号（从 1 开始） |
| data.columns[].width | Integer | 列宽（px，可为 null） |
| data.columns[].fixed | String | 固定位置：left / right / null |

**默认可见列**（系统默认配置中 visible=true 的列）：isUrgent、orderCode、status、businessType、orderType、patientName、hospitalName、hospitalDeptName、doctorName、rebuildProjectSummary、designerName、packageCount、designStartTime、expectedDeliveryDate、createTime、needsPhysicalDelivery、areaName。

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1744000000000,
    "data": {
        "module": "design",
        "columns": [
            { "field": "isUrgent", "label": "加急", "visible": true, "sort": 1, "width": 60, "fixed": "left" },
            { "field": "orderCode", "label": "订单编号", "visible": true, "sort": 2, "width": 180, "fixed": null },
            { "field": "status", "label": "状态", "visible": true, "sort": 3, "width": 100, "fixed": null },
            { "field": "rejectReason", "label": "驳回原因", "visible": false, "sort": 19, "width": 200, "fixed": null }
        ]
    }
}
```

### 20.4 保存用户列配置

**接口地址**：`POST /design/column-config`

**是否需要认证**：是

**接口说明**：保存当前登录用户的列配置到 `sys_user.design_column_settings` 字段（JSON 格式）。完整替换，不做增量更新。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| columns | Array | 是 | 列配置项列表（不能为 null，可为空数组） |
| columns[].field | String | 是 | 字段名 |
| columns[].label | String | 是 | 列标题 |
| columns[].visible | Boolean | 是 | 是否可见 |
| columns[].sort | Integer | 是 | 排序序号 |
| columns[].width | Integer | 否 | 列宽（px） |
| columns[].fixed | String | 否 | 固定位置：left / right / null |

**请求示例**：
```json
POST /design/column-config
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "columns": [
        { "field": "isUrgent", "label": "加急", "visible": true, "sort": 1, "width": 60, "fixed": "left" },
        { "field": "orderCode", "label": "订单编号", "visible": true, "sort": 2, "width": 180, "fixed": null },
        { "field": "rejectReason", "label": "驳回原因", "visible": true, "sort": 3, "width": 200, "fixed": null }
    ]
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1744000000000,
    "data": null
}
```

**错误码**：

| code | 说明 |
|------|------|
| 404 | 当前用户不存在（DATA_NOT_FOUND） |
| 500 | JSON 序列化失败（列配置保存失败） |

## 数据包接口

### 20.5 上传打印文件数据包

**接口地址**：`POST /design/package/upload`

**是否需要认证**：是

**接口说明**：上传压缩包文件（ZIP/RAR/7Z/TAR）作为打印文件数据包。后端自动解析压缩包内的有效文件（扩展名白名单由系统配置 `design.package.allowed_extensions` 控制，默认 `.stl,.obj,.ply,.3mf,.gcode,.ctb,.cbddlp`），生成数据包记录及包内文件清单。

**操作权限**：当前登录用户必须是该订单的设计师（`designer_id` 匹配），且订单状态为"设计中"或"设计审核不通过"。

**请求参数**（multipart/form-data）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| orderId | Long | 是 | 订单ID（Query 参数） |
| file | File | 是 | 压缩包文件（ZIP/RAR/7Z/TAR） |

**请求示例**：
```
POST /design/package/upload?orderId=1001
Content-Type: multipart/form-data
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

file: [binary data]
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| data.id | Long | 数据包ID |
| data.orderId | Long | 订单ID |
| data.orderCode | String | 订单编号 |
| data.packageCode | String | 数据包编号（系统生成） |
| data.packageSeq | Integer | 数据包序号（该订单下从 1 递增） |
| data.fileId | String | 压缩包文件ID |
| data.fileName | String | 原始文件名 |
| data.fileUrl | String | 压缩包访问地址 |
| data.fileSize | Long | 文件大小（字节） |
| data.fileCount | Integer | 解析到的有效文件数量 |
| data.uploadTime | String | 上传时间（yyyy-MM-dd HH:mm:ss） |
| data.files | Array | 包内文件列表 |
| data.files[].id | Long | 包内文件ID |
| data.files[].packageId | Long | 数据包ID |
| data.files[].fileName | String | 文件名 |
| data.files[].fileExt | String | 文件扩展名（不含点，如 "stl"） |
| data.files[].filePath | String | 包内相对路径 |
| data.files[].fileSize | Long | 文件大小（字节） |
| data.files[].sortOrder | Integer | 排序序号 |
| data.files[].hasPrintInfo | Boolean | 是否已填写打印信息 |

**错误码**：

| code | 说明 |
|------|------|
| 404 | 订单不存在（ORDER_NOT_FOUND） |
| 403 | 当前用户不是该订单的设计师（DESIGN_OPERATOR_NOT_ALLOWED） |
| 400 | 订单不在可操作状态（DESIGN_ORDER_STATUS_NOT_ALLOWED） |
| 400 | 压缩包格式不支持（DESIGN_ARCHIVE_FORMAT_NOT_SUPPORTED） |
