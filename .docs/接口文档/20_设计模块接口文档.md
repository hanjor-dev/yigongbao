# 20_设计模块接口文档

## 基本信息

| 项目 | 说明 |
|------|------|
| 所属模块 | design（设计工单管理） |
| 请求前缀 | `/design` |
| 认证要求 | 需要登录认证（SaToken） |

### Controller 职责划分

| Controller | 前缀 | 职责 |
|---|---|---|
| `DesignWorkorderController` | `/design/workorder` | 工单列表/详情查询、开始设计、驳回后继续、提交审核 |
| `DesignColumnConfigController` | `/design/column-config` | 工单列表列显示配置 |
| `DesignPackageController` | `/design` | 打印文件数据包（上传/删除/列表） |
| `DesignPrintInfoController` | `/design/workorder` | 打印信息（选项/列表/保存/删除） |
| `DesignAttachmentController` | `/design` | 可视化模型 + 设计报告（关联/删除/查询） |
| `DesignDocController` | `/design/workorder` | 指令单/图纸下载/预览（按需自动生成）、版本查询、修订版上传、截图上传/查询 |
| `DesignReviewController` | `/design/review` | 待审核工单列表查询、审核详情、审核通过/驳回 |

## 工单查询接口

### 20.1 分页查询设计工单列表

**接口地址**：`POST /design/workorder/list`

**是否需要认证**：是

**接口说明**：根据当前登录用户的数据权限范围（SELF/DEPT/ORG/ALL），分页查询设计阶段（phase=20）的工单列表。数据权限按 `designer_id` 过滤，HOSPITALS 类型自动降级为 SELF。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数，最大 100 | 10 |
| orderCode | String | 否 | 订单编号（模糊匹配） | - |
| patientName | String | 否 | 患者姓名（模糊匹配） | - |
| status | Integer | 否 | 工单状态值 | - |
| isUrgent | Integer | 否 | 是否加急：0-否，1-是 | - |
| hospitalId | Long | 否 | 医院ID（精确匹配） | - |
| businessType | String | 否 | 业务类型字典码（如 "11.1"） | - |
| createTimeStart | String | 否 | 创建时间起始（yyyy-MM-dd HH:mm:ss） | - |
| createTimeEnd | String | 否 | 创建时间结束（yyyy-MM-dd HH:mm:ss） | - |
| sortField | String | 否 | 排序字段（白名单见下方说明） | createTime |
| sortOrder | String | 否 | 排序方向：ASC / DESC | DESC |

**sortField 可选值**：`createTime`、`updateTime`、`orderCode`、`patientName`、`hospitalName`、`status`、`isUrgent`、`expectedDeliveryDate`、`designStartTime`。传入不在白名单内的值时自动降级为 `createTime`，不报错。

**请求示例**：
```json
POST /design/workorder/list
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "pageNum": 1,
    "pageSize": 20,
    "isUrgent": 1,
    "sortField": "expectedDeliveryDate",
    "sortOrder": "ASC"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200 表示成功 |
| data | Object | 分页数据 |
| data.current | Long | 当前页码 |
| data.size | Long | 每页条数 |
| data.total | Long | 总记录数 |
| data.records | Array | 工单列表 |
| data.records[].id | Long | 订单ID |
| data.records[].isUrgent | Integer | 是否加急：0-否，1-是 |
| data.records[].orderCode | String | 订单编号 |
| data.records[].status | Integer | 当前状态值 |
| data.records[].statusName | String | 当前状态名称 |
| data.records[].businessType | String | 业务类型字典码 |
| data.records[].businessTypeName | String | 业务类型名称 |
| data.records[].orderType | Integer | 订单类型：1-医疗器械，2-非医疗器械 |
| data.records[].orderTypeName | String | 订单类型名称 |
| data.records[].needsPhysicalDelivery | Integer | 是否需要实体交付：0-否，1-是 |
| data.records[].needsPhysicalDeliveryName | String | 是否需要实体交付名称 |
| data.records[].patientName | String | 患者姓名 |
| data.records[].hospitalId | Long | 医院ID |
| data.records[].hospitalName | String | 医院名称 |
| data.records[].hospitalDeptName | String | 科室名称 |
| data.records[].doctorName | String | 医生姓名 |
| data.records[].areaName | String | 地区名称 |
| data.records[].rebuildProjectSummary | String | 重建项目摘要，格式：左髋骨导板, 右髋骨模型 |
| data.records[].designerId | Long | 设计师ID |

### 20.19 下载指令单（线下模式）

**接口地址**：`GET /design/workorder/{orderId}/package/{packageId}/instruction/download`

**是否需要认证**：是

**说明**：按需自动生成指令单（Excel 模板填充）并流式返回文件。
- 首次调用或打印信息在上次生成后发生变化时：自动重新生成，`isConfirmed` 重置为 0
- 打印信息未变化时：直接复用已有文件，不产生新版本记录

调用方无需事先调用独立的"生成"接口。

**权限**：订单状态为设计中或设计审核不通过，且当前用户为该订单的 designerId；数据包下必须已有打印信息（design_product 记录数 > 0）。

**路径参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| orderId | Long | 订单ID |
| packageId | Long | 数据包ID |

**响应**：HTTP 200，`Content-Type: application/octet-stream`，文件内容直接写入响应流。

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 740 | 非设计师或订单状态不允许 |
| 750 | 打印信息未填写，无法生成 |
| 500 | 文件流式传输失败 |
