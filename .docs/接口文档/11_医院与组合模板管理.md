| 项目 | 说明 |
|------|------|

## 接口列表

### 11.1 分页查询医院列表

**接口地址**：`POST /basic/hospital/list`

**是否需要认证**：是

**接口说明**：分页查询医院列表，支持按医院名称、地区ID、医院等级、医院类型、状态等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| hospitalName | String | 否 | 医院名称（模糊查询） | - |
| areaId | Long | 否 | 地区ID | - |
| hospitalLevel | String | 否 | 医院等级（字典编码=3） | - |
| hospitalType | String | 否 | 医院类型（字典编码=4） | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /basic/hospital/list
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "pageNum": 1,
    "pageSize": 10,
    "hospitalName": "北京",
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 医院列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
```

### 11.3 创建医院

**接口地址**：`POST /basic/hospital`

**是否需要认证**：是

**接口说明**：创建新医院。系统自动生成医院编码，无需手动填写。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| hospitalName | String | 是 | 医院名称，最大128字符 |
| areaId | Long | 是 | 地区ID |
| contact | String | 否 | 联系人，最大32字符 |
| phone | String | 否 | 联系电话（手机号格式） |
| email | String | 否 | 邮箱 |
| hospitalLevel | String | 否 | 医院等级（字典编码=3） |
| hospitalType | String | 否 | 医院类型（字典编码=4） |
| address | String | 否 | 详细地址，最大256字符 |
| creditCode | String | 否 | 统一社会信用代码 |
| businessLicense | String | 否 | 营业执照路径，最大512字符 |
| remark | String | 否 | 备注，最大512字符 |

**请求示例**：
```json
{
    "hospitalName": "上海市第一人民医院",
    "areaId": 2,
    "contact": "李主任",
    "phone": "13900139000",
    "email": "contact@shmph.cn",
    "hospitalLevel": "3a",
    "hospitalType": "public",
    "address": "上海市虹口区武进路85号",
    "creditCode": "12100000400005678Y",
    "remark": "新建合作医院"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败（详见 message） |

## 业务说明

### 医院编码

医院编码由系统自动生成，无需手动填写。创建医院后可通过医院详情接口查询系统分配的编码。

### 字典管理

医院等级和医院类型通过字典管理：
- `hospitalLevel`：字典编码为 `3`，存储等级编码如 "3a"、"3b" 等
- `hospitalType`：字典编码为 `4`，存储类型编码如 "public"、"private" 等

具体选项值需查询字典表（dict_code=3、dict_code=4）。

### 医院组合模板

医院组合模板用于管理医院检查项目的批量组合模板，支持：
- 批量关联多个医院到一个模板
- 通过模板快速获取一组医院的完整信息
- 模板支持启用/禁用状态管理

### 删除模板

删除模板时仅删除模板记录和模板与医院的关联关系，被关联的医院数据本身不受影响。
