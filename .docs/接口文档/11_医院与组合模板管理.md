# 11_医院组合模板管理接口文档

> **重要说明**：医院管理（CRUD）已合并至机构管理模块。医院在系统中以 `sys_org` 记录表示，`orgType=1.3`。医院的新增、编辑、删除、查询等操作请使用机构管理接口（`/system/org`）。本文档仅涵盖**医院组合模板**相关接口。

## 基本信息

| 项目 | 说明 |
|------|------|
| 所属模块 | system（系统管理） |
| Controller | HospitalGroupTemplateController |
| 请求前缀 | /system/hospital-group-template |
| 认证要求 | 需要登录认证 |

## 接口列表

### 11.1 分页查询医院组合模板列表

**接口地址**：`POST /system/hospital-group-template/list`

**是否需要认证**：是

**接口说明**：分页查询医院组合模板列表，支持按模板名称、状态筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| templateName | String | 否 | 模板名称（模糊查询） | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /system/hospital-group-template/list
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "pageNum": 1,
    "pageSize": 10,
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 模板列表（HospitalGroupTemplateVO，不含 details） |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "templateName": "北京三甲医院组合",
                "templateCode": "TPL-0001",
                "templateDesc": "包含北京地区所有三甲医院",
                "status": 1,
                "statusName": "正常",
                "remark": "覆盖东城、西城、海淀区",
                "hospitalCount": 15,
                "createTime": "2026-03-01 10:00:00",
                "updateTime": "2026-03-01 10:00:00"
```

### 11.3 创建医院组合模板

**接口地址**：`POST /system/hospital-group-template`

**是否需要认证**：是

**接口说明**：创建新的医院组合模板，批量关联医院。`hospitalIds` 为 `sys_org.id`（`orgType=1.3` 的机构记录）。系统自动生成模板编码。

**请求参数**：

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| templateName | String | 是 | @NotBlank, @Size(max=64) | 模板名称 |
| templateDesc | String | 否 | - | 模板描述 |
| hospitalIds | List\<Long\> | 是 | @NotEmpty | 医院ID列表（sys_org.id，orgType=1.3） |
| remark | String | 否 | - | 备注 |

**请求示例**：
```json
POST /system/hospital-group-template
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "templateName": "华东地区三甲医院组合",
    "templateDesc": "覆盖上海、杭州、南京三地三甲医院",
    "hospitalIds": [101, 102, 103, 104, 105],
    "remark": "用于大型多中心临床研究项目"
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败（详见 message） |
| 658 | 模板名称已存在 |
| 632 | 医院ID无效（不存在或非医疗机构类型） |

### 11.4 更新医院组合模板

**接口地址**：`PUT /system/hospital-group-template/{id}`

**是否需要认证**：是

**接口说明**：更新指定模板信息。`hospitalIds` 为全量替换——传入新列表后，原有关联医院全部替换为新列表。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| templateName | String | 否 | 模板名称 |
| templateDesc | String | 否 | 模板描述 |
| hospitalIds | List\<Long\> | 否 | 医院ID列表（全量替换，sys_org.id，orgType=1.3） |
| remark | String | 否 | 备注 |

**请求示例**：
```json
{
    "templateName": "华东地区三甲医院组合（更新）",
    "templateDesc": "新增苏州地区医院",
    "hospitalIds": [101, 102, 103, 104, 105, 106, 107]
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 656 | 模板不存在 |
| 658 | 模板名称已存在 |
| 632 | 医院ID无效（不存在或非医疗机构类型） |

### 11.5 删除医院组合模板

**接口地址**：`DELETE /system/hospital-group-template/{id}`

**是否需要认证**：是

**接口说明**：逻辑删除指定模板。仅删除模板记录及模板与医院的关联关系，不影响 sys_org 中的医院数据。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 模板ID |

**请求示例**：
```http
DELETE /system/hospital-group-template/1
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 656 | 模板不存在 |
| 659 | 模板已被用户引用，无法删除 |

## 业务说明

### 医院与机构的关系

医院不再是独立实体，而是 `sys_org` 表中 `orgType=1.3` 的机构记录。医院的新增、编辑、删除、状态管理等操作统一通过机构管理接口（`/system/org`）完成。

### hospitalIds 说明

创建或更新模板时传入的 `hospitalIds`，其值为 `sys_org` 表的主键 `id`（`orgType=1.3`）。明细中的 `hospitalName`、`hospitalCode` 均从 `sys_org` 的 `orgName`、`orgCode` 字段读取。

### 模板编码

模板编码由系统自动生成，无需手动填写。

### hospitalIds 全量替换

更新模板时，若传入 `hospitalIds`，系统将删除原有所有关联明细，重新插入新列表。若不传 `hospitalIds`，则保持原有关联不变。

### 删除模板

逻辑删除，仅删除模板记录及关联明细，不影响 `sys_org` 中的医院数据。若模板已被用户引用（错误码 659），需先解除引用再删除。
