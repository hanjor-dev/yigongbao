#### 23.1 分页查询生产列表

**接口地址**：`POST /production/record/list`

**是否需要认证**：是

**接口说明**：分页查询生产流转卡列表，支持按关键词、状态、加工中心、订单创建时间等条件筛选。

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数（最小1） | 10 |
| keyword | String | 否 | 关键词（模糊匹配订单号、数据包编号、患者姓名） | - |

| processingCenterId | Long | 否 | 加工中心ID | - |

| orderCreateTimeEnd | LocalDateTime | 否 | 订单创建时间范围-结束 | - |

#### 23.11 提交打印机配置

**接口地址**：`POST /production/record/{id}/assign-device`

**是否需要认证**：是

**接口说明**：为流转卡分配打印机，并一次性提交打印材质、打印参数以及该流转卡下全部生产产品的重量。设备分配和产品重量保存处于同一事务，任一项校验或保存失败时均不生效。打印机必须同时满足连接在线、设备状态为 0、没有状态为 `PENDING_PRINT` 或 `PRINTING` 的活跃流转卡占用；状态 5“准备就绪”也不允许分配。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 流转卡ID |

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| deviceId | Long | 是 | @NotNull | 打印机ID |
| productWeights | Array | 是 | @Valid、@NotEmpty | 产品重量列表，必须且只能覆盖当前流转卡下的全部生产产品；不允许遗漏、重复或混入其他流转卡产品 |
| productWeights[].productId | Long | 是 | @NotNull | 生产产品ID，取自 23.3 返回的 `data.products[].id`，不是产品主数据ID |
| productWeights[].weight | Decimal | 否 | 最小值0；最多8位整数、2位小数 | 产品重量，单位：克；传 `null` 表示该产品暂不填写重量或清空原重量，但该产品项仍必须出现在数组中 |
| material | String | 否 | - | 打印材质 |
| printParams | String | 否 | - | 打印参数（JSON格式，如层厚、支撑密度等） |

**前端对接流程**：

1. 打开打印机配置页面时，调用 23.3 `GET /production/record/{id}`，读取 `data.products`。
2. 在打印设备配置区域下方展示该流转卡的全部产品，建议至少展示产品名称、型号规格、打印文件名和重量输入框；使用 `products[].weight` 回显已保存重量。
3. 提交时将页面上的全部产品映射为 `productWeights`，即使某个产品重量未填写，也必须提交 `{ "productId": ..., "weight": null }`。
4. 不要只提交本次修改过的产品，也不要使用产品目录/主数据ID代替生产产品ID。

**请求示例**：
```json
POST /production/record/1/assign-device
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Content-Type: application/json

{
    "deviceId": 10,
    "productWeights": [
        {
            "productId": 101,
            "weight": 12.35
        },
        {
            "productId": 102,
            "weight": null
        }
    ],
    "material": "树脂",
    "printParams": "{\"layerHeight\":0.05,\"supportDensity\":30}"
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 / 410 | 打印机ID、产品重量列表或生产产品ID为空 |
| 400 / 410 | 产品重量小于0，或超过8位整数、2位小数 |
| 410 | 产品ID重复、产品不属于当前流转卡，或未覆盖当前流转卡全部产品 |
| 800 | 生产流转卡不存在 |
| 801 | 打印设备不存在 |
| 806 | 设备离线、已占用或不可用 |
| 812 | 流转卡当前状态不允许分配打印机 |

**打印状态与流转卡规则**：

- 状态 1 表示开始打印，仅将当前为 `PENDING_PRINT` 的流转卡推进为 `PRINTING`。
- 新设备先推送状态 2、再推送状态 0；状态 2 只是中间信号，不单独完成打印，`2→0` 时才完成。
- 旧设备从状态 1 直接推送状态 0，`1→0` 时完成。
- 打印中设备短暂离线后从状态 6 恢复为状态 0，`6→0` 时完成。
- `1→0`、`2→0`、`6→0` 只完成当前处于 `PRINTING` 的流转卡。
- `3→0`、`4→0`、`5→0` 不完成，流转卡保持原状态。
- 状态 3（报警）、4（暂停）、5（准备就绪）、6（离线）本身不改变流转卡状态；不增加报警通知功能。

## 业务说明

### 生产流程概述

生产模块管理从设计完成到产品入库的完整生产流程，主要包括以下环节：

1. **打印准备**：分配打印机、填写生产批号和材料批号
2. **3D打印**：执行打印工序，记录打印时间和参数
3. **后处理**：依次执行清洗、固化、清洁烘干等工序
4. **质检**：对每个产品进行质检，标记合格/不合格，生成UDI码
5. **包装**：填写包装参数（热封温度、灭菌方式等）
6. **入库**：完成生产，流转到库存管理

### 流转卡状态流转

流转卡状态由 `FlowStatusEnum` 定义，主要状态包括：
- **待打印**：流转卡已创建，等待分配打印机
- **打印中**：正在执行打印工序
- **后处理中**：正在执行清洗、固化等后处理工序
- **质检中**：所有工序完成，等待质检
- **包装中**：质检完成，正在包装
- **已完成**：包装完成，已入库

### 工序类型说明

| 工序代码 | 工序名称 | 说明 |
|---------|---------|------|
| print | 打印 | 3D打印工序，使用打印机设备 |
| wash | 清洗 | 酒精清洗，去除表面残留树脂 |
| cure | 固化 | UV固化，增强产品强度 |
| clean_dry | 清洁烘干 | 超声清洗+烘干 |
| pack | 包装 | 热封包装+灭菌 |

### 产品状态说明

| 状态代码 | 状态名称 | 说明 |
|---------|---------|------|
| in_process | 生产中 | 产品正在生产流程中 |
| pass | 合格 | 质检合格 |
| fail | 不合格 | 质检不合格 |
| completed | 已完成 | 已入库 |
| cancelled | 已取消 | 已取消生产 |

### UDI码生成规则

医疗器械产品（orderType=1）在质检合格后自动生成UDI码，规则如下：
- 格式：`UDI + 生产批号 + 产品序号`
- 示例：`UDI-BATCH20260528001-001`

### 权限说明

- **生产员**：只能查看和操作自己绑定加工中心的流转卡和设备
- **质检员**：可以查看所有流转卡，执行质检操作
- **管理员**：拥有所有权限
