#### 23.1 分页查询生产列表

**接口地址**：`POST /production/record/list`

**是否需要认证**：是

**接口说明**：分页查询生产流转卡列表，支持按关键词、状态、加工中心、订单创建时间等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数（最小1） | 10 |
| keyword | String | 否 | 关键词（模糊匹配订单号、数据包编号、患者姓名） | - |
| status | Integer | 否 | 流转卡状态（对应 FlowStatusEnum 值） | - |
| processingCenterId | Long | 否 | 加工中心ID | - |
| orderCreateTimeStart | LocalDateTime | 否 | 订单创建时间范围-起始 | - |
| orderCreateTimeEnd | LocalDateTime | 否 | 订单创建时间范围-结束 | - |

**请求示例**：
```json
POST /production/record/list
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Content-Type: application/json

{
    "pageNum": 1,
```

#### 23.2 扫码查询流转卡

**接口地址**：`GET /production/record/scan`

**是否需要认证**：是

**接口说明**：通过扫描流转卡二维码获取流转卡编号，查询流转卡详情。

**请求参数**（Query String）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| recordNo | String | 是 | 流转卡编号 |

**请求示例**：
```http
GET /production/record/scan?recordNo=REC20260528001
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "id": 1,
        "recordNo": "REC20260528001",
        "orderId": 100,
        "orderCode": "ORD20260528001",
        "status": 1,
        "currentProcess": "PRINT",
        "currentProcessName": "打印",
        "products": []
```

#### 23.15 开始工序

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |

```json
{
```

| 错误码 | 说明 |

## 业务说明

### 生产流程概述

生产模块管理从设计完成到产品入库的完整生产流程，主要包括以下环节：

1. **打印准备**：分配打印机、填写生产批号和材料批号
2. **3D打印**：执行打印工序，记录打印时间和参数
3. **后处理**：依次执行清洗、固化、清洁烘干等工序
4. **质检**：对每个产品进行质检，标记合格/不合格，生成UDI码
5. **包装**：填写包装参数（热封温度、灭菌方式等）
6. **入库**：完成生产，流转到库存管理

### 流转卡状态流转

流转卡状态由 `FlowStatusEnum` 定义，主要状态包括：
- **待打印**：流转卡已创建，等待分配打印机
- **打印中**：正在执行打印工序
- **后处理中**：正在执行清洗、固化等后处理工序
- **质检中**：所有工序完成，等待质检
- **包装中**：质检完成，正在包装
- **已完成**：包装完成，已入库

### 工序类型说明

| 工序代码 | 工序名称 | 说明 |
|---------|---------|------|
| print | 打印 | 3D打印工序，使用打印机设备 |
| wash | 清洗 | 酒精清洗，去除表面残留树脂 |
| cure | 固化 | UV固化，增强产品强度 |
| clean_dry | 清洁烘干 | 超声清洗+烘干 |
| pack | 包装 | 热封包装+灭菌 |

### 产品状态说明

| 状态代码 | 状态名称 | 说明 |
|---------|---------|------|
| in_process | 生产中 | 产品正在生产流程中 |
| pass | 合格 | 质检合格 |
| fail | 不合格 | 质检不合格 |
| completed | 已完成 | 已入库 |
| cancelled | 已取消 | 已取消生产 |

### UDI码生成规则

医疗器械产品（orderType=1）在质检合格后自动生成UDI码，规则如下：
- 格式：`UDI + 生产批号 + 产品序号`
- 示例：`UDI-BATCH20260528001-001`

### 权限说明

- **生产员**：只能查看和操作自己绑定加工中心的流转卡和设备
- **质检员**：可以查看所有流转卡，执行质检操作
- **管理员**：拥有所有权限
