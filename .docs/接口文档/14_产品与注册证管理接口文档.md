# 14_产品与注册证管理接口文档

## 基本信息

| 项目 | 说明 |
|------|------|
| 所属模块 | basic（基础管理） |
| Controller | RegistrationCertController、ProductController |
| 请求前缀 | /basic/registration-cert、/basic/product |
| 认证要求 | 需要登录认证 |

## 接口列表

### 14.1 分页查询注册证列表

**接口地址**：`GET /basic/registration-cert/list`

**是否需要认证**：是

**接口说明**：分页查询注册证列表，支持按注册证号、注册证名称、状态等条件筛选。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| certCode | String | 否 | 注册证号（模糊查询） | - |
| certName | String | 否 | 注册证名称（模糊查询） | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```http
GET /basic/registration-cert/list?pageNum=1&pageSize=10&status=1
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 注册证列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "certCode": "国械注进20203010001",
                "certName": "某某产品注册证",
                "validFrom": "2026-01-01",
                "validTo": "2030-12-31",
                "certFileUrl": "https://example.com/cert.pdf",
                "status": 1,
                "statusName": "正常",
                "remark": "有效期5年",
                "createTime": "2026-03-01 10:00:00"
            }
        ],
        "total": 50,
        "size": 10,
        "current": 1,
        "pages": 5
    }
}
```

## 业务说明

### 注册证与产品的关系

注册证是产品的合规性依据，一个注册证可关联多个产品。产品创建时可选择关联注册证，系统会关联展示注册证号。

### 产品型号编码

产品型号编码（productCode）由系统自动生成，无需手动填写。编码格式取决于系统编码规则配置。

### 颜色选项

`colorOptions` 字段存储 JSON 数组格式，如 `["红色","蓝色","黑色"]`，用于记录产品的可选颜色。

### 有效注册证查询

`/basic/registration-cert/valid-list` 接口的过滤条件为 `validTo >= 当前日期`，返回所有有效期未过期的注册证。
