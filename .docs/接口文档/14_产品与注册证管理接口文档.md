## 产品管理

### 14.1 分页查询产品列表

**接口地址**：`POST /basic/product/page`

**是否需要认证**：是

**接口说明**：分页查询产品型号列表，支持按产品名称、分类、注册证、状态等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| productName | String | 否 | 产品名称（模糊查询） | - |
| category | String | 否 | 产品分类（精确匹配） | - |
| certId | Long | 否 | 注册证ID（精确筛选） | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /basic/product/page
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "pageNum": 1,
    "pageSize": 10,
    "productName": "颅骨",
    "category": "假体",
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 产品列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "productCode": "PROD-20260330-0001",
                "productName": "PEEK材料颅骨修补假体",
                "category": "假体",
                "spec": "大号",
                "certId": 1,
                "certCode": "GZZJ-2026-0001",
                "material": "PEEK",
                "colorOptions": "[\"黑色\",\"白色\"]",
                "price": 15000.00,
                "imageUrl": "https://example.com/product.jpg",
                "status": 1,
                "statusName": "正常",
                "remark": "PEEK材料颅骨修补假体",
                "createTime": "2026-03-30 10:00:00",
                "createBy": 1
            }
        ],
        "total": 1,
        "size": 10,
        "current": 1,
        "pages": 1
    }
}
```

### 14.4 创建产品

**接口地址**：`POST /basic/product`

**是否需要认证**：是

**接口说明**：创建新的产品型号，系统自动生成产品编码。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| productName | String | 是 | 产品名称 |
| category | String | 否 | 产品分类 |
| spec | String | 否 | 规格 |
| certId | Long | 否 | 关联注册证ID |
| material | String | 否 | 材质 |
| colorOptions | String | 否 | 可选颜色（JSON数组，如 ["黑色","白色"]） |
| price | BigDecimal | 否 | 标准价格 |
| imageUrl | String | 否 | 产品图片URL |
| remark | String | 否 | 备注 |

**请求示例**：
```json
POST /basic/product
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "productName": "PEEK材料颅骨修补假体",
    "category": "假体",
    "spec": "大号",
    "certId": 1,
    "material": "PEEK",
    "colorOptions": "[\"黑色\",\"白色\"]",
    "price": 15000.00,
    "imageUrl": "https://example.com/product.jpg",
    "remark": "PEEK材料颅骨修补假体"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 产品名称不能为空 |
| 400 | 参数校验失败 |

## 业务说明

### 产品与注册证关系

一个注册证（RegistrationCert）可以关联多个产品（Product）。在创建/编辑产品时，通过 `certId` 字段关联到具体的注册证。

注册证中存储 `certCode`（注册证号），产品中存储 `certId`（关联的注册证ID）和 `certCode`（冗余存储的注册证号）。

### 产品分类

产品分类（category）使用字典管理（dict_code=10，字典类型编码=9），支持按分类筛选产品列表。

### 有效期判断

14.14 有效注册证列表的判断逻辑为：`status = 1 AND validTo >= 当前日期`，仅返回在有效期内的注册证。
