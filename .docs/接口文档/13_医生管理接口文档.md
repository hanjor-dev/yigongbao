### 13.1 分页查询医生列表

**接口地址**：`POST /basic/doctor/page`

**是否需要认证**：是

**接口说明**：分页查询医生列表，支持按医生姓名、医院ID、科室ID、状态等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| doctorName | String | 否 | 医生姓名（模糊查询） | - |
| hospitalId | Long | 否 | 所属医院ID | - |
| hospitalDeptId | Long | 否 | 所属科室ID | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /basic/doctor/page
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "pageNum": 1,
    "pageSize": 10,
    "hospitalId": 1,
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 医生列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "doctorName": "张医生",
                "doctorPhone": "13800138001",
                "hospitalId": 1,
                "hospitalName": "某某医院",
                "hospitalDeptId": 1,
                "hospitalDeptName": "心内科",
                "creatorId": 1,
                "orderCount": 5,
                "status": 1,
                "statusName": "正常",
                "remark": "主治医师",
                "createTime": "2026-03-01 10:00:00",
                "createBy": 1
            }
        ],
        "total": 100,
        "size": 10,
        "current": 1,
        "pages": 10
    }
}
```

### 13.4 创建医生

**接口说明**：创建新医生信息。医生姓名与所属医院联合唯一，不可重复。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |

**请求示例**：
```json
{
    "doctorName": "张医生",

    "hospitalDeptId": 1,
    "remark": "心内科主治医师"
}
```

| 参数名 | 类型 | 说明 |

## 业务说明

### 医生管理

医生管理用于维护医院下的医生信息，支持业务员通过联想功能快速选择历史医生。

### 医生联想功能

`/basic/doctor/suggest` 接口用于订单创建流程中医生字段的联想，返回当前业务员之前在该医院创建过的医生记录，通过 `creatorId` 字段过滤。

### 快速添加医生

`/basic/doctor/quick-add` 接口用于订单创建流程中直接新建医生，与普通创建接口的区别是不会校验医生姓名是否已存在，允许同一医院下存在同名医生记录。

### 创建人记录

医生的 `creatorId` 记录了创建该医生记录的业务员ID（用户ID），用于医生联想时的数据过滤。
