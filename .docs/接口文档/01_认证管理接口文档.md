# 01_认证管理接口文档

## 基本信息

| 项目 | 说明 |
|------|------|
| 所属模块 | system（系统管理） |
| Controller | AuthController + tianai-captcha 自动注册 |
| 请求前缀 | /system/auth（认证接口）、/captcha（滑动验证码接口） |
| 认证要求 | 部分接口需登录，详见各接口说明 |

## 接口列表

### 1.1 生成行为验证码

**接口地址**：`GET /image-captch/genCaptcha?type={type}`

**是否需要认证**：否

**接口说明**：密码登录（PASSWORD 类型）前调用，生成图像行为验证码。支持多种验证码类型，不传 `type` 时默认为滑块（`SLIDER`）。前端展示验证码，用户操作完成后将返回的 `id` 和前端采集的轨迹数据一并提交至校验接口或随登录请求提交。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | String | 否 | 验证码类型，默认 `SLIDER`；可选值：`SLIDER`（滑块）、`ROTATE`（旋转）、`WORD_IMAGE_CLICK`（文字点选）、`CONCAT`（拼图） |

**响应说明**：直接返回 tianai-captcha 框架的 `ApiResponse<ImageCaptchaVO>`，不封装在统一 `Result` 中。

**响应参数（`repData` 字段）**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| id | String | 验证码 id，校验时回传 |
| type | String | 验证码类型 |
| backgroundImage | String | 背景图（Base64） |
| templateImage | String | 滑块/模板图（Base64） |
| backgroundImageWidth | Integer | 背景图宽度（px） |
| backgroundImageHeight | Integer | 背景图高度（px） |
| templateImageWidth | Integer | 模板图宽度（px） |
| templateImageHeight | Integer | 模板图高度（px） |

**响应示例**：
```json
{
  "code": "0000",
  "msg": "success",
  "data": {
    "id": "d5a9f3e2-1234-5678-abcd-ef0123456789",
    "type": "SLIDER",
    "backgroundImage": "data:image/png;base64,...",
    "templateImage": "data:image/png;base64,...",
    "backgroundImageWidth": 320,
    "backgroundImageHeight": 160,
    "templateImageWidth": 60,
    "templateImageHeight": 60
  }
}
```

> `repData.id` 即后续提交的验证码 id。

### 1.1.1 校验行为验证码

**接口地址**：`POST /image-captch/check`

**是否需要认证**：否

**接口说明**：提交用户操作产生的轨迹数据进行校验。校验成功后 id 即失效，请勿重复使用同一 id 提交登录。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | String | 是 | 验证码 id（由生成接口返回的 `repData.id`） |
| data | Object | 是 | 前端采集的轨迹数据（`ImageCaptchaTrack`，见文末数据结构） |

**请求示例**：
```json
{
  "id": "d5a9f3e2-1234-5678-abcd-ef0123456789",
  "data": {
    "trackList": [...],
    "startSlidingTime": 1714000000000,
    "endSlidingTime": 1714000003000,
    "bgImageWidth": 320,
    "bgImageHeight": 160,
    "sliderImageWidth": 60,
    "sliderImageHeight": 60,
    "percentagex": 0.875,
    "percentagey": 0.5
  }
}
```

**响应说明**：校验成功时返回 `{id}`，失败时返回错误信息，格式均为 `ApiResponse`。

**响应示例（成功）**：
```json
{
  "code": "0000",
  "msg": "success",
  "data": {
    "id": "d5a9f3e2-1234-5678-abcd-ef0123456789"
  }
}
```

**接口地址**：`POST /system/auth/captcha`

**是否需要认证**：否

**接口说明**：手机号（PHONE）登录前调用此接口发送验证码。

### 1.3 用户登录

**接口地址**：`POST /system/auth/login`

**是否需要认证**：否

**接口说明**：支持两种登录方式，通过 `loginType` 区分。密码登录建议先获取滑动验证码；手机登录需先发送验证码。

**登录类型说明**：

| loginType | principal | credential | 额外字段 |
|-----------|-----------|------------|----------|
| `PASSWORD` | 用户名 **或** 邮箱（自动识别） | 密码 | `captchaKey`（行为验证码 id）、`captchaTrack`（轨迹数据，过渡期可不传） |
| `PHONE` | 手机号 | 短信验证码 | 无 |

> `PASSWORD` 登录时，`principal` 字段支持输入**用户名**或**邮箱**，系统通过判断值是否符合邮箱格式来自动路由查询字段：邮箱格式走 `email` 字段匹配，否则走 `username` 字段匹配。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| loginType | String | 是 | 登录类型：`PASSWORD` / `PHONE` |
| principal | String | 是 | 登录凭据主体（用户名/邮箱/手机号） |
| credential | String | 是 | 登录凭据（密码/验证码） |
| captchaKey | String | 否 | 滑动验证码 id（由 GET /captcha/get 返回） |
| captchaTrack | Object | 否 | 滑动轨迹数据（captchaKey 有值时必传） |

**请求示例（密码登录，含滑动验证码）**：
```json
{
    "loginType": "PASSWORD",
    "principal": "admin",
    "credential": "123456",
    "captchaKey": "d5a9f3e2-...",
    "captchaTrack": {
        "trackList": [...],
        "startSlidingTime": 1714000000000,
        "endSlidingTime": 1714000003000,
        "trackLength": 280,
        "bgImageWidth": 320,
        "bgImageHeight": 160,
        "sliderImageWidth": 60,
        "sliderImageHeight": 60,
        "percentagex": 0.875,
        "percentagey": 0.5
    }
}
```

**请求示例（密码登录，兼容旧格式，过渡期使用）**：
```json
{
    "username": "admin",
    "password": "123456"
}
```

**请求示例（密码登录，用邮箱作为账号）**：
```json
{
    "loginType": "PASSWORD",
    "principal": "admin@example.com",
    "credential": "123456"
}
```

**请求示例（手机验证码登录）**：
```json
{
    "loginType": "PHONE",
    "principal": "13800138000",
    "credential": "123456"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| token | String | 认证 Token（后续请求需在 Header 中携带） |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "token": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx"
    }
}
```

> 登录接口仅返回 token，菜单和权限通过 `GET /system/auth/info` 获取。

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败 |
| 774 | 滑动验证码校验失败（CAPTCHA_GRAPHIC_ERROR） |
| 608 | 用户名或密码错误 |
| 602 | 账户已被禁用 |
| 609 | 账户已锁定，返回剩余分钟数 |

### 1.6 修改密码

**接口地址**：`PUT /system/auth/password`

**是否需要认证**：是

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| oldPassword | String | 是 | 旧密码 |
| newPassword | String | 是 | 新密码，长度 6-20 位 |

**请求示例**：
```json
{
    "oldPassword": "123456",
    "newPassword": "abcdef"
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 606 | 旧密码不正确 |
| 607 | 新密码与旧密码相同 |
| 400 | 新密码长度不符合要求（6-20 位） |

### 1.7 发送忘记密码验证码

**接口地址**：`POST /system/auth/forgot-password/captcha`

**是否需要认证**：否

**接口说明**：忘记密码流程第一步。无论目标是否注册，接口始终返回成功（防止用户枚举攻击）。

| target | String | 是 | 手机号或邮箱 |

**请求示例**：
```json
{
    "captchaType": "EMAIL",
    "target": "admin@example.com"
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

### 1.8 忘记密码重置

**接口地址**：`POST /system/auth/forgot-password/reset`

**是否需要认证**：否

**接口说明**：忘记密码流程第二步，校验验证码并重置密码，同时解除账户锁定。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| captchaType | String | 是 | 验证码类型：`PHONE` / `EMAIL` |
| target | String | 是 | 手机号或邮箱 |
| captcha | String | 是 | 收到的验证码 |
| newPassword | String | 是 | 新密码，长度 6-20 位 |

**请求示例**：
```json
{
    "captchaType": "PHONE",
    "target": "13800138000",
    "captcha": "123456",
    "newPassword": "newpass123"
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 639 | 验证码已过期或不存在 |
| 640 | 验证码错误 |
| 400 | 新密码长度不符合要求（6-20 位） |
| 600 | 手机号/邮箱未注册 |

## 认证说明

### Token 使用方式

登录成功后，服务端返回 Token，前端需在后续所有请求的 Header 中携带：

```http
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

### Token 有效期

Token 默认有效期 30 天（可配置），过期后需重新登录。

### 登录失败限制

连续密码错误 5 次后账户锁定（默认 15 分钟，可配置）。

### 登录流程说明

```
密码登录：GET /image-captch/genCaptcha → POST /image-captch/check → POST /login (loginType=PASSWORD, captchaKey=id)
手机登录：POST /system/auth/captcha (PHONE) → POST /login (loginType=PHONE)
忘记密码：POST /forgot-password/captcha → POST /forgot-password/reset
```
