# 01_认证管理接口文档

## 基本信息

| 项目 | 说明 |
|------|------|
| 所属模块 | system（系统管理） |
| Controller | AuthController |
| 请求前缀 | /system/auth |
| 认证要求 | 部分接口需登录，详见各接口说明 |

## 接口列表

### 1.1 用户登录

**接口地址**：`POST /system/auth/login`

**是否需要认证**：否

**接口说明**：用户使用用户名和密码登录系统，登录成功后返回 Token 和用户信息。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名 |
| password | String | 是 | 密码 |

**请求示例**：
```json
{
    "username": "admin",
    "password": "123456"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 响应数据 |
| data.token | String | 认证 Token（后续请求需在 Header 中携带） |
| data.user | UserVO | 用户信息 |
| data.menus | Array | 菜单树（用于侧边栏渲染） |
| data.permissions | Array | 权限列表（按钮级权限） |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "token": "xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
        "user": {
            "id": 1,
            "username": "admin",
            "realName": "管理员",
            "phone": "13800138000",
            "email": "admin@example.com",
            "orgName": "医工宝科技",
            "deptName": "技术部",
            "roleName": "超级管理员"
        },
        "menus": [
            {
                "id": 1,
                "resourceName": "系统管理",
                "path": "/system",
                "children": []
            }
        ],
        "permissions": ["user:add", "user:edit", "user:delete"]
    }
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 401 | 用户名或密码错误 |
| 403 | 账户已被禁用 |

### 1.2 用户登出

**接口地址**：`POST /system/auth/logout`

**是否需要认证**：是

**接口说明**：退出当前登录状态，使 Token 失效。

**请求参数**：无

**请求示例**：
```http
POST /system/auth/logout
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

### 1.3 获取当前用户信息

**接口地址**：`GET /system/auth/info`

**是否需要认证**：是

**接口说明**：获取当前登录用户的详细信息，包含菜单树和权限列表。用于前端初始化用户信息和动态渲染菜单/权限。

        "user": {
            "id": 1,
            "username": "admin",

            "accountType": 1,
            "accountTypeName": "内部用户",

            "orgName": "医工宝科技",

### 1.4 修改密码

**接口地址**：`PUT /system/auth/password`

**是否需要认证**：是

**接口说明**：修改当前登录用户的密码。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| oldPassword | String | 是 | 旧密码 |
| newPassword | String | 是 | 新密码，长度6-20位 |

**请求示例**：
```json
{
    "oldPassword": "123456",
    "newPassword": "abcdef"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 旧密码不正确 |
| 400 | 新密码格式不符合要求（长度6-20位） |

## 认证说明

### Token 使用方式

登录成功后，服务端返回 Token，前端需要在后续所有请求的 Header 中携带 Token：

```http
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

### Token 有效期

Token 默认有效期为 7 天（可配置），过期后需重新登录。

### 登录失败限制

系统支持登录失败次数限制，连续失败 5 次后账户将被锁定 30 分钟（可配置）。
