### 2.1 分页查询用户列表

**接口地址**：`POST /system/user/list`

**是否需要认证**：是

**接口说明**：分页查询用户列表，支持按用户名、真实姓名、机构ID、部门ID、账户类型、状态等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| username | String | 否 | 用户名（模糊查询） | - |
| realName | String | 否 | 真实姓名（模糊查询） | - |
| orgId | Long | 否 | 所属机构ID | - |
| deptId | Long | 否 | 所属部门ID | - |
| accountType | Integer | 否 | 账户分类（1=内部用户，2=外部用户） | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /system/user/list
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Content-Type: application/json

{
    "pageNum": 1,
    "pageSize": 10,
    "orgId": 1,
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 用户列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "username": "admin",
                "realName": "管理员",
                "phone": "13800138000",
                "email": "admin@example.com",
                "accountType": 1,
                "accountTypeName": "内部用户",
                "orgId": 1,
                "orgName": "医工宝科技",
                "deptId": 1,
                "deptName": "技术部",
                "roleId": 1,
                "roleName": "超级管理员",
                "status": 1,
                "statusName": "正常",
                "createTime": "2026-03-01 10:00:00"
```

### 2.3 创建用户

**接口地址**：`POST /system/user`

**是否需要认证**：是

**接口说明**：创建新用户。密码如不填写则使用系统默认密码（可在系统配置中修改）。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | String | 是 | 用户名，3-32字符 |
| password | String | 否 | 密码，不填使用系统默认 |
| realName | String | 是 | 真实姓名 |
| phone | String | 是 | 手机号，1[3-9]开头11位 |
| email | String | 否 | 邮箱 |
| sex | Integer | 否 | 性别 |
| avatar | String | 否 | 头像路径 |
| accountType | Integer | 是 | 账户分类（1=内部用户，2=外部用户） |
| orgId | Long | 是 | 所属机构ID |
| deptId | Long | 否 | 所属部门ID |
| roleId | Long | 否 | 关联角色ID |
| hospitalIds | Array | 否 | 医院ID列表（医院范围权限） |
| employeeNo | String | 否 | 工号 |
| specialtyList | List\<String\> | 否 | 专业方向字典编码列表（如 `["7.1","7.2"]`，设计师/设计师管理员角色必填） |
| qualification | String | 否 | 资质证书信息 |
| settlementType | Integer | 否 | 结算类型 |
| remark | String | 否 | 备注 |

**请求示例**：
```json
{
    "username": "zhangsan",
    "password": "123456",
    "realName": "张三",
    "phone": "13800138001",
    "email": "zhangsan@example.com",
    "sex": 1,
    "accountType": 1,
    "orgId": 1,
    "deptId": 1,
    "roleId": 2,
    "hospitalIds": [1, 2],
    "employeeNo": "EMP002",
    "specialtyList": ["7.1","7.2"],
    "remark": "新入职员工"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败（详见 message） |
| 617 | 用户名已存在 |
| 618 | 手机号已存在 |
| 636 | 邮箱已存在 |

## 业务说明

### 默认密码

创建用户时如不填写密码，系统将使用默认密码（可在系统配置中修改，默认为 `123456`）。

### 医院范围权限

当用户的角色的数据权限范围为 `dataScopeType="hospitals"` 时，用户只能在被分配的医院范围内进行业务操作。通过 `hospitalIds` 字段指定可访问的医院列表。

### 专业方向

`specialty` 字段存储的是字典值编码，如 "1"、"2" 等，具体含义需查询字典表。

### 结算类型

`settlementType` 字段用于标识用户（主要是外部用户/业务员）的薪酬结算方式，具体值需查询字典表。
