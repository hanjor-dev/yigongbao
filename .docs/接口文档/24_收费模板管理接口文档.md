## 接口列表

### 24.1 分页查询收费模板列表

**接口地址**：`GET /api/basic/charging-template/list`

**是否需要认证**：是

**接口说明**：分页查询收费模板列表，支持按模板名称模糊搜索。

**请求参数**（Query）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pageNum | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页大小，默认10 |
| templateName | String | 否 | 模板名称（模糊查询） |

**请求示例**：
```http
GET /api/basic/charging-template/list?pageNum=1&pageSize=10&templateName=标准
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据对象 |
| data.records | Array | 模板列表 |
| data.total | Long | 总记录数 |
| data.size | Long | 每页大小 |
| data.current | Long | 当前页码 |
| data.pages | Long | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "templateName": "标准收费模板",
                "remark": "适用于普通业务账号",
                "status": 1,
                "statusName": "正常",
                "createTime": "2026-06-08 14:00:00",
                "updateTime": "2026-06-08 14:00:00"

        ],
        "total": 1,
        "size": 10,
        "current": 1,
```

### 24.2 查询收费模板详情

**接口地址**：`GET /api/basic/charging-template/{id}`

### 24.3 创建收费模板

**接口地址**：`POST /api/basic/charging-template`

**是否需要认证**：是

**接口说明**：创建新的收费模板，包含模板基本信息和价格明细。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| templateName | String | 是 | 模板名称，长度1-100字符 |
| remark | String | 否 | 备注说明，最大512字符 |
| status | Integer | 否 | 状态（0=禁用，1=正常），默认1 |
| items | Array | 是 | 模板明细列表，至少1项 |
| items[].rebuildProjectId | Long | 是 | 重建项目ID |
| items[].price | Decimal | 是 | 收费价格，0.01-9999999.99 |

**请求示例**：
```json
POST /api/basic/charging-template
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "templateName": "标准收费模板",
    "remark": "适用于普通业务账号",
    "status": 1,
    "items": [
        {
            "rebuildProjectId": 1,
            "price": 5000.00
        },
        {
            "rebuildProjectId": 2,
            "price": 3000.00
        }
    ]
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Long | 新创建的模板ID |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": 1
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 788 | 收费模板名称已存在 |
| 789 | 重建项目不存在或已停用 |
| 790 | 同一模板中存在重复的重建项目 |

## 业务说明

### 窗口期差异

收费模板可能与系统当前活跃的重建项目存在差异：

- **缺失项目（missingCount）**：系统中新增的活跃项目，但模板中尚未配置价格
- **过时项目（obsoleteCount）**：模板中已配置价格，但对应的重建项目已被删除或禁用

查询模板详情时会自动计算这些差异统计，帮助管理员及时发现并更新模板。

### 数据完整性

- 模板名称必须唯一
- 同一模板内不能有重复的重建项目
- 重建项目必须是当前活跃状态（status=1）
- 删除模板时会级联删除所有明细项
