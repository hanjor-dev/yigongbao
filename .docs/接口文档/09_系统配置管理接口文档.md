## 接口列表

### 9.1 分页查询配置列表

**接口地址**：`POST /system/config/list`

**是否需要认证**：是

**接口说明**：分页查询系统配置列表，支持按配置键、配置名称、配置分组、配置类型、状态等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| configKey | String | 否 | 配置键（模糊查询） | - |
| configName | String | 否 | 配置名称（模糊查询） | - |
| configGroup | String | 否 | 配置分组 | - |
| configType | String | 否 | 配置类型 | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /system/config/list
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Content-Type: application/json

{
    "pageNum": 1,
    "pageSize": 10,
    "configGroup": "security",
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 配置列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "configKey": "default.password",
                "configName": "默认密码",
                "configValue": "123456",
                "configType": "string",
                "configGroup": "security",
                "configDesc": "新用户初始密码",
                "isSystem": 1,
                "isPublic": 1,
                "sort": 1,
                "status": 1,
                "createTime": "2026-03-01 10:00:00"
            },
            {
                "id": 2,
                "configKey": "login.max.failures",
                "configName": "最大连续登录失败次数",
                "configValue": "5",
                "configType": "number",
                "configGroup": "security",
                "configDesc": "连续失败后锁定账号",
                "isSystem": 1,
                "isPublic": 1,
                "sort": 2,
                "status": 1,
                "createTime": "2026-03-01 10:00:00"
            }
        ],
        "total": 20,
        "size": 10,
        "current": 1,
        "pages": 2
    }
}
```

### 9.3 创建配置

**接口地址**：`POST /system/config`

**是否需要认证**：是

**接口说明**：创建新的系统配置项。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| configKey | String | 是 | 配置键，最大64字符 |
| configName | String | 是 | 配置名称，最大128字符 |
| configValue | String | 否 | 配置值 |
| configType | String | 否 | 配置类型（默认string） |
| configGroup | String | 是 | 配置分组 |
| configDesc | String | 否 | 配置说明，最大256字符 |
| isSystem | Integer | 否 | 是否系统内置（默认0） |
| isPublic | Integer | 否 | 是否公开（默认1） |
| sort | Integer | 否 | 排序（默认0） |
| status | Integer | 否 | 状态（默认1） |

**请求示例**：
```json
{
    "configKey": "max.upload.size",
    "configName": "文件上传最大大小",
    "configValue": "10485760",
    "configType": "number",
    "configGroup": "system",
    "configDesc": "文件上传最大大小（字节），默认10MB",
    "isSystem": 1,
    "isPublic": 1,
    "sort": 10,
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 配置键已存在 |
| 400 | 参数校验失败 |

## 业务说明

### 配置分组

常见配置分组包括：
- `system` - 系统配置（业务参数：订单、流程、设计等）
- `security` - 安全配置（密码策略、登录锁定、短信间隔）
- `file` - 文件配置（上传大小、各业务类型允许的扩展名）
- `other` - 其他配置

### 配置类型

| 类型值 | 说明 |
|--------|------|
| string | 字符串类型 |
| number | 数字类型 |
| boolean | 布尔类型 |
| json | JSON类型 |

### 系统内置配置

系统内置配置（`isSystem=1`）不允许修改和删除，用于保护关键系统参数。

### 配置使用方式

前端通过调用 `GET /system/config/public` 获取公开配置，或通过后端 `ConfigService.getConfigValue(key)` 方法获取配置值。
