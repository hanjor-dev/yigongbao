### 8.7 创建字典

**接口说明**：创建新的字典项。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |

```json
    "sort": 10,
    "status": 1,
    "remark": "用于订单流程管理"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
```

### 8.9 删除字典

**接口地址**：`DELETE /system/dict/{id}`

**是否需要认证**：是

**接口说明**：删除指定字典（逻辑删除）。如果字典存在子节点，则不允许删除。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 字典ID |

**请求示例**：
```http
DELETE /system/dict/10
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null

```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 404 | 字典不存在 |
| 400 | 字典存在子节点，无法删除 |

### 8.10 修改字典状态（级联）

**接口地址**：`PUT /system/dict/{id}/status`

**是否需要认证**：是

**接口说明**：修改字典状态，并级联修改所有子节点的状态。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 字典ID |

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| status | Integer | 是 | 状态值，范围0-1（0=禁用，1=正常） |

**请求示例**：
```http
PUT /system/dict/9/status?status=0
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**业务说明**：此接口会同时禁用/启用父节点和所有子节点。

## 业务说明

### 字典编码规则

字典编码采用层级数字格式：
- 顶级类型：如 "1"、"2"、"user_status"
- 二级数据：如 "1.1"、"1.2"、"user_status.1"
- 三级数据：如 "1.1.1"、"1.1.2"

### 字典层级

| 层级 | level值 | 说明 | 用途 |
|------|---------|------|------|
| 字典类型 | 1 | 无 dictValue | 用于分组，下拉列表中不显示 |
| 字典数据 | 2 | 有 dictValue | 实际的选项值，用于下拉选择 |

### 级联操作

- 删除字典时，如果存在子节点则不允许删除
- 修改状态时，会同时修改所有子节点的状态
