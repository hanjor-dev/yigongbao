# 10_基础数据下拉选项接口文档

## 基本信息

| 项目 | 说明 |
|------|------|
| 所属模块 | system（系统管理）/ order（订单管理） |
| Controller | SelectController（/system/select）、FlowSelectController（/flow/select） |
| 请求前缀 | /system/select、/flow/select |
| 认证要求 | 需要登录认证 |

## 接口列表

### 10.1 获取树形结构

**接口地址**：`POST /system/select/tree`

**是否需要认证**：是

**接口说明**：获取树形结构数据，支持地区树和字典树两种类型。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| type | String | 是 | 数据类型（area=地区，dict=字典） |
| code | String | 条件必填 | 字典编码（type=dict时必填） |
| parentId | Long | 条件必填 | 父级ID（type=area时必填，默认0） |

**请求示例**：
```json
POST /system/select/tree
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "type": "area",
    "parentId": 0
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Array | 树形结构列表 |

**响应示例（地区树）**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": [
        {
            "id": 1,
            "name": "北京市",
            "value": "110000",
            "parentId": 0,
            "level": 1,
            "children": [
                {
                    "id": 2,
                    "name": "东城区",
                    "value": "110101",
                    "parentId": "110000",
                    "level": 2,
                    "children": []
                }
            ]
        }
    ]
}
```

**响应示例（字典树）**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": [
        {
            "id": 9,
            "name": "用户状态",
            "value": null,
            "parentId": 0,
            "level": 1,
            "children": [
                {
                    "id": 10,
                    "name": "正常",
                    "value": "1",
                    "parentId": 9,
                    "level": 2,
                    "children": []
                },
                {
                    "id": 11,
                    "name": "禁用",
                    "value": "0",
                    "parentId": 9,
                    "level": 2,
                    "children": []
                }
            ]
        }
    ]
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 缺少必要参数 |
| 400 | 不支持的数据类型 |

### 10.6 获取流转状态下拉列表

**接口地址**：`POST /flow/select/statuses`

**是否需要认证**：是

**接口说明**：返回 `FlowStatusEnum` 枚举值，可通过 `phase` 参数过滤指定阶段的状态。状态值编码规则：`阶段值 × 100 + 序号 × 10`（如订单阶段 10 → 1010, 1020, 1030...）。

**请求参数**（Query String）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phase | Integer | 否 | 阶段值（10/20/30/40/50/60/70/80），不传则返回全部状态 |

**请求示例**：
```
POST /flow/select/statuses?phase=10
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| data | Array | 状态列表 |
| data[].name | String | 状态名称（中文） |
| data[].value | String | 状态数值字符串 |

**响应示例（phase=10，仅返回订单阶段状态）**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1744800000000,
    "data": [
        {"name": "草稿", "value": "1010"},
        {"name": "数据待审核", "value": "1020"},
        {"name": "数据审核通过", "value": "1030"},
        {"name": "数据审核不通过", "value": "1040"}
    ]
}
```

**响应示例（不传 phase，返回所有状态）**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1744800000000,
    "data": [
        {"name": "草稿", "value": "1010"},
        {"name": "数据待审核", "value": "1020"},
        {"name": "数据审核通过", "value": "1030"},
        {"name": "数据审核不通过", "value": "1040"},
        {"name": "待设计", "value": "2010"},
        {"name": "设计中", "value": "2020"},
        ...
    ]
}
```

## 业务说明

### type 类型说明

| type值 | 说明 | 必填参数 |
|--------|------|----------|
| area | 地区树/下拉 | parentId（父级ID，默认0） |
| dict | 字典树/下拉 | code（字典编码） |
| config_group | 配置分组下拉 | 无 |

### 使用场景

1. **地区选择**：通过 `type=area` 获取省市区树形结构，用于医院地址选择等场景
2. **字典下拉**：通过 `type=dict` 获取字典下拉选项，用于表单中的下拉选择
3. **配置分组**：通过 `type=config_group` 获取配置分组列表，用于系统配置页面的分组选择
4. **文件业务类型**：通过 `biz-type-list` 获取所有可用的文件业务类型
5. **流转阶段**：通过 `/flow/select/phases` 获取所有阶段，用于订单列表等页面的阶段筛选下拉
6. **流转状态**：通过 `/flow/select/statuses` 获取状态列表，支持按阶段过滤，用于订单状态筛选下拉

### 字典编码获取方式

字典编码可以通过以下方式获取：
1. 调用 `GET /system/dict/type/list` 获取所有字典类型
2. 在字典表中查看 dict_code 字段
