## 接口列表

### 6.1 分页查询机构列表

**接口地址**：`POST /system/org/list`

**是否需要认证**：是

**接口说明**：分页查询机构列表，支持按机构名称、机构类型、地区、状态等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| orgName | String | 否 | 机构名称（模糊查询） | - |
| orgType | String | 否 | 机构类型（字典编码） | - |
| areaId | Long | 否 | 地区ID | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /system/org/list
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Content-Type: application/json

{
    "pageNum": 1,
    "pageSize": 10,
    "orgType": "manufacturer",
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 机构列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "orgName": "医工宝科技有限公司",
                "orgCode": "ORG001",
                "orgType": "manufacturer",
                "orgTypeName": "生产厂家",
                "areaId": 1,
                "areaName": "北京市",
                "address": "北京市朝阳区xxx路",
                "contact": "张三",
                "phone": "010-12345678",
                "email": "contact@example.com",
                "status": 1,
                "statusName": "正常",
                "createTime": "2026-03-01 10:00:00"
            }
        ],
        "total": 50,
        "size": 10,
        "current": 1,
        "pages": 5
    }
}
```

### 6.3 创建机构

**接口地址**：`POST /system/org`

**是否需要认证**：是

**接口说明**：创建新机构。系统自动生成机构编码。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| orgName | String | 是 | 机构名称，最大128字符 |
| orgType | String | 否 | 机构类型（字典编码） |
| areaId | Long | 否 | 所属地区ID |
| address | String | 否 | 详细地址，最大256字符 |
| contact | String | 否 | 联系人，最大32字符 |
| phone | String | 否 | 联系电话（手机号格式） |
| email | String | 否 | 联系邮箱 |
| creditCode | String | 否 | 统一社会信用代码 |
| businessLicense | String | 否 | 营业执照路径，最大512字符 |
| agentArea | String | 否 | 代理区域（经销商），最大64字符 |
| agentProductLine | String | 否 | 代理产品线，最大256字符 |
| hospitalLevel | String | 否 | 医院等级（字典编码=3） |
| hospitalType | String | 否 | 医院类型（字典编码=4） |
| remark | String | 否 | 备注，最大512字符 |

**请求示例**：
```json
{
    "orgName": "北京医疗器械公司",
    "orgType": "distributor",
    "areaId": 1,
    "address": "北京市海淀区xxx路",
    "contact": "李四",
    "phone": "13800138000",
    "email": "sales@example.com",
    "creditCode": "91110000XXXXXXXXYY",
    "agentArea": "华北地区",
    "agentProductLine": "1,2,3",
    "remark": "新签约经销商"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败 |

### 6.5 删除机构

**是否需要认证**：是

**接口说明**：删除指定机构（逻辑删除）。如果机构下有关联的用户或部门，则不允许删除。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 机构ID |

**响应参数**：

| 参数名 | 类型 | 说明 |

| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
```

### 6.7 全量查询机构列表（用于下拉选择）

**接口地址**：`GET /system/org/all`

**是否需要认证**：是

**接口说明**：全量查询所有机构列表，返回包含字典名称的完整机构信息，用于前端下拉选择组件，无需分页。

**请求参数**：无

**请求示例**：
```http
GET /system/org/all
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

|| 参数名 | 类型 | 说明 |
|--------|------|------|
|| code | Integer | 状态码，200表示成功 |
|| message | String | 响应消息 |
|| timestamp | Long | 时间戳 |
|| data | Array | 机构列表 |
|| data[].id | Long | 机构ID |
|| data[].orgName | String | 机构名称 |
|| data[].orgCode | String | 机构编码 |
|| data[].orgType | String | 机构类型（字典编码） |
|| data[].orgTypeName | String | 机构类型名称 |
|| data[].areaId | Long | 地区ID |
|| data[].areaName | String | 地区名称 |
|| data[].status | Integer | 状态（0=禁用，1=正常） |
|| data[].statusName | String | 状态名称 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": [
        {
            "id": 1,
            "orgName": "测试医疗机构",
            "orgCode": "ORG-H-001",
            "orgType": "3",
            "orgTypeName": "医疗机构",
            "areaId": 1,
            "areaName": "北京市",
            "status": 1,
            "statusName": "正常"
        }
    ]
}
```

**业务说明**：
- 返回所有未删除的机构，按机构名称升序排列
- 包含完整的字典名称字段，方便前端直接展示

## 业务说明

### 机构类型

机构类型通过字典管理，常见类型包括：
- `manufacturer` - 生产厂家
- `distributor` - 经销商
- `hospital` - 医院（实际上医院在 basic 模块单独管理）

### 代理产品线

`agentProductLine` 字段存储的是逗号分隔的字典值编码，如 "1,2,3"，`agentProductLineNames` 字段存储对应的名称列表。

### 机构与用户的关系

- 一个机构可以包含多个部门
- 一个机构可以包含多个用户
- 删除机构前需要先删除关联的用户和部门
