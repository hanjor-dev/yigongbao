## 接口列表

### 18.1 分页查询操作日志

**接口地址**：`POST /basic/operation-log/page`

**是否需要认证**：是

**接口说明**：分页查询操作日志列表，支持按模块名称、操作描述、操作用户名、请求IP、操作状态、时间范围等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| module | String | 否 | 模块名称（模糊查询） | - |
| businessType | Integer | 否 | 业务类型 | - |
| operation | String | 否 | 操作描述（模糊查询） | - |
| username | String | 否 | 操作用户名（模糊查询） | - |
| ip | String | 否 | 请求IP | - |
| status | Integer | 否 | 操作状态（0=失败，1=成功） | - |
| startTime | String | 否 | 开始时间（格式 yyyy-MM-dd） | - |
| endTime | String | 否 | 结束时间（格式 yyyy-MM-dd） | - |

**请求示例**：
```json
POST /basic/operation-log/page
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "pageNum": 1,
    "pageSize": 10,
    "module": "用户管理",
    "status": 1,
    "startTime": "2026-03-01",
    "endTime": "2026-03-30"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 操作日志列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "userId": 1,
                "username": "admin",
                "realName": "管理员",
                "module": "用户管理",
                "businessType": 1,
                "businessTypeName": "新增",
                "operation": "创建用户",
                "description": "创建用户 zhangsan",
                "requestMethod": "POST",
                "requestUrl": "/system/user",
                "requestParams": "{\"username\":\"zhangsan\",\"realName\":\"张三\",...}",
                "ip": "192.168.1.100",
                "location": "广东省深圳市",
                "status": 1,
                "statusName": "成功",
                "errorMessage": null,
                "duration": 156,
                "operationTime": "2026-03-30 10:00:00"
            }
        ],
        "total": 100,
        "size": 10,
        "current": 1,
        "pages": 10
    }
}
```

### 18.2 导出操作日志

**接口地址**：`POST /basic/operation-log/export`

**是否需要认证**：是

**接口说明**：导出操作日志为 Excel 文件。导出符合条件的所有记录，不受分页限制。结果直接输出为文件流到 HTTP 响应。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| module | String | 否 | 模块名称（模糊查询） |
| businessType | Integer | 否 | 业务类型 |
| operation | String | 否 | 操作描述（模糊查询） |
| username | String | 否 | 操作用户名（模糊查询） |
| ip | String | 否 | 请求IP |
| status | Integer | 否 | 操作状态（0=失败，1=成功） |
| startTime | String | 否 | 开始时间（格式 yyyy-MM-dd） |
| endTime | String | 否 | 结束时间（格式 yyyy-MM-dd） |

**请求示例**：
```json
POST /basic/operation-log/export
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "module": "用户管理",
    "startTime": "2026-03-01",
    "endTime": "2026-03-30"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| Content-Type | String | application/vnd.openxmlformats-officedocument.spreadsheetml.sheet |
| Content-Disposition | String | attachment; filename=operation_log_20260330_100000.xlsx |

**响应示例**：
```
HTTP/1.1 200 OK
Content-Type: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet
Content-Disposition: attachment; filename=operation_log_20260330_100000.xlsx

[Excel文件二进制流]
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 导出条件不合法 |
| 500 | 导出失败 |

## 业务说明

### 日志记录机制

操作日志由系统切面自动记录，**无需业务代码手动处理**。记录范围为所有带有 `@OperationLog` 注解的 Controller 方法。

### 敏感信息脱敏

`requestParams` 字段中的敏感信息已做脱敏处理，包括但不限于：
- 密码字段（替换为 `******`）
- 身份证号（部分位数替换为 `*`）
- 银行卡号（部分位数替换为 `*`）
- 手机号（部分位数替换为 `*`）

### 业务类型说明

| 业务类型值 | 说明 |
|------------|------|
| 1 | 新增 |
| 2 | 修改 |
| 3 | 删除 |
| 4 | 查询 |
| 5 | 导出 |
| 6 | 其他 |

### 查询时间范围

`startTime` 和 `endTime` 参数格式为 `yyyy-MM-dd`，表示日期范围。当只传入 `startTime` 时，查询该日期及之后的所有记录；当只传入 `endTime` 时，查询该日期及之前的所有记录。

### 导出文件命名

导出的 Excel 文件名格式为 `operation_log_yyyyMMdd_HHmmss.xlsx`，其中时间戳为导出时刻的时间。
