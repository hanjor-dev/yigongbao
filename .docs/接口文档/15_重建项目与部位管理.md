# 15_重建项目与部位管理

## 基本信息

| 项目 | 说明 |
|------|------|
| 所属模块 | basic（基础管理） |
| Controller | BodyPartController、RebuildProjectController |
| 请求前缀 | /basic/body-part、/basic/rebuild-project |
| 认证要求 | 需要登录认证 |

## 接口列表

### 15.1 获取部位列表

**接口地址**：`POST /basic/body-part/list`

**是否需要认证**：是

**接口说明**：获取所有部位的平级列表，按 sort 升序、createTime 降序排列，返回全量数据（不分页）。

**请求参数**（JSON Body）：无

**请求示例**：
```json
POST /basic/body-part/list
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Array | 部位平级列表 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,

            "updateTime": "2026-03-01 10:00:00"

        {
            "id": 2,
            "name": "颌面",
            "code": "BP-0002",
            "sort": 2,
            "status": 1,
            "statusName": "正常",
            "remark": null,
            "createTime": "2026-03-01 10:00:00",
            "updateTime": "2026-03-01 10:00:00"

```

### 15.3 创建部位

**接口地址**：`POST /basic/body-part`

**是否需要认证**：是

**接口说明**：创建新的部位数据，系统自动生成部位编码。部位名称全局唯一。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 部位名称，最大100字符，全局唯一 |
| sort | Integer | 否 | 排序（默认0） |
| status | Integer | 否 | 状态（0=禁用，1=正常） |
| remark | String | 否 | 备注 |

**请求示例**：
```json
{
    "name": "颅骨",
    "sort": 1,
    "status": 1,
    "remark": "颅骨区域"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败（详见 message） |
| 663 | 部位名称已存在 |

### 15.7 获取项目树形结构

**接口地址**：`POST /basic/rebuild-project/tree`

**是否需要认证**：是

**接口说明**：获取完整的重建项目树形结构，支持按项目分类筛选和名称关键字搜索，返回所有项目数据（不限状态）。有 keyword 时只返回名称匹配的项目及其子项目，关键字搜索对父子项目分别独立匹配。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| categoryCode | String | 否 | 项目分类编码（字典 dict_code=13，精确匹配，如 13.1=模型） |
| keyword | String | 否 | 项目名称关键字（模糊搜索，不传则返回全部） |

**请求示例**：
```json
POST /basic/rebuild-project/tree
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "categoryCode": "13.1",
    "keyword": "颅骨"
}
```

| data | Array | 重建项目树形列表 |

### 15.9 获取完整部位-项目树形结构

**接口地址**：`POST /basic/rebuild-project/full-tree`

**是否需要认证**：是

**接口说明**：返回完整的三层嵌套结构（部位 → 项目 → 子项目），只包含有启用项目的部位，支持按项目分类筛选、按部位过滤和名称关键字搜索。有 keyword 时只返回名称匹配的项目及其父项目，无匹配项目的部位不出现在结果中。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| categoryCode | String | 否 | 项目分类编码（字典 dict_code=13，精确匹配） |
| bodyPartId | Long | 否 | 部位ID（传入则只返回该部位的数据） |
| keyword | String | 否 | 项目名称关键字（模糊搜索，不传则返回全部；有 keyword 时无匹配项目的部位不出现） |

**请求示例**：
```json
POST /basic/rebuild-project/full-tree
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
    "categoryCode": "13.3",
    "bodyPartId": 1,
    "keyword": "修补"
}
```

**响应参数**：

| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Array\<BodyPartProjectTreeVO\> | 部位-项目树形列表 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
```

| name | String | 是 | 项目名称，最大100字符 |
| standardPrice | BigDecimal | 否 | 标准价格 |

| message | String | 响应消息 |
| timestamp | Long | 时间戳 |

## 业务说明

### 部位平级结构

部位采用平级列表管理，每条记录即为一个具体部位（如"颅骨"、"颌面"、"颈椎"），名称全局唯一。

### 重建项目树形结构

重建项目采用树形结构：
- 顶级（level=1）：重建项目，如"颅骨修补术"
- 二级（level=2）：子重建项目，如"PEEK材料颅骨修补"

### 部位与项目关联

部位和重建项目通过 `bodyPartId` 字段关联，一个部位下可以包含多个重建项目。

### 完整树形结构（full-tree）

`/full-tree` 接口返回三层嵌套：部位 → 项目 → 子项目。只返回有启用项目的部位节点，没有项目的部位不出现在结果中。支持三个可选过滤参数：`bodyPartId`（按部位精确过滤）、`categoryCode`（按分类精确筛选）、`keyword`（按项目名称模糊搜索）。有 keyword 时，无匹配项目的部位不出现在结果中。

### 价格说明

- `standardPrice`：标准价格，正常流程下的项目费用
- `urgentPrice`：加急价格，加急流程下的项目费用

### 预计耗时

`estimatedHours` 字段存储预计耗时，单位为小时，用于生产排期参考。

### 分类筛选

`categoryCode` 字段存储项目分类的字典编码（dict_code=13），传入时精确匹配，不传则返回全部。

重建项目分类字典值（dict_code=13）：

| dict_code | dict_name | 说明 |
|-----------|-----------|------|
| 13.1 | 模型 | 3D 模型类项目 |
| 13.2 | 导板 | 手术导板类项目 |
| 13.3 | 假体 | 植入物假体类项目 |
| 13.4 | 其他 | 其他类项目 |
