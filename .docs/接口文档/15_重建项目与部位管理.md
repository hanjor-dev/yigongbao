# 15_重建项目与部位管理

## 基本信息

| 项目 | 说明 |
|------|------|
| 所属模块 | basic（基础管理） |
| Controller | BodyPartController、RebuildProjectController |
| 请求前缀 | /basic/body-part、/basic/rebuild-project |
| 认证要求 | 需要登录认证 |

GET /basic/body-part/tree
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

|--------|------|------|
| code | Integer | 状态码，200表示成功 |

| timestamp | Long | 时间戳 |

### 15.4 创建部位

**接口地址**：`POST /basic/body-part`

**是否需要认证**：是

**接口说明**：创建新的部位数据，系统自动生成部位编码。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| parentId | Long | 是 | 父级ID（0=顶级身体区域） |
| name | String | 是 | 部位名称，最大100字符 |
| designerCode | String | 否 | 设计师编号 |
| sort | Integer | 否 | 排序（默认0） |
| status | Integer | 否 | 状态（0=禁用，1=正常） |
| remark | String | 否 | 备注 |

**请求示例**：
```json
{
    "parentId": 1,
    "name": "颅骨",
    "designerCode": "D001",
    "sort": 1,
    "status": 1,
    "remark": "头部颅骨区域"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败（详见 message） |
| 400 | 部位名称不能为空 |
| 400 | 部位名称长度超出限制（最大100字符） |

## 业务说明

### 部位树形结构

部位采用树形结构管理，支持多层级：
- 顶级（level=1）：身体区域，如"头部"、"躯干"、"四肢"
- 二级（level=2）：具体部位，如"颅骨"、"颈椎"、"股骨"

### 重建项目树形结构

重建项目也采用树形结构：
- 顶级（level=1）：重建项目，如"颅骨修补术"
- 二级（level=2）：子重建项目，如"PEEK材料颅骨修补"

### 部位与项目关联

部位和重建项目通过 `bodyPartId` 字段关联，一个部位下可以包含多个重建项目。

### 价格说明

- `standardPrice`：标准价格，正常流程下的项目费用
- `urgentPrice`：加急价格，加急流程下的项目费用

### 预计耗时

`estimatedHours` 字段存储预计耗时，单位为小时，用于生产排期参考。

### 分类筛选

`category` 字段存储项目分类的字典值编码，可通过字典接口查询可选值。
