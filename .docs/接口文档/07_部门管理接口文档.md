## 接口列表

### 7.1 分页查询部门列表

**接口地址**：`POST /system/dept/list`

**是否需要认证**：是

**接口说明**：分页查询部门列表，支持按所属机构、部门名称、状态等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| orgId | Long | 否 | 所属机构ID | - |
| deptName | String | 否 | 部门名称（模糊查询） | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /system/dept/list
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Content-Type: application/json

{
    "pageNum": 1,
    "pageSize": 10,
    "orgId": 1,
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 部门列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "deptName": "技术部",
                "deptCode": "DEPT001",
                "orgId": 1,
                "orgName": "医工宝科技有限公司",
                "leaderUserId": 5,
                "leaderUserName": "张三",
                "status": 1,
                "statusName": "正常",
                "createTime": "2026-03-01 10:00:00"
            },
            {
                "id": 2,
                "deptName": "销售部",
                "deptCode": "DEPT002",
                "orgId": 1,
                "orgName": "医工宝科技有限公司",
                "leaderUserId": 10,
                "leaderUserName": "李四",
                "status": 1,
                "statusName": "正常",
                "createTime": "2026-03-01 11:00:00"
            }
        ],
        "total": 20,
        "size": 10,
        "current": 1,
        "pages": 2
    }
}
```

### 7.3 创建部门

**接口地址**：`POST /system/dept`

**是否需要认证**：是

**接口说明**：创建新部门。系统自动生成部门编码。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| deptName | String | 是 | 部门名称，最大128字符 |
| orgId | Long | 是 | 所属机构ID |
| leaderUserId | Long | 否 | 部门负责人用户ID |
| remark | String | 否 | 备注，最大512字符 |

**请求示例**：
```json
{
    "deptName": "产品部",
    "orgId": 1,
    "leaderUserId": 8,
    "remark": "负责产品设计和规划"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 部门名称已存在（同一机构下） |
| 400 | 参数校验失败 |

### 7.5 删除部门

**接口地址**：`DELETE /system/dept/{id}`

**是否需要认证**：是

**接口说明**：删除指定部门（逻辑删除）。如果部门下有关联的用户，则不允许删除。

**路径参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 部门ID |

**请求示例**：
```http
DELETE /system/dept/10
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 404 | 部门不存在 |
| 400 | 部门下存在用户，无法删除 |

## 业务说明

### 部门编码规则

部门编码由系统自动生成，格式为 `DEPT` + 序号。

### 部门负责人

`leaderUserId` 字段用于指定部门的负责人，但不强制约束，仅作为信息展示。

### 机构与部门的关系

- 一个机构可以包含多个部门
- 部门必须属于某个机构
- 部门名称在同一机构下必须唯一
