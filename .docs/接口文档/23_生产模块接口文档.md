## 流转卡接口

### 23.1 分页查询生产列表

**接口地址**：`POST /production/record/list`

**是否需要认证**：是

**接口说明**：分页查询生产流转卡列表，支持按状态、流转卡编号、加工中心筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| recordNo | String | 否 | 流转卡编号（模糊查询） | - |
| status | Integer | 否 | 流转卡状态 | - |
| processingCenterId | Long | 否 | 加工中心ID | - |

**请求示例**：
```json
POST /production/record/list
Content-Type: application/json
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx

{
  "pageNum": 1,
  "pageSize": 10,
  "status": 3010
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 响应码（200=成功） |
| message | String | 响应消息 |
| data | Object | 分页数据 |
| data.records | Array | 流转卡列表 |
| data.records[].id | Long | 流转卡ID |
| data.records[].recordNo | String | 流转卡编号 |
| data.records[].orderType | Integer | 订单类型（1=医疗器械，2=非医疗器械） |
| data.records[].designPackageCode | String | 设计数据包编号 |
| data.records[].productionBatchNo | String | 生产批号 |
| data.records[].totalProductCount | Integer | 产品总数 |
| data.records[].qualifiedCount | Integer | 合格数量 |
| data.records[].unqualifiedCount | Integer | 不合格数量 |
| data.records[].hasRedoProduct | Integer | 是否存在待重做产品（0=否，1=是） |
| data.records[].status | Integer | 当前状态（整型，见状态码说明） |
| data.records[].currentProcess | String | 当前工序 |
| data.records[].qrCodeUrl | String | 流转卡二维码URL |
| data.records[].createTime | String | 创建时间 |
| data.records[].products | Array | 产品列表 |
| data.total | Long | 总记录数 |
| data.size | Long | 每页条数 |
| data.current | Long | 当前页码 |
| data.pages | Long | 总页数 |

**响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [
      {
        "id": 1,
        "recordNo": "LC202605270001",
        "orderType": 1,
        "designPackageCode": "PKG202605270001",
        "productionBatchNo": "BATCH202605270001",
        "totalProductCount": 5,
        "qualifiedCount": 0,
        "unqualifiedCount": 0,
        "hasRedoProduct": 0,
        "status": 3010,
        "currentProcess": null,
        "qrCodeUrl": "data:image/png;base64,iVBORw0KG...",
        "createTime": "2026-05-27 10:30:00",
        "products": []
      }
    ],
    "total": 1,
    "size": 10,
    "current": 1,
```

### 23.5 下载设计数据包

**接口地址**：`POST /production/record/download-package`

**是否需要认证**：是

**接口说明**：下载设计数据包，触发订单状态流转（START_PRINT），将该数据包对应流转卡状态推进到待打印（3010）。流转卡已在设计审核通过时自动创建，此接口不再创建流转卡。

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| designPackageId | Long | 是 | 设计数据包ID |

```

```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 响应码（200=成功） |
| message | String | 响应消息 |
| data | Null | 无返回数据 |

**响应示例**：
```json
{
  "code": 200,
  "message": "操作成功",
```
