#### 22.3 创建加工中心

**接口地址**：`POST /basic/processing-center`

**是否需要认证**：是

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| centerCode | String | 是 | @NotBlank | 中心编码（全局唯一） |
| centerName | String | 是 | @NotBlank | 中心名称 |
| contactPerson | String | 否 | - | 联系人姓名 |
| contactPhone | String | 否 | - | 联系电话 |
| address | String | 否 | - | 地址 |
| deviceIdRanges | String | 否 | JSON数组 | 可用设备ID范围，格式见下方说明 |
| remark | String | 否 | - | 备注 |

**deviceIdRanges 格式说明**：

JSON 数组，每个元素包含 `start`（起始编号）和 `end`（结束编号），基于字符串字典序比较，要求 `start <= end`。同一范围不允许与其他加工中心的范围交叉或重叠。

```json
[{"start": "P001", "end": "P099"}]
```

**请求示例**：
```json
{
    "centerCode": "SH001",
    "centerName": "上海加工中心",
    "contactPerson": "李四",
    "contactPhone": "13900139000",
    "address": "上海市浦东新区xxx",
    "deviceIdRanges": "[{\"start\":\"P100\",\"end\":\"P199\"}]",
    "remark": "新建加工中心"
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": 2
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败 |
| 409 | 中心编码已存在 |
| 410 | deviceIdRanges 格式不合法，或与其他加工中心的设备ID范围存在重叠 |

#### 22.12 WebSocket 设备状态推送

**接口地址**：`WS /api/basic/ws/device`

**是否需要认证**：**否**（无需携带 token，任何客户端均可连接）

**接口说明**：加工中心设备端通过 WebSocket 长连接推送设备状态。连接建立后，客户端发送 JSON 消息，服务端解析后批量更新设备状态；若设备不存在则自动创建。

**推送消息格式**（客户端 → 服务端）：

| 字段 | 类型 | 说明 |
|------|------|------|
| centerName | String | 加工中心名称（用于匹配加工中心记录） |
| devices | Array | 设备状态列表 |
| devices[].id | String | 设备编号 |
| devices[].state | Integer | 设备状态（0=空闲，1=占用） |

**推送示例**：
```json
{
    "centerName": "北京加工中心",
    "devices": [
        {"id": "PRINTER001", "state": 0},
        {"id": "PRINTER002", "state": 1}
    ]
}
```

**响应消息**（服务端 → 客户端）：

```json
{"code": 200, "message": "success"}
```

**业务说明**：
- 服务端收到推送后，根据 `centerName` 匹配加工中心（状态须为启用）
- 已存在的设备：更新 `state`、`connectionStatus=1`、`lastHeartbeat`
- 不存在的设备：自动创建，默认类型为 `PRINTER_SLA`
- 推送的 `deviceId` 不在该加工中心配置的 `deviceIdRanges` 范围内时，该设备被跳过（不创建、不更新）
- 加工中心 WebSocket 连接断开时，该中心所有设备自动标记为离线（无定时任务）

## 业务说明

### 加工中心与设备关系

- 每个设备归属于一个加工中心（`centerId`）
- 加工中心可包含多个设备
- 删除加工中心前需确保其下没有关联设备

### 设备ID范围（deviceIdRanges）

- 格式为 JSON 数组：`[{"start":"P001","end":"P099"}]`，支持多段范围
- `start` 和 `end` 基于字符串字典序比较，要求 `start <= end`
- 创建或更新时，系统自动校验与其他加工中心的范围不存在交叉或重叠，违反时返回错误码 410

### 设备状态说明

| 字段 | 值 | 含义 |
|------|----|------|
| state | 0 | 空闲（未分配任务） |
| state | 1 | 占用（正在执行任务） |
| connectionStatus | 0 | 离线（心跳超时或连接断开） |
| connectionStatus | 1 | 在线（心跳正常） |

### 生产员权限

- 生产员角色（roleCode=producer）必须绑定加工中心（sys_user.center_id）
- 生产员只能查看和操作自己绑定中心的设备
- 数据权限在查询时自动过滤，无需前端额外处理
