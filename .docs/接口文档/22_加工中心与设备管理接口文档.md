### 一、加工中心管理

#### 22.1 分页查询加工中心列表

**接口地址**：`POST /basic/processing-center/list`

**是否需要认证**：是

**接口说明**：分页查询加工中心列表，支持按中心名称、状态等条件筛选。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| centerName | String | 否 | 中心名称（模糊查询） | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```json
POST /basic/processing-center/list
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
Content-Type: application/json

{
    "pageNum": 1,
    "pageSize": 10,
    "status": 1
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 加工中心列表（ProcessingCenterVO） |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "centerName": "北京加工中心",
                "centerCode": "BJ001",
                "address": "北京市朝阳区xxx",
                "contactPerson": "张三",
                "contactPhone": "13800138000",
                "status": 1,
                "statusName": "正常",
                "remark": "主要加工中心",
                "createTime": "2026-03-01 10:00:00"
            }
        ],
        "total": 10,
        "size": 10,
        "current": 1,
        "pages": 1
    }
}
```

#### 22.3 创建加工中心

**接口地址**：`POST /basic/processing-center`

**是否需要认证**：是

**接口说明**：创建新的加工中心。

**请求参数**（JSON Body）：

| 参数名 | 类型 | 必填 | 校验规则 | 说明 |
|--------|------|------|----------|------|
| centerName | String | 是 | @NotBlank, @Size(max=64) | 中心名称 |
| centerCode | String | 否 | @Size(max=32) | 中心编码 |
| address | String | 否 | @Size(max=256) | 地址 |
| contactPerson | String | 否 | @Size(max=32) | 联系人 |
| contactPhone | String | 否 | @Pattern(^1[3-9]\d{9}$) | 联系电话 |
| remark | String | 否 | @Size(max=512) | 备注 |

**请求示例**：
```json
{
    "centerName": "上海加工中心",
    "centerCode": "SH001",
    "address": "上海市浦东新区xxx",
    "contactPerson": "李四",
    "contactPhone": "13900139000",
    "remark": "新建加工中心"
}
```

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": 2
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败 |
| 612 | 加工中心名称已存在 |

## 业务说明

### 加工中心与设备关系

- 每个设备必须归属于一个加工中心
- 加工中心可以包含多个设备
- 删除加工中心前需确保其下没有关联设备

### 设备状态管理

- 设备状态通常由WebSocket心跳自动维护
- 设备上线时通过WebSocket注册并自动创建记录
- 设备离线超过5分钟自动标记为离线状态
- 手动创建和状态更新接口用于特殊情况（如设备维护、测试等）

### 生产员权限

- 生产员角色（roleCode=producer）必须绑定加工中心（sys_user.center_id）
- 生产员只能查看和操作自己绑定中心的设备
- 数据权限在查询时自动过滤，无需前端额外处理
