## 接口列表

### 12.1 分页查询科室列表

**接口地址**：`GET /basic/hospital-dept/page`

**是否需要认证**：是

**接口说明**：分页查询医院科室列表，支持按科室名称、状态等条件筛选。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 | 默认值 |
|--------|------|------|------|--------|
| pageNum | Integer | 否 | 页码 | 1 |
| pageSize | Integer | 否 | 每页条数 | 10 |
| hospitalDeptName | String | 否 | 科室名称（模糊查询） | - |
| status | Integer | 否 | 状态（0=禁用，1=正常） | - |

**请求示例**：
```http
GET /basic/hospital-dept/page?pageNum=1&pageSize=10&status=1
Authorization: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | Object | 分页数据 |
| data.records | Array | 科室列表 |
| data.total | Long | 总记录数 |
| data.size | Integer | 每页条数 |
| data.current | Integer | 当前页码 |
| data.pages | Integer | 总页数 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": {
        "records": [
            {
                "id": 1,
                "hospitalDeptCode": "DEPT-0001",
                "hospitalDeptName": "心内科",
                "sort": 1,
                "status": 1,
                "statusName": "正常",
                "remark": "心血管疾病诊疗",
                "createTime": "2026-03-01 10:00:00",
                "createBy": 1
            }
        ],
        "total": 50,
        "size": 10,
        "current": 1,
        "pages": 5
    }
}
```

### 12.4 创建科室

**接口地址**：`POST /basic/hospital-dept`

**是否需要认证**：是

**接口说明**：创建新科室。系统自动生成科室编码，无需手动填写。

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| hospitalDeptName | String | 是 | 科室名称，最大64字符 |
| sort | Integer | 否 | 排序，数字越小越靠前 |
| remark | String | 否 | 备注，最大512字符 |

**请求示例**：
```json
{
    "hospitalDeptName": "肿瘤科",
    "sort": 5,
    "remark": "肿瘤疾病诊疗与研究"
}
```

**响应参数**：

| 参数名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 状态码，200表示成功 |
| message | String | 响应消息 |
| timestamp | Long | 时间戳 |
| data | null | 无数据返回 |

**响应示例**：
```json
{
    "code": 200,
    "message": "操作成功",
    "timestamp": 1740700800000,
    "data": null
}
```

**错误码**：

| 错误码 | 说明 |
|--------|------|
| 400 | 参数校验失败（详见 message） |

## 业务说明

### 科室编码

科室编码由系统自动生成，无需手动填写。创建科室后可通过科室详情接口查询系统分配的编码。

### 科室与医生的关系

科室用于管理医院的科室信息，与医生管理功能关联。医生在创建或更新时需关联所属科室。
