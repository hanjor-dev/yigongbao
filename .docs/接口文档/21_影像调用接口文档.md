# 21. 影像阅览接口文档

> 模块：`yigongbao-module-imaging`  
> 基础路径：`/api/imaging`  
> 认证：所有接口需要登录（SaToken `@SaCheckLogin`）

---

## 通用说明

### 响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [],
  "timestamp": 1713600000000
}
```

### 颜色透明度字段说明

3D 模型相关接口的 `colorCode` 和 `opacity` 字段通过文件名（去扩展名）在 `part_colors` 表精确匹配。若无匹配记录，两字段均返回 `null`，前端应按默认样式渲染。

---

## 接口列表

### 1. 获取订单的 DCM 影像数据包列表

**GET** `/api/imaging/dcm-packages`

查询指定订单上传的 DCM 影像压缩包列表（order_file 表中 fileCategory = `10.1` 的记录）。

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | Long | 是 | 订单ID |

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "fileId": "abc123",
      "fileName": "CT影像.zip",
      "fileUrl": "https://storage.example.com/abc123.zip",
      "fileSize": 524288000,
      "packageNo": "PKG001",
      "uploadTime": "2026-04-10T09:30:00"
    }
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| fileId | String | 文件ID |
| fileName | String | 文件名（含扩展名） |
| fileUrl | String | 文件访问地址 |
| fileSize | Long | 文件大小（字节） |
| packageNo | String | 影像数据包编号 |
| uploadTime | LocalDateTime | 上传时间 |

---

### 2. 获取指定数据包内的模型文件列表

**GET** `/api/imaging/package-model-files`

查询设计阶段某数据包解压后的 3D 模型文件列表，附带颜色和透明度配置。

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| packageId | Long | 是 | 数据包ID（design_package.id） |

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "packageFileId": 101,
      "fileName": "右肺上叶.stl",
      "fileExt": "stl",
      "filePath": "models/右肺上叶.stl",
      "fileSize": 2048000,
      "colorCode": "170,255,0",
      "opacity": 0.80
    },
    {
      "packageFileId": 102,
      "fileName": "未知部位.stl",
      "fileExt": "stl",
      "filePath": "models/未知部位.stl",
      "fileSize": 1024000,
      "colorCode": null,
      "opacity": null
    }
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| packageFileId | Long | 数据包文件记录ID |
| fileName | String | 文件名（含扩展名） |
| fileExt | String | 文件扩展名 |
| filePath | String | 文件相对路径 |
| fileSize | Long | 文件大小（字节） |
| colorCode | String | 颜色 RGB（如 `255,0,0`），无匹配时为 null |
| opacity | BigDecimal | 透明度（0.00~1.00），无匹配时为 null |

### 6. dcmPath - DCM影像压缩包URL列表

**POST** `/api/imaging/v1/dcm`

查看器调用此接口获取 DCM 影像压缩包 URL 列表（用于 2D/3D 切片渲染）。

**请求体**

```json

    "https://storage.example.com/dcm2.zip"
  ]
}
```

### 7. stlPath - STL模型数据（按数据包分组）

**POST** `/api/imaging/v1/stl`

查看器调用此接口获取 STL 模型数据，按设计数据包分组，含颜色透明度配置。

**请求体**

```json
{"orderId": 123}
```

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "isGroup": true,
    "list": [
      {
        "groupId": "ORD20260410001-1",
        "groupName": "CT影像",
        "stls": [
          {
            "id": "101",
            "stlName": "左髋骨.stl",
            "url": "https://storage.example.com/models/左髋骨.stl",
            "color": "170,255,0",
            "opacity": 0.80
          }
        ]
      }
    ]
  }
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| isGroup | Boolean | 是否分组（固定为 true） |
| list | Array | STL 分组列表 |
| groupId | String | 分组ID（数据包编号，如 ORD20260410001-1） |
| groupName | String | 分组名称（数据包文件名，去扩展名） |
| stls | Array | STL 文件列表 |
| id | String | 文件ID（对应 design_package_file.id） |
| stlName | String | 文件名 |
| url | String | 文件访问地址 |
| color | String | 颜色 RGB（如 `170,255,0`），无匹配时为 null |
| opacity | BigDecimal | 透明度（0.00~1.00），无匹配时为 null |

### 8. markPath - 提交标注截图

**POST** `/api/imaging/v1/mark`

查看器提交用户标注后的截图，关联到数据包。

**请求格式**：`multipart/form-data`

**表单字段**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| groupId | String | 是 | 数据包编号（查看器自动附带，对应 stlPath 返回的 groupId） |
| id | String | 是 | 模型文件ID（查看器自动附带，对应 stlPath 返回的 stls[].id） |
| file | File | 是 | 截图文件（PNG/JPG） |

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null
}
```

**说明**：
- 截图通过 `groupId`（数据包编号，全局唯一）查询到 `packageId`，然后关联到 `design_package_screenshot` 表
- 关联关系：`packageId` + `packageFileId`（即 `id` 参数）
- 同一模型文件多次标注会覆盖之前的截图（upsert 逻辑）

---

### 9. stlList - STL文件列表

**GET** `/api/imaging/v1/stl-list`

查看器调用此接口获取订单关联的所有 STL 文件列表（扁平化列表，不分组）。

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | Long | 是 | 订单ID |

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "stlName": "左髋骨.stl",
      "url": "https://storage.example.com/models/左髋骨.stl"
    },
    {
      "stlName": "右髋骨.stl",
      "url": "https://storage.example.com/models/右髋骨.stl"
    }
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| stlName | String | STL文件名 |
| url | String | 文件访问URL |

**说明**：
- 返回订单下所有设计数据包的 STL 文件，按 `sortOrder` 排序
- 与 `stlPath` 接口的区别：不包含颜色透明度信息，不按数据包分组
- 适用于需要快速获取文件列表的场景
