# 21. 影像阅览接口文档

> 模块：`yigongbao-module-imaging`  
> 基础路径：`/api/imaging`  
> 认证：所有接口需要登录（SaToken `@SaCheckLogin`）

---

## 通用说明

### 响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [],
  "timestamp": 1713600000000
}
```

### 颜色透明度字段说明

3D 模型相关接口的 `colorCode` 和 `opacity` 字段通过文件名（去扩展名）在 `part_colors` 表精确匹配。若无匹配记录，两字段均返回 `null`，前端应按默认样式渲染。

---

## 接口列表

### 1. 获取订单的 DCM 影像数据包列表

**GET** `/api/imaging/dcm-packages`

查询指定订单上传的 DCM 影像压缩包列表（order_file 表中 fileCategory = `10.1` 的记录）。

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | Long | 是 | 订单ID |

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "fileId": "abc123",
      "fileName": "CT影像.zip",
      "fileUrl": "https://storage.example.com/abc123.zip",
      "fileSize": 524288000,
      "packageNo": "PKG001",
      "uploadTime": "2026-04-10T09:30:00"
    }
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| fileId | String | 文件ID |
| fileName | String | 文件名（含扩展名） |
| fileUrl | String | 文件访问地址 |
| fileSize | Long | 文件大小（字节） |
| packageNo | String | 影像数据包编号 |
| uploadTime | LocalDateTime | 上传时间 |

---

### 2. 获取指定数据包内的模型文件列表

**GET** `/api/imaging/package-model-files`

查询设计阶段某数据包解压后的 3D 模型文件列表，附带颜色和透明度配置。

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| packageId | Long | 是 | 数据包ID（design_package.id） |

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "packageFileId": 101,
      "fileName": "右肺上叶.stl",
      "fileExt": "stl",
      "filePath": "models/右肺上叶.stl",
      "fileSize": 2048000,
      "colorCode": "170,255,0",
      "opacity": 0.80
    },
    {
      "packageFileId": 102,
      "fileName": "未知部位.stl",
      "fileExt": "stl",
      "filePath": "models/未知部位.stl",
      "fileSize": 1024000,
      "colorCode": null,
      "opacity": null
    }
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| packageFileId | Long | 数据包文件记录ID |
| fileName | String | 文件名（含扩展名） |
| fileExt | String | 文件扩展名 |
| filePath | String | 文件相对路径 |
| fileSize | Long | 文件大小（字节） |
| colorCode | String | 颜色 RGB（如 `255,0,0`），无匹配时为 null |
| opacity | BigDecimal | 透明度（0.00~1.00），无匹配时为 null |

---

### 3. 获取订单所有数据包的模型文件（按包分组）

**GET** `/api/imaging/package-model-files/by-order`

一次性返回订单下所有设计数据包的模型文件，按数据包分组，适合前端批量加载场景。

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | Long | 是 | 订单ID |

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "packageId": 10,
      "packageCode": "ORD20260410001-1",
      "files": [
        {
          "packageFileId": 101,
          "fileName": "右肺上叶.stl",
          "fileExt": "stl",
          "filePath": "models/右肺上叶.stl",
          "fileSize": 2048000,
          "colorCode": "170,255,0",
          "opacity": 0.80
        }
      ]
    },
    {
      "packageId": 11,
      "packageCode": "ORD20260410001-2",
      "files": []
    }
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| packageId | Long | 数据包ID |
| packageCode | String | 数据包编号 |
| files | Array | 包内模型文件列表（字段同接口2） |

---

### 4. 获取订单的可视化模型列表

**GET** `/api/imaging/models`

查询设计阶段关联的可视化模型文件（design_model 表），附带文件访问地址及颜色透明度。

**Query 参数**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| orderId | Long | 是 | 订单ID |

**响应示例**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": [
    {
      "modelId": 1,
      "fileId": "fileABC",
      "fileName": "整体模型.stl",
      "fileUrl": "https://storage.example.com/fileABC.stl",
      "fileSize": 4096000,
      "colorCode": "255,0,0",
      "opacity": 0.90
    }
  ]
}
```

**响应字段说明**

| 字段 | 类型 | 说明 |
|------|------|------|
| modelId | Long | 模型记录ID（design_model.id） |
| fileId | String | 文件ID |
| fileName | String | 文件名（含扩展名） |
| fileUrl | String | 文件访问地址 |
| fileSize | Long | 文件大小（字节） |
| colorCode | String | 颜色 RGB（如 `255,0,0`），无匹配时为 null |
| opacity | BigDecimal | 透明度（0.00~1.00），无匹配时为 null |

---

## 错误码

| code | 说明 |
|------|------|
| 200 | 成功，data 为空数组表示无数据 |
| 401 | 未登录 |
| 500 | 服务器内部错误 |
