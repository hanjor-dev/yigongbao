> **版本：** v1.0.0

## 一、统一响应规范

### 1.1 响应格式

所有接口统一返回以下 JSON 结构：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { },
  "timestamp": 1710392800000
}
```

**字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| code | Integer | 状态码，200=成功，其他=失败 |
| message | String | 提示信息，成功时返回"操作成功"，失败时返回错误描述 |
| data | Object/Array | 响应数据，可以是任意类型 |
| timestamp | Long | 时间戳（毫秒） |

### 1.2 分页响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "records": [ ],
    "total": 100,
    "size": 10,
    "current": 1,
    "pages": 10
  },
  "timestamp": 1710392800000
}
```

**分页字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| records | Array | 当前页的数据列表 |
| total | Long | 总记录数 |
| size | Long | 每页条数 |
| current | Long | 当前页码 |
| pages | Long | 总页数 |

### 1.3 错误码说明

| 错误码 | 说明 | 前端处理建议 |
|--------|------|-------------|
| 200 | 操作成功 | - |

| 606 | 字典编码已存在 | 提示编码重复 |

| 615 | 该部门下存在用户，无法删除 | 提示先转移用户 |
| 617 | 用户名已存在 | 提示用户名重复 |

| username | String | 是 | Body | 用户名，长度 3-32 字符 |
| password | String | 是 | Body | 密码，长度 6-20 字符 |

### 3.3 创建用户

**接口名称：** 创建用户
**请求路径：** `/api/system/user`
**请求方式：** `POST`
**认证要求：** 需要登录

**参数说明：**

| 参数名 | 类型 | 必填 | 来源 | 说明 |
|--------|------|------|------|------|
| username | String | 是 | Body | 用户名，长度 3-32 字符 |

| phone | String | 是 | Body | 手机号，需符合正则 `^1[3-9]\\d{9}$` |
| email | String | 否 | Body | 邮箱，需符合邮箱格式 |
| sex | Integer | 否 | Body | 性别 |
| avatar | String | 否 | Body | 头像路径，最大 512 字符 |
| accountType | Integer | 是 | Body | 账户分类，1=内部用户，2=外部用户 |
| orgId | Long | 是 | Body | 所属机构ID |
| deptId | Long | 否 | Body | 所属部门ID |
| roleId | Long | 否 | Body | 关联角色ID |
| employeeNo | String | 否 | Body | 工号，最大 32 字符 |
| specialty | String | 否 | Body | 专业方向，最大 64 字符 |
| qualification | String | 否 | Body | 资质证书信息，最大 256 字符 |
| settlementType | Integer | 否 | Body | 结算类型 |
| remark | String | 否 | Body | 备注，最大 512 字符 |

**参数示例：**

```json
{
  "username": "zhangsan",
  "password": "123456",
  "realName": "张三",
  "phone": "13800138001",
  "email": "zhangsan@example.com",
  "sex": 1,
  "accountType": 1,
  "orgId": 1,
  "deptId": 1,
  "roleId": 2,
  "employeeNo": "EMP001",
  "specialty": "骨科",
  "remark": "新入职员工"
}
```

**返回数据结构：** 空

**返回数据示例：**

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null,
  "timestamp": 1710392800000
}
```

**特殊说明：**
- 用户名已存在时返回 code=617
- 手机号已存在时返回 code=618
- 机构不存在时返回 code=619
- 部门不存在时返回 code=620
- 角色不存在时返回 code=621
