# 工单设计阶段需求分析

## 一、设计师操作流程概览

```
┌────────────────────────────────────────────────────────────────────────────────┐
│                           设计师工单处理流程                                     │
├────────────────────────────────────────────────────────────────────────────────┤
│                                                                                │
│   第1步        第2步        第3步        第4步        第5步        第6步     │
│   ┌───┐       ┌───┐       ┌───┐       ┌───┐       ┌───┐       ┌───┐          │
│   │接单│   →   │查看│   →   │设计│   →   │上传│   →   │填写│   →   │提交│          │
│   └───┘       └───┘       └───┘       └───┘       └───┘       └───┘          │
│                                                                                │
│   接收新工单   查看订单    执行设计    上传文件    填写打印    指令单+图纸    │
│               信息                  信息       信息         生成+提交         │
│                                                                                │
└────────────────────────────────────────────────────────────────────────────────┘
```

> **说明**：以上6步中，「填写打印信息」和「指令单+图纸生成+提交」可以理解为设计师的完整操作环节。

## 二、设计师操作步骤详解

### 第1步：接收新工单

**触发条件**：订单审核通过后，系统自动/手动分配给设计师

**设计师操作**：

1. 在「我的工单」列表中查看待处理工单
2. 可以看到工单基本信息：订单编号、患者姓名、部位、项目、期望交付时间等

**系统行为**：

- 工单状态显示为「待设计」
- 系统推送消息通知设计师有新工单

**设计师分配方式**：

| 方式 | 说明 |
|------|------|
| 自动分配 | 按设计师专业方向（部位）、负载均衡、随机、轮询等规则自动匹配 |
| 手动分配 | 管理员手动指定设计师 |

---

### 第2步：查看订单详情

**设计师操作**：

1. 点击工单进入详情页面
2. 查看以下订单信息：

| 信息分类 | 具体内容 |
|----------|----------|
| 基础信息 | 订单编号、提单机构、操作员、联系电话 |
| 机构信息 | 机构类型、所属地区、医院、科室 |
| 医生信息 | 医生姓名、医生电话 |
| 患者信息 | 患者姓名、年龄、性别 |
| 业务信息 | 邮寄地址、所需部位、重建项目 |
| 项目要求 | 项目说明、成形需求、其他要求 |
| 时效信息 | 期望时效（标准/加急）、期望交付时间 |
| 费用信息 | 预计费用 |
| 影像资料 | 影像数据包、报告文件（如有上传） |

---

### 第3步：开始设计

**设计师操作**：

1. 点击「开始设计」按钮
2. 工单状态从「待设计」变为「设计中」

> **说明**：「开始设计」按钮用于标记设计师正式开始处理此工单，系统记录开始时间。

---

### 第4步：上传设计文件

**设计师操作**：

点击「上传设计文件」按钮，上传以下文件：

| 文件类型 | 说明 | 必填 | 格式要求 |
|----------|------|:----:|----------|
| 打印文件 | 用于3D打印的设计文件 | ✓ 是 | STL/3MF/OBJ等 |
| 设计报告 | 设计说明、设计参数等 | ✗ 否 | PDF/Word |
| 可视化模型 | 用于展示的三维模型 | ✗ 否 | 3DPDF/PLY/STL等 |

**操作说明**：

- 打印文件为必填，至少上传1个
- 设计报告和可视化模型为选填
- 每种文件类型可以上传多个
- 支持文件删除和重新上传
- 上传成功后显示文件列表（文件名、大小、上传时间）

---

### 第5步：填写打印信息

**设计师操作**：

点击「填写打印信息」按钮，填写以下内容：

#### 5.1 系统自动填充（无需手动填写）

| 字段 | 数据来源 |
|------|----------|
| 流水号 | 系统自动生成 |
| 指令单编号 | 系统自动生成 |
| 订单编号 | 订单信息自动带出 |
| 客户 | 订单提单机构自动带出 |
| 联系人 | 订单操作员自动带出 |
| 数据包编号 | 订单信息自动带出 |
| 医院 | 订单信息自动带出 |
| 期望交付时间 | 订单时效要求自动带出 |
| 患者姓名 | 订单信息自动带出 |
| 是否邮寄 | 订单信息自动带出 |
| 邮寄地址 | 订单信息自动带出 |

#### 5.2 设计师手动填写

| 字段 | 填写要求 | 关联说明 |
|------|----------|----------|
| 产品名称 | 必填，从下拉列表选择 | 选择产品后，自动带出该产品可选的型号规格 |
| 型号规格 | 必填，从下拉列表选择 | 根据所选产品名称，动态显示可选规格 |
| 材质 | 必填，从下拉列表选择 | 后台物料管理 |
| 颜色 | 必填，从下拉列表选择 | 后台配置 |
| 注册证号 | 必填，从下拉列表选择 | 与产品型号关联 |
| 打印模型 | 必填，可多选 | 根据产品型号关联 |
| 产品标识 | 必填，手动填写 | 设计师输入 |
| 产品编码（UDI码） | 自动填充 | 根据产品型号自动生成 |

**填写完成后**：

- 点击「保存」按钮保存打印随时修改保存后的信息

---

###信息
- 可 第6步：生成指令单和图纸

**设计师操作**：

#### 6.1 生成指令单

点击「生成指令单」按钮，系统根据模板自动生成指令单。

**指令单包含内容**：

| 信息分类 | 具体内容 |
|----------|----------|
| 基本信息 | 流水号、指令单编号、订单编号、客户、联系人 |
| 医院信息 | 医院名称、科室 |
| 患者信息 | 患者姓名 |
| 产品信息 | 产品名称、型号规格、材质、颜色、注册证号 |
| 打印信息 | 打印模型列表 |
| 订单信息 | 数据包编号、期望交付时间、是否邮寄、邮寄地址 |
| 设计信息 | 设计师签名、设计日期 |
| 审批信息 | 审批签名、审批日期（审核时填写） |

**指令单操作**：

| 操作 | 说明 |
|------|------|
| 生成预览 | 点击后预览指令单内容 |
| 下载 | 下载指令单PDF文件 |
| 打印 | 直接打印指令单 |
| 上传修订版 | 如需修改，上传修订后的指令单 |
| 电子签名 | 点击签名按钮进行电子签名 |

#### 6.2 生成图纸

点击「生成图纸」按钮，系统根据模板自动生成图纸。

**图纸包含内容**：

| 信息分类 | 具体内容 |
|----------|----------|
| 基本信息 | 序号、文件名称、产品名称 |
| 标识信息 | 二维码（包含订单信息）、版本号 |
| 订单信息 | 订单编号、数据包编号 |
| 日期信息 | 设计日期、审批日期 |
| 页码信息 | 第X页/共Y页 |
| 生产信息 | 生产机构名称、备注 |

**图纸操作**：

| 操作 | 说明 |
|------|------|
| 生成预览 | 点击后预览图纸内容 |
| 下载 | 下载图纸PDF文件 |
| 多页管理 | 支持多页图纸，自动生成分页标记 |
| 上传修订版 | 如需修改，上传修订后的图纸 |
| 电子签名 | 点击签名按钮进行电子签名 |

> **说明**：指令单和图纸都是必须生成的，用于后续生产流程。

---

### 第7步：提交设计

**设计师操作**：

当以上步骤完成后，点击「提交设计」按钮。

**提交条件检查**：

| 检查项 | 要求 |
|--------|------|
| 设计文件 | 必须上传至少1个打印文件 |
| 打印信息 | 必须填写完整（必填字段不能为空） |
| 指令单 | 必须生成 |
| 图纸 | 必须生成 |

**提交后**：

- 工单状态从「设计中」变为「设计完成」
- 等待设计审核

## 三、设计审核流程

### 3.1 审核角色

设计师提交设计后，需要进行设计审核，审核角色包括：

| 角色 | 审核权限 |
|------|----------|
| 设计管理员 | ✓ 可审核 |
| 业务管理员 | ✓ 可审核 |
| 系统管理员 | ✓ 可审核 |

### 3.2 审核操作

审核人员点击工单进行审核：

| 操作 | 说明 |
|------|------|
| 审核通过 | 填写审批意见，工单进入「待打印」状态，流转至生产模块 |
| 审核不通过 | 填写驳回原因，工单状态变为「设计审核不通过」 |

### 3.3 驳回处理

如果审核不通过：

1. 设计师收到驳回通知
2. 查看驳回原因
3. 修改设计文件/打印信息/指令单/图纸
4. 重新点击「提交设计」
5. 重新进入「设计审核中」状态

### 3.4 审核信息记录

| 字段 | 说明 |
|------|------|
| 审核时间 | 系统自动记录 |
| 审核人 | 系统自动记录 |
| 审核结果 | 通过/不通过 |
| 审批意见 | 审核通过时填写（可选） |
| 驳回原因 | 审核不通过时必填 |

## 四、服务订单特殊处理

### 4.1 什么是服务订单

服务订单 = 仅提供设计服务，不涉及实物生产和交付

### 4.2 服务订单流程

```
设计中 → 设计完成 → 提单人确认 → 已完成
                  ↓
         业务员点击「确认完成」按钮
```

> **说明**：服务订单在设计完成后，不需要经过设计审核环节，直接由提单人确认即可完成。

### 4.3 确认操作

| 项目 | 说明 |
|------|------|
| 触发条件 | 设计成果已完成，服务订单需要提单人确认 |
| 操作角色 | 业务员/区域管理员/经销商（订单创建者） |
| 操作动作 | 在订单详情点击「确认完成」按钮 |
| 状态变更 | 设计完成 → 已完成 |
| 确认记录 | 确认时间、确认人自动记录 |

## 七、角色权限汇总

| 角色 | 可操作内容 |
|------|------------|
| 设计师 | 查看工单、开始设计、上传设计文件、填写打印信息、生成指令单/图纸、提交设计 |
| 设计管理员 | 查看所有设计师工单、审核设计、修改部位/项目/说明 |
| 业务管理员 | 审核设计 |
| 系统管理员 | 审核设计、全权限 |
