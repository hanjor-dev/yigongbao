# 账户生命周期流程分析

## 一、文档概述

本文档详细描述医工宝系统**账户生命周期管理**流程，包括账户创建、审核、通知等核心环节的管理逻辑。

本文档涵盖两种账户来源方式：
1. **管理员分发账户**：由管理员手动创建并分配给用户（内部用户）
2. **用户自主注册**：外部用户（经销商、医疗机构等）主动注册，管理员审核后启用（外部用户）

> **说明**：
> - 两种方式并行存在，管理员可根据业务需求选择使用。
> - 根据**用户体系分析**的最新设计：
>   - 账户分类简化为**内部用户**、**外部用户**两类
>   - 所有账户**必须归属机构**
>   - 用户可选择**归属部门**（可选）
>   - 删除子账户/层级关系功能

## 三、详细流程设计

### 3.1 方式一：管理员分发账户

#### 3.1.1 阶段1：创建前准备

在正式创建账户前，管理员需要明确以下信息：

| 准备项 | 说明 | 必填 |
|-------|------|:---:|
| **账户分类** | 内部用户（默认） | ✓ |
| **机构类型** | 生产企业/经销商/医疗机构 | ✓ |
| **所属机构** | 哪个具体的企业/医院 | ✓ |
| **角色** | 根据机构类型确定可选角色（设计师、业务员等） | ✓ |
| **生效时间** | 账户立即生效还是指定日期生效 | - |

> **说明**：
> - 管理员创建的账户均为**内部用户**，账户分类选择"内部用户"
> - 机构类型决定可用的角色范围（生产企业→设计师/生产员等，经销商→业务员/区域管理员，医疗机构→医生）

---

#### 3.1.2 阶段2：账户创建（填写信息）

账户应包含以下信息字段：（具体详细字段待定）

#### 3.1.2.1 基础信息

| 字段 | 说明 | 必填 | 备注 |
|-----|------|:---:|------|
| 姓名 | 用户真实姓名 | ✓ | |
| 手机号 | 登录账号 | ✓ | 唯一性校验 |
| 邮箱 | 通知接收 | - | |
| 性别 | - | - | |
| 身份证号 | 实名认证 | - | 敏感信息，需加密存储 |

#### 3.1.2.2 机构信息

> **重要说明**：根据用户体系设计要求，**所有账户必须归属于具体机构**，机构是业务运营的实体单位。

| 字段 | 说明 | 必填 | 备注 |
|-----|------|:---:|------|
| 账户分类 | 内部用户（默认） | ✓ | 管理员创建账户固定为内部用户 |
| 机构类型 | 生产企业/经销商/医疗机构 | ✓ | 决定可绑定的角色范围 |
| 所属机构 | 具体的企业/医院名称 | ✓ | 关联机构信息 |
| 所属部门 | 机构内的二级单位 | - | 可选归属，同一机构下唯一 |
| 角色 | 根据机构类型确定 | ✓ | 决定菜单和功能权限 |

#### 3.1.2.3 扩展信息（根据角色）

| 字段 | 适用角色 | 说明 |
|-----|---------|------|
| 工号 | 设计师、生产员等 | 内部编号，如 A001、B001 |
| 专业方向 | 设计师 | 字母代表，如 A-骨科、B-口腔 |
| 资质证书 | 设计师、质管 | 证书编号、有效期 |

#### 3.1.2.4 账户安全信息

| 字段 | 说明 | 初始值 |
|-----|------|-------|
| 登录密码 | 首次创建时设置 | 系统生成或管理员指定 |
| 账户状态 | 正常/停用 | 创建时默认"正常" |
| 有效期 | 账户有效期限 | 默认无限制 |

#### 3.1.2.5 特殊字段（根据角色）

| 字段 | 适用角色 | 说明 |
|-----|---------|------|
| 结算类型 | 业务员、区域管理员 | 预付费/后付费/月结 |

#### 3.1.2.6 医院业务范围（按角色，可选）

> **说明**：
> - 此处“医院”指**订单创建时选择的提单医院**（后台维护的医院数据），不是“账户所属机构”概念
> - 当某些角色需要按医院范围控制可见/可操作的订单时，由管理员在创建账号时配置

| 字段 | 适用角色（示例） | 说明 |
|-----|------------------|------|
| 医院范围模板 | 业务员、区域管理员、设计师管理员等 | 选择一个预设“医院组合模板”，自动带出医院列表 |
| 医院列表（可选微调） | 同上 | 在模板基础上允许少量增删（可选，具体策略可配置） |

#### 3.1.4 通知机制

| 通知方式 | 通知内容 | 发送条件 |
|---------|---------|---------|
| 短信 | 登录账号、初始密码、登录链接 | 创建成功时 |
| 邮件 | 账户信息、使用说明、安全提醒 | 创建成功时（若填写邮箱） |
| 系统内消息 | 账户创建成功提醒 | 创建成功时 |

### 3.2 方式二：用户自主注册审批

#### 3.2.1 功能说明

用户自主注册审批流程适用于**外部用户（经销商、医疗机构等）主动申请加入系统**的场景，与管理员分发账户方式互补。

| 特性 | 说明 |
|-----|------|
| 注册开关 | 由后台系统配置字段控制（如 `enable_user_register`），管理员可随时开启/关闭 |
| 审核方式 | 一级审核（业务管理员或一级管理员） |
| 审核要点 | 系统不强制校验，由审核人人工判断资料真实性 |
| 拒绝处理 | 拒绝后允许用户重新提交资料 |

#### 3.2.2 流程概述

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                        用户自主注册审批流程                                      │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐   │
│  │  1. 触发     │ →  │  2. 填写     │ →  │  3. 提交     │ →  │  4. 审核     │   │
│  │  注册入口    │    │  账户资料    │    │  等待审核    │    │  资料审核    │   │
│  └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘   │
│                                                                     │          │
│                                                                     ├─ 通过   │
│                                                                     │          │
│                                                                     └─ 拒绝   │
│                                                                       ↓        │
│  ┌─────────────┐    ┌─────────────┐                                    │       │
│  │  6. 通知     │ ←  │  5. 处理     │                                    │       │
│  │  审核结果    │    │  通过/拒绝   │ ──────────────────────────────────┘       │
│  └─────────────┘    └─────────────┘                                              │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

#### 3.2.3 阶段1：注册入口控制

| 配置项 | 说明 |
|-------|------|
| 配置名称 | 系统注册开关 |
| 配置字段 | `enable_user_register` |
| 配置值 | `true` - 开启 / `false` - 关闭 |
| 生效位置 | 登录页是否显示"注册"入口 |

> **说明**：当关闭注册开关时，登录页隐藏"注册"入口，已提交待审核的申请不受影响。

#### 3.2.4 阶段2：用户填写注册资料

##### 3.2.4.1 注册资料要求（机构注册）

| 字段 | 说明 | 必填 | 备注 |
|-----|------|:---:|------|
| 企业名称 | 公司全称 | ✓ | 唯一性校验 |
| 统一社会信用代码 | 营业执照注册号 | ✓ | 唯一性校验 |
| 联系人姓名 | 负责对接的人员姓名 | ✓ | |
| 联系人电话 | 联系电话，用于登录 | ✓ | 唯一性校验 |
| 营业执照 | 营业执照照片/扫描件 | ✓ | 支持图片上传 |
| 经营许可证 | 医疗器械相关许可证 | - | 根据业务需要 |
| 合同复印件 | 与平台合作的合同 | - | 根据业务需要 |
| 开票信息 | 增值税发票开票信息 | - | 根据业务需要 |

##### 3.2.4.2 注册限制（唯一性校验）

| 字段 | 规则 |
|-----|------|
| 手机号 | 全系统唯一，同一手机号只能注册一个账户 |
| 企业名称 | 全系统唯一，同一企业只能注册一个账户 |
| 统一社会信用代码 | 全系统唯一，同一企业代码只能注册一个账户 |

##### 3.2.4.3 注册申请状态

注册提交后，申请进入"待审核"状态：

| 状态 | 说明 |
|-----|------|
| 待审核 | 已提交，等待管理员审核 |
| 通过 | 审核通过，账户已激活，可登录 |
| 拒绝 | 审核拒绝，账户未激活，可重新提交 |

#### 3.2.5 阶段3：管理员审核

##### 3.2.5.1 审核入口

管理员在后台"注册审核"功能中处理待审核申请：

| 角色 | 审核权限 |
|-----|---------|
| 一级管理员 | ✓ 可审核 |
| 业务管理员 | ✓ 可审核 |

##### 3.2.5.2 审核操作

| 操作 | 说明 |
|-----|------|
| 查看资料 | 查看用户提交的注册资料（图片可预览/下载） |
| 审核通过 | 同意用户的注册申请，账户激活 |
| 审核拒绝 | 拒绝用户的注册申请，填写拒绝原因 |
| 填写备注 | 可选，添加内部备注信息 |

##### 3.2.5.3 审核通过后的处理

审核通过后，系统自动完成以下操作：

1. **创建正式账户**：根据注册信息创建系统账户
2. **分配角色**：分配默认角色（机构管理员（外部））
3. **创建机构**：创建对应的机构信息（外部机构）
4. **发送通知**：短信/站内通知用户审核通过

**默认账户分类与角色**：

| 注册类型 | 账户分类 | 分配的角色 |
|----------|----------|------------|
| 机构注册 | 外部用户 | 机构管理员（外部） |

> **说明**：
> - 机构管理员（外部）用于管理该外部机构的整体账户和数据，并可在后台创建本机构的其他用户账号（如“机构用户”）。

##### 3.2.5.4 审核拒绝后的处理

审核拒绝后：

1. **账户保持未激活状态**
2. **发送通知**：站内信/短信通知用户被拒绝，告知拒绝原因
3. **允许重新提交**：用户可修改资料后再次提交申请

#### 3.2.6 阶段4：通知机制

| 触发时机 | 通知方式 | 通知内容 |
|---------|---------|---------|
| 提交注册申请 | 站内信 | 您的注册申请已提交，请等待审核 |
| 审核通过 | 短信 + 站内信 | 您的注册申请已通过，请使用手机号登录 |
| 审核拒绝 | 站内信 | 您的注册申请未通过，拒绝原因：{原因}，请重新提交 |

#### 3.2.7 机构管理员的特殊权限

当外部机构用户注册审核通过后，该账户默认获得**机构管理员（外部）**身份，具备：

| 权限 | 说明 |
|-----|------|
| 创建机构用户账号 | 可为自己的机构创建其他用户账号（如`机构用户`角色） |
| 数据查看权限 | 可查看该机构的全部业务数据 |
| 机构用户管理 | 可管理本机构下所有`机构用户`账户的信息和权限 |

#### 3.2.8 注册申请表数据结构（建议）

```
表名：account_register_application（注册申请表）

字段说明：
├── id                      自增主键
├── phone                   手机号（登录账号）

── 机构注册字段 ──
```

### 术语解释

| 术语 | 说明 |
|------|------|
| 账户分类 | 用户的来源方式划分（内部用户、外部用户） |
| 机构类型 | 机构的业务类型（生产企业、经销商、医疗机构、其他） |
| 机构 | 业务运营的实体单位，如具体的生产企业、经销商、医疗机构 |
| 角色 | 用户在系统中的职能身份，如业务员、设计师、机构管理员等 |
| 所属机构 | 账户归属的具体企业/医院 |
| 结算类型 | 账户的结算方式，如预付费、后付费、月结 |
| 注册审批 | 用户自主注册后由管理员审核的流程 |
| 医院（提单医院） | 订单创建时选择的医院（后台维护），用于医院业务范围与订单归属 |
| 医院范围模板 | 预设医院组合模板，用于快速给账户配置可操作/可查看的医院列表 |
