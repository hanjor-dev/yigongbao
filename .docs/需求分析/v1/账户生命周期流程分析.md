# 账户生命周期流程分析

## 一、文档概述

本文档详细描述医工宝系统**账户生命周期管理**流程，包括账户创建、审核、通知等核心环节的管理逻辑。

本文档涵盖两种账户来源方式：
1. **管理员分发账户**：由管理员手动创建并分配给用户
2. **用户自主注册**：外部用户（经销商、医疗机构、个人用户等）主动注册，管理员审核后启用

> **说明**：两种方式并行存在，管理员可根据业务需求选择使用。

## 三、详细流程设计

### 3.1 方式一：管理员分发账户

#### 3.1.1 阶段1：创建前准备

在正式创建账户前，管理员需要明确以下信息：

| 准备项 | 说明 | 必填 |
|-------|------|:---:|
| **账户分类** | 内部用户（默认） | ✓ |
| **组织类型** | 生产企业/经销商/医疗机构 | ✓ |
| **所属组织** | 哪个具体的企业/医院 | ✓ |
| **角色** | 根据组织类型确定可选角色（设计师、业务员等） | ✓ |
| **父账户** | 是否需要挂靠到某个父账户下（区域管理员管理业务员） | - |
| **生效时间** | 账户立即生效还是指定日期生效 | - |

> **说明**：
> - 管理员创建的账户均为**内部用户**，账户分类选择"内部用户"
> - 组织类型决定可用的角色范围（生产企业→设计师/生产员等，经销商→业务员/区域管理员，医疗机构→医生）
> - 父账户与子账户必须在同一组织内

### 3.2 方式二：用户自主注册审批

#### 3.2.1 功能说明

用户自主注册审批流程适用于**外部用户（经销商、医疗机构、个人用户等）主动申请加入系统**的场景，与管理员分发账户方式互补。

| 特性 | 说明 |
|-----|------|
| 注册开关 | 由后台系统配置字段控制（如 `enable_user_register`），管理员可随时开启/关闭 |
| 审核方式 | 一级审核（业务管理员或一级管理员） |
| 审核要点 | 系统不强制校验，由审核人人工判断资料真实性 |
| 拒绝处理 | 拒绝后允许用户重新提交资料 |

#### 3.2.2 流程概述

```

│  │  1. 触发     │ →  │  2. 填写     │ →  │  3. 提交     │ →  │  4. 审核     │   │
│  │  注册入口    │    │  账户资料    │    │  等待审核    │    │  资料审核    │   │
│  └─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘   │
│                                                                     │          │
```

#### 3.2.3 阶段1：注册入口控制

| 配置项 | 说明 |
|-------|------|
| 配置名称 | 系统注册开关 |
| 配置字段 | `enable_user_register` |
| 配置值 | `true` - 开启 / `false` - 关闭 |
| 生效位置 | 登录页是否显示"注册"入口 |

> **说明**：当关闭注册开关时，登录页隐藏"注册"入口，已提交待审核的申请不受影响。

#### 3.2.4 阶段2：用户填写注册资料

##### 3.2.4.1 账户分类选择

注册时用户需要选择账户分类：

| 分类 | 说明 | 对应账户分类 | 例子 |
|-----|------|-------------|------|
| **机构** | 企业/单位类型 | 外部机构用户 | 医疗机构等 |
| **个人** | 个人类型 | 外部个人用户 | 个人用户 |

> **说明**：这里的"机构"和"个人"是注册界面的选择项，注册通过后将分别映射为"外部机构用户"和"外部个人用户"账户分类。

##### 3.2.4.2 注册资料要求（按分类区分，具体内容待定）

**机构注册资料：**

| 字段 | 说明 | 必填 | 备注 |
|-----|------|:---:|------|
| 企业名称 | 公司全称 | ✓ | 唯一性校验 |
| 统一社会信用代码 | 营业执照注册号 | ✓ | 唯一性校验 |
| 联系人姓名 | 负责对接的人员姓名 | ✓ | |
| 联系人电话 | 联系电话，用于登录 | ✓ | 唯一性校验 |
| 营业执照 | 营业执照照片/扫描件 | ✓ | 支持图片上传 |
| 经营许可证 | 医疗器械相关许可证 | - | 根据业务需要 |
| 合同复印件 | 与平台合作的合同 | - | 根据业务需要 |
| 开票信息 | 增值税发票开票信息 | - | 根据业务需要 |

**个人注册资料：**

| 字段 | 说明 | 必填 | 备注 |
|-----|------|:---:|------|
| 姓名 | 真实姓名 | ✓ | |
| 身份证号 | 身份证号码 | ✓ | 唯一性校验 |
| 身份证照片-正面 | 身份证人像面 | ✓ | 支持图片上传 |
| 身份证照片-反面 | 身份证国徽面 | ✓ | 支持图片上传 |
| 专业资质证明 | 医生执业证、药师证等 | - | 根据账户分类 |
| 所属机构 | 所属医院/诊所（可选） | - | 如医生需关联机构 |

##### 3.2.4.3 注册限制（唯一性校验）

| 字段 | 规则 |
|-----|------|
| 手机号 | 全系统唯一，同一手机号只能注册一个账户 |
| 企业名称 | 全系统唯一，同一企业只能注册一个账户 |
| 统一社会信用代码 | 全系统唯一，同一企业代码只能注册一个账户 |
| 身份证号 | 全系统唯一，同一身份证号只能注册一个账户 |

##### 3.2.4.4 注册申请状态

注册提交后，申请进入"待审核"状态：

| 状态 | 说明 |
|-----|------|
| 待审核 | 已提交，等待管理员审核 |
| 通过 | 审核通过，账户已激活，可登录 |
| 拒绝 | 审核拒绝，账户未激活，可重新提交 |

#### 3.2.5 阶段3：管理员审核

##### 3.2.5.1 审核入口

管理员在后台"注册审核"功能中处理待审核申请：

| 角色 | 审核权限 |
|-----|---------|
| 一级管理员 | ✓ 可审核 |
| 业务管理员 | ✓ 可审核 |

##### 3.2.5.2 审核操作

| 操作 | 说明 |
|-----|------|
| 查看资料 | 查看用户提交的注册资料（图片可预览/下载） |
| 审核通过 | 同意用户的注册申请，账户激活 |
| 审核拒绝 | 拒绝用户的注册申请，填写拒绝原因 |
| 填写备注 | 可选，添加内部备注信息 |

##### 3.2.5.3 审核通过后的处理

审核通过后，系统自动完成以下操作：

1. **创建正式账户**：根据注册信息创建系统账户
2. **分配角色**：根据注册类型分配默认角色
3. **创建组织**：如为机构注册，创建对应的组织信息（外部机构组织）
4. **发送通知**：短信/站内通知用户审核通过

**根据注册类型分配默认账户分类与角色**：

| 注册类型 | 账户分类       | 分配的角色   |
|----------|----------------|--------------|
| 机构注册 | 外部机构用户   | 机构管理员（外部） |
| 个人注册 | 外部个人用户   | 个人用户     |

> **说明**：
> - 机构管理员（外部）用于管理该外部机构的整体账户和数据，具备创建本机构子账户的能力。
> - 个人用户仅能使用被授权的部分系统功能，不可创建子账户。

##### 3.2.5.4 审核拒绝后的处理

审核拒绝后：

1. **账户保持未激活状态**
2. **发送通知**：站内信/短信通知用户被拒绝，告知拒绝原因
3. **允许重新提交**：用户可修改资料后再次提交申请

#### 3.2.6 阶段4：通知机制

| 触发时机 | 通知方式 | 通知内容 |
|---------|---------|---------|
| 提交注册申请 | 站内信 | 您的注册申请已提交，请等待审核 |
| 审核通过 | 短信 + 站内信 | 您的注册申请已通过，请使用手机号登录 |
| 审核拒绝 | 站内信 | 您的注册申请未通过，拒绝原因：{原因}，请重新提交 |

#### 3.2.7 机构管理员的特殊权限

当外部机构用户注册审核通过后，该账户默认获得**机构管理员（外部）**身份，具备：

| 权限 | 说明 |
|-----|------|
| 创建子账户 | 可为自己的机构创建下属账户，子账户统一使用`机构用户`角色 |
| 数据查看权限 | 可查看该机构的全部业务数据 |
| 子账户管理 | 可管理本机构下所有`机构用户`账户的信息和权限 |

> **说明**：个人用户注册成功后，不允许创建子账户，仅允许管理自己的账户信息和数据。

### 术语解释

| 术语 | 说明 |
|------|------|
| 账户分类 | 用户的来源方式划分（内部用户、外部机构用户、外部个人用户、监管机构） |
| 组织类型 | 组织的业务类型（生产企业、经销商、医疗机构、其他） |
| 组织 | 业务运营的实体单位，如具体的生产企业、经销商、医疗机构 |
| 角色 | 用户在系统中的职能身份，如业务员、设计师、机构管理员等 |
| 所属组织 | 账户归属的具体企业/医院 |
| 父账户 | 具有管理子账户权限的账户 |
| 子账户 | 被父账户管理的账户 |
| 结算类型 | 账户的结算方式，如预付费、后付费、月结 |
| 注册审批 | 用户自主注册后由管理员审核的流程 |
