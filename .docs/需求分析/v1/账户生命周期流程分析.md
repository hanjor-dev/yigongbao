# 账户生命周期流程分析

## 一、文档概述

本文档详细描述医工宝系统**账户生命周期管理**流程，包括账户创建、审核、通知等核心环节的管理逻辑。

当前文档内容仅聚焦于**管理员发放账户**的流程设计，涵盖从账户创建到首次登录的完整生命周期。未添加用户主动注册相关内容，待后续完善。

> **说明**：账户的注册、审批等流程属于账户生命周期管理范畴，本文档仅专注管理员发放账户的流程设计。

## 三、详细流程设计

### 阶段1：创建前准备

在正式创建账户前，管理员需要明确以下信息：

| 准备项 | 说明 | 必填 |
|-------|------|:---:|
| **账户分类** | 生产企业、经销商、医疗机构、监管机构、患者 | ✓ |
| **角色** | 业务员、设计师、区域管理员、生产员等（需与分类匹配） | ✓ |
| **所属组织** | 哪个企业/经销商/医院（根据账户分类配置） | ✓ |
| **父账户** | 是否需要挂靠到某个父账户下（区域管理员管理业务员） | - |
| **生效时间** | 账户立即生效还是指定日期生效 | - |

> **说明**：
> - 根据用户体系分析文档，一个账户只能拥有一个角色，角色必须与账户分类匹配
> - 父账户与子账户的账户分类必须一致（如：经销商分类下的区域管理员只能创建经销商分类的业务员）

---

### 阶段2：账户创建（填写信息）

账户应包含以下信息字段：（具体详细字段待定）

#### 2.1 基础信息

| 字段 | 说明 | 必填 | 备注 |
|-----|------|:---:|------|
| 姓名 | 用户真实姓名 | ✓ | |
| 手机号 | 登录账号 | ✓ | 唯一性校验 |
| 邮箱 | 通知接收 | - | |
| 性别 | - | - | |
| 身份证号 | 实名认证 | - | 敏感信息，需加密存储 |

#### 2.2 组织信息

| 字段 | 说明 | 必填 | 备注 |
|-----|------|:---:|------|
| 账户分类 | 生产企业/经销商/医疗机构等 | ✓ | 决定可绑定的角色 |
| 所属组织 | 具体的企业/医院名称 | ✓ | 关联组织信息 |
| 角色 | 对应的系统角色 | ✓ | 决定菜单和功能权限 |
| 父账户 | 区域管理员/负责人 | - | 存在层级关系时 |

#### 2.3 扩展信息（根据角色）

| 字段 | 适用角色 | 说明 |
|-----|---------|------|
| 工号 | 设计师、生产员等 | 内部编号，如 A001、B001 |
| 所属部门 | 生产员、设计师等 | 设计部、生产部等 |
| 专业方向 | 设计师 | 字母代表，如 A-骨科、B-口腔 |
| 资质证书 | 设计师、质管 | 证书编号、有效期 |

#### 2.4 账户安全信息

| 字段 | 说明 | 初始值 |
|-----|------|-------|
| 登录密码 | 首次创建时设置 | 系统生成或管理员指定 |
| 账户状态 | 正常/停用 | 创建时默认"正常" |
| 有效期 | 账户有效期限 | 默认无限制 |

#### 2.5 特殊字段（根据角色）

| 字段 | 适用角色 | 说明 |
|-----|---------|------|
| 结算类型 | 业务员、区域管理员 | 预付费/后付费/月结 |

---

### 阶段3：创建后处理

#### 3.1 通知机制

账户创建成功后，需要通知用户：

| 通知方式 | 通知内容 | 发送条件 |
|---------|---------|---------|
| 短信 | 登录账号、初始密码、登录链接 | 创建成功时 |
| 邮件 | 账户信息、使用说明、安全提醒 | 创建成功时（若填写邮箱） |
| 系统内消息 | 账户创建成功提醒 | 创建成功时 |

## 四、账户操作管理

### 4.1 账户状态说明

| 状态 | 说明 |
|------|------|
| 正常 | 账户可正常使用 |
| 停用 | 账户被管理员停用或触发系统封禁，无法登录 |

```
│                        账户状态流转图                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│    创建 ──→ 正常 ──→ 停用                                          │
│                │        │                                           │
│                │        │                                           │
│                └────────┘                                           │
│                  (重新启用)                                         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.3 管理员操作权限

| 操作 | 一级管理员 | 二级管理员 | 信息中心 |
|-----|:--------:|:--------:|:------:|
| 创建普通业务账户 | ✓ | ✓ | ✗ |
| 创建二级管理员账户 | ✓ | ✗ | ✗ |
| 创建一级管理员账户 | ✓ | ✗ | ✗ |
| 创建信息中心管理员账户 | ✓ | ✗ | ✗ |
| 修改账户信息 | ✓ | ✓ | ✗ |
| 重置密码 | ✓ | ✓ | ✗ |
| 启用/停用账户 | ✓ | ✓ | ✗ |
| 删除账户 | ✓ | ✗ | ✗ |

> **说明**：二级管理员只能管理自己创建的普通业务账户，或由一级管理员分配给他的下属账户。

## 附录

### 术语解释

| 术语 | 说明 |
|------|------|
| 账户分类 | 用户的基本类型划分，如生产企业、经销商等 |
| 角色 | 用户在系统中的职能身份，如业务员、设计师等 |
| 所属组织 | 账户归属的具体企业/医院 |
| 父账户 | 具有管理子账户权限的账户 |
| 子账户 | 被父账户管理的账户 |
| 结算类型 | 账户的结算方式，如预付费、后付费、月结 |
