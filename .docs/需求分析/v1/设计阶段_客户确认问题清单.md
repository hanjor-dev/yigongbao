# 设计阶段功能确认问题清单

---

## Q1：设计师完成设计后需要提交哪些内容？


数据包、可视化模型文件、设计报告、指令单、图纸等。

 - **1a**：这些文件和订单/重建项目之间的对应关系是怎样的？

| 文件类型 | 对应关系候选 | 答案 |
|----------|-------------|------|
| 打印文件数据包 | A）每个重建项目一个包（一一对应）<br>B）一个订单一个包 <br>C）一个项目可以有多个包 | |
| 可视化模型文件 | A）每个重建项目一个文件<br>B）每个重建项目多个文件 | |
| 设计报告 | A）每个重建项目一份<br>B）整个订单一份 | |
| 指令单 | A）每个重建项目一份（N个项目→N份指令单）<br>B）整个订单一份（所有项目汇总在一张指令单内，多个项目则多行） | |
| 图纸 | A）每个重建项目一份<br>B）整个订单一份（超出格位数量时自动分页） | |

## Q3：一个重建项目是否可能需要制作多个产品？

例如「左髋关节」项目可能需要同时制作骨模型和手术导板两种产品。

- **A）一个项目只对应一种产品**：打印信息行数 = 重建项目数量
- **B）一个项目可以对应多种产品**：打印信息可在同一项目下添加多行

---

## Q4：上传数据包、填写打印信息等操作是否有顺序要求？

- **A）有顺序**：必须先上传数据包，才能填写该项目的打印信息和后续操作
- **B）无顺序**：可以任意顺序操作，提交时统一校验完整性

## Q5：图纸中每个项目格位的「3D 模型图片」从哪里来？

- **A）设计师单独上传每个项目的预览图**
- **B）从可视化模型文件中提取**
- **C）从数据包中解析提取**

## Q6：设计师的完整操作流程是怎样的？

请确认以下核心主流程描述是否正确：

```
接单（开始设计）
  → 针对每个重建项目：上传数据包 → 填写打印信息
  → 生成指令单
  → 生成图纸
  → 上传修订后的指令单和图纸
  → 提交设计
  → 审核

 如果错误请修正或补充，如果主流程大致正确请详细补充或给出完整的设计阶段操作演示。
```


## Q7：填写打印信息时，产品字段的级联关系是什么？

- **7a. 产品名称 → 型号规格**：选产品后，型号规格是否自动过滤？
- **7b. 型号规格 → 材质 / 颜色**：选型号后，材质和颜色是否自动过滤？
- **7c. 注册证号**：是随型号规格自动带出（一型号对应一个证号），还是手动选择？
- **7d. 「打印模型」字段**：含义是什么？是产品的子部件列表，还是其他含义？
